王树森深度强化学习笔记8：Multi-Step TD Target

Posted on 2024-01-10，3 min read

一、Sarsa算法与Q-Learning算法（Sarsa versus Q-Learning）

1）Sarsa

① Sarsa 算法用于训练动作价值函数 Qπ(s,a)。

② TD Target 记作 y_t，它是当前观测到的奖励 r_t，与动作价值函数对下一状态、下一动作的预测值乘以折扣因子 γ 之和。

③ 使用 Sarsa 算法更新价值网络，即 Actor-Critic 算法中的 Critic 网络。

2）Q-Learning

① Q-Learning 用于学习最优动作价值函数 Q*(s,a)。

② TD Target 记作 y_t，是当前观测到的奖励 r_t，与价值函数对下一状态下最优动作的预测值乘以折扣因子 γ 之和。

③ 使用 Q-Learning 算法更新 DQN。

无论是 Sarsa 还是 Q-Learning，都只使用一个奖励 r_t，即只用一条 transition 中的奖励；下一条 transition 再用于更新动作价值 Qπ。这样计算出的 TD Target 称为 One-Step TD Target。

二、多步TD Target（Multi-Step TD Target）

其实可以使用多个奖励，例如 r_t、r_{t+1}，即用多条 transition 中的奖励去更新动作价值 Qπ；这样计算出的 TD Target 称为 Multi-Step TD Target。

1）推导多步回报（Derive Multi-Step Return）

我们已经知道 U_t 与 U_{t+1} 的关系，再递归一次，把 U_{t+1} 用 U_{t+2} 表示；经过多步迭代，便得到 U_t 与 U_{t+m} 的关系，这个公式就称为多步回报（Multi-Step Return）。
