linux安装jenkins

Posted on 2022-06-13，2 min read

Jenkins 是最常用的持续集成 / 持续交付（CI/CD）工具之一，一般单独部署在一台构建机上。下面记录在 CentOS 上通过 yum 源安装 Jenkins 的完整过程：装 JDK、添加官方源、修改端口、启动服务，最后解锁并完成初始化配置。

1、安装JDK

Jenkins 是 Java 应用，必须先有可用的 Java 运行时：

yum install -y java

这条命令安装的是 OpenJDK 运行时，只包含 java，不含编译器 javac。如果后续需要在构建任务里编译 Java 代码，建议改装开发包（例如 java-11-openjdk-devel）。安装完成后确认版本，避免 JDK 版本与 Jenkins 要求不匹配：

java -version

2、安装jenkins

添加Jenkins库到yum库，Jenkins将从这里下载安装。

wget -O /etc/yum.repos.d/jenkins.repo http://pkg.jenkins-ci.org/redhat/jenkins.repo

rpm --import https://jenkins-ci.org/redhat/jenkins-ci.org.key

yum install -y jenkins
或
yum install jenkins -y --nogpgcheck

三条命令各做一件事：把 yum 源定义文件写到 /etc/yum.repos.d/jenkins.repo，导入仓库签名公钥，然后安装 jenkins 包。少了导入公钥这一步，yum install 会因 GPG 校验失败而中断；--nogpgcheck 是校验失败时的兜底写法，它会跳过签名校验，安全性更低，不建议长期使用。

3、修改jenkins端口

先确认装上的版本，再看这个包到底放了哪些文件：

[root@tools ~]# rpm -qa | grep jenkins
jenkins-2.340-1.1.noarch

[root@tools ~]# rpm -ql jenkins-2.340-1.1.noarch
/etc/init.d/jenkins
/etc/logrotate.d/jenkins
/etc/sysconfig/jenkins
/usr/bin/jenkins
/usr/lib/systemd/system/jenkins.service
/usr/sbin/rcjenkins
/usr/share/java/jenkins.war
/usr/share/jenkins
/usr/share/jenkins/migrate
/var/cache/jenkins
/var/lib/jenkins
/var/log/jenkins

Jenkins 的监听端口来自环境变量 JENKINS_PORT：旧版本把它放在 /etc/sysconfig/jenkins 里，新版本的服务单元则可能直接用它自己的一份环境变量指定。两处都值得看一眼，改完记得让 systemd 重新加载：

[root@tools ~]# vi /etc/sysconfig/jenkins

# 找到端口号并修改；此端口不冲突可以不修改
JENKINS_PORT="9000"

systemctl daemon-reload

4、启动jenkins

systemctl start jenkins.service
systemctl enable jenkins.service

用下面的命令确认服务已经起来、端口已经监听（netstat 在新版发行版中已废弃，习惯上也可以用 ss -nultp 代替）：

[root@tools ~]# netstat -nultp

端口出现 LISTEN 行且进程名为 java，就说明服务已经就绪；没有输出则先看 systemctl status jenkins 与 /var/log/jenkins/jenkins.log，常见原因是 JDK 版本不满足该 Jenkins 版本的要求或端口被占用。接下来按下面的顺序完成首次初始化：

安装成功后Jenkins将作为一个守护进程随系统启动
系统会创建一个“jenkins”用户来允许这个服务，如果改变服务所有者，同时需要修改/var/log/jenkins, /var/lib/jenkins, 和/var/cache/jenkins的所有者
启动的时候将从/etc/sysconfig/jenkins获取配置参数
默认情况下，Jenkins运行在8080端口，在浏览器中直接访问该端进行服务配置
Jenkins的RPM仓库配置被加到/etc/yum.repos.d/jenkins.repo

5、打开jenkins

在浏览器中访问 http://192.168.3.200:9000/（把 IP 换成实际服务器地址），首次进入会要求输入初始密码。

初始密码在 /var/lib/jenkins/secrets/initialAdminPassword，可以直接在服务器上打印出来：

cat /var/lib/jenkins/secrets/initialAdminPassword

粘贴密码解锁后，按提示安装推荐插件并创建管理员账号，初始化就完成了。

如果忘了管理员密码，可以在 Jenkins 的「系统管理 → 管理用户」里重置；旧版本的默认账号密码是 admin/admin，仅适合本地测试，生产环境务必改掉。
