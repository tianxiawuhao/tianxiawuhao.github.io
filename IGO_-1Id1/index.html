一、深度Q网络（Deep Q-Network DQN）

1）近似Q函数（Approximate the Q* Function）

可以把 Q*(s,a) 看作一位“先知”：它能告诉 Agent 在状态 s 下如何选择最好的动作 a；但真正的 Q*(s,a) 我们并不知道，因此需要用一个函数去近似它。

DQN 是一种价值学习方法：利用神经网络（Neural Network，NN）去近似 Q*(s,a)，记作 Q(s,a;w)。

2）时序差分方法（Temporal Difference Learning TD-Learning）

重要 · 重要 · 非常重要

以我自己的理解复述王树森老师的例子：从纽约到亚特兰大，模型 Q(w) 预测耗时为 1000 分钟，而这个模型一开始是随机的。

那么如何更新模型，使模型的预测值变得越来越准确？

①首先做出一个预测：q=Q(w) → q=1000

②完成这段路程得到真实值y：y=860

这时，产生了一个偏差（q-y）

记损失 Loss 为 L = ½·(q−y)²。前面的 1/2 只是为求导方便：常数缩放不会改变最优点（Loss 乘同一常数后，梯度同向缩放，最优参数 w 不变）。

为了使预测值尽可能逼近真实值，需要让 Loss 取到最小值，因此引入 L 对 w 的梯度（Gradient），即求偏导；利用偏微分的链式法则，可推导出 L 对 w 的梯度表达式，如下图所示：

这样，我们在进行参数更新时，采用梯度下降算法（Gradient Descent）即可使参数w不断接近真实值对应的参数w*。

而当无法到达目的地、拿不到整段路程的真实值时，就可以利用 TD 算法来更新模型参数。

假设我们从纽约向亚特兰大出发，途中经过华盛顿，但在华盛顿停住不再前进，那么此时就不能再用整条路程的真实值来更新预测值了。

因此，这里采用 TD 算法。

我们已知模型做出一个预测：q=Q(w) → q=1000

我们从纽约走到华盛顿后停住，于是得到纽约到华盛顿的真实值：y1 = 300

而从华盛顿到亚特兰大有一个模型预测值：q1=Q(w1)→q=600

此时定义 TD target 为 y = y1 + q1 = 900。这个 TD target 比原来的模型预测值 1000 更加可靠。

记损失为 L = ½·(q−y)²，定义 TD error 为 δ = q−y = 1000−900；也可以理解为：模型对纽约到华盛顿的预测值为 400，真实值为 300，故 δ = 400−300 = 100。

类似地，我们可以得到Loss Function关于w的一个函数，对w求梯度，得到Loss的最小值对应的w用于更新参数（采用梯度下降方法Gradient Descent）

我们必须使 TD error 尽可能小；当 TD error = 0 时，就得到了最优的模型。
