AI 周报 · 2026.04.27 – 05.03

Posted on 2026-05-03，5 min read

微软与 OpenAI 重定合作，终结云独家与 AGI 条款，OpenAI 可接入 AWS 等云；Anthropic 被曝洽谈 500 亿美元融资。马斯克在庭审中承认 xAI 用 OpenAI 模型训练 Grok，法律边界成焦点。

模型与产品

  • 04-29 · Mistral 发布中型模型 Medium 3.5：法国 AI 公司 Mistral 发布 Medium 3.5，并展示其面向智能体与远程使用场景的能力；发布消息在开发者社区获高票讨论，延续其高性价比路线的定位。 来源
  • 04-27 · DeepSeek 大幅下调 V4 收费，价格战升级：DeepSeek 为新发布的 V4 系列大幅下调 API 收费，彭博社称其再度点燃中国大模型价格战；此前 SCMP 统计其定价较 OpenAI GPT-5.5 低约 97%。 来源

开源与开发

  • 05-01 · DeepSeek V4 Flash 与 Pro 上架微软 Foundry：微软 Azure AI Foundry 上架 DeepSeek V4 Flash 与 V4 Pro，企业可直接在云上调用；国产开源权重进入主流云目录，是本周开源生态的重要进展。 来源
  • 05-02 · VS Code 默认追加 Copilot 署名引争议：VS Code 仓库一则合并请求拟在提交中自动追加 Co-Authored-by: Copilot 尾注，开发者质疑未用 Copilot 也会被署名，引发数千条讨论。 来源

融资与产业

  • 04-27 · 微软与 OpenAI 重定合作，终结云独家与 AGI 条款：微软不再独家持有 OpenAI 技术许可，OpenAI 对微软的分成设上限并延续至 2030 年，AGI 条款终结；OpenAI 可经 AWS 等任意云交付产品。 来源
  • 04-29 · 传 Anthropic 洽谈 500 亿美元融资，估值或达 9000 亿：TechCrunch 援引知情人士称，Anthropic 洽谈新一轮约 500 亿美元融资，估值或达 9000 亿美元，交易或于两周内落地，将是 AI 领域迄今最大融资之一。 来源

政策与治理

  • 04-27 · 中国叫停 Meta 以 20 亿美元收购 Manus：中国监管机构在数月审查后，否决 Meta 拟以 20 亿美元收购 AI 智能体公司 Manus 的交易；作为热门通用智能体初创，Manus 的去向引发对 AI 跨境并购前景的讨论。 来源
  • 04-30 · 马斯克作证：xAI 曾用 OpenAI 模型训练 Grok：马斯克诉 OpenAI 案开庭，其作证承认 xAI 曾用 OpenAI 模型输出训练 Grok；边起诉对方背离使命、边被曝采用其模型，本案被视为界定 AI 竞争边界的标志性诉讼。 来源

人文与社会

  • 05-01 · 奥斯卡新规：AI 生成的表演与剧本不得参评：美国电影艺术与科学学院更新参评规则，完全由 AI 生成的演员表演与剧本将不具备奥斯卡奖参评资格，人类创作被置于评审中心；好莱坞的 AI 边界之争延伸到奖项体系。 来源
  • 04-30 · Meta 智能眼镜审核员工因看到私密画面遭解雇：据 BBC 报道，Meta 数名审核智能眼镜用户画面的员工，因在审核中看到性行为等私密内容遭解雇，处理方式引批评；事件聚焦内容审核劳工处境与可穿戴相机隐私。 来源

人文视角 · 一点思考

本周的反讽出现在法庭：马斯克起诉 OpenAI 背离使命，却承认 xAI 用其模型训练 Grok；微软与 OpenAI 的 AGI 条款也在本周终结。当联盟边界要靠合同与诉讼划定，信任便让位于律师。另一边，奥斯卡把 AI 表演挡在门外，是在为人的创作保留一块自留地。工具在变，谁算作者、谁为行为负责，答案仍在形成中。
