5.6 多步TD误差

Posted on 2025-04-16，2 min read

每个时刻的1步TD误差计算如下：

1步TD误差为：

$$\begin{array}{l}\delta_t = R_t + \gamma V(S_{t+1}) - V(S_t)\\ \delta_{t+1} = R_{t+1} + \gamma V(S_{t+2}) - V(S_{t+1})\\ \delta_{t+2} = R_{t+2} + \gamma V(S_{t+3}) - V(S_{t+2})\\ \delta_{t+3} = R_{t+3} + \gamma V(S_{t+4}) - V(S_{t+3}) \end{array} \quad (5.30)$$

1步TD误差为：

$$\begin{array}{l}{A_t^{(1)} = R_t + \gamma V(S_{t+1}) - V(S_t)}\\ {= -V(S_t) + R_t + \gamma V(S_{t+1})}\\ {= \delta_t} \end{array} \quad (5.31)$$

贝尔曼期望方程

$$V(S_{t+1}) = \mathbb{E}[R_{t+1} + \gamma V(S_{t+2})] \quad (5.32)$$

将式子中的 $V(S_{t+1})$ 由 $R_{t+1} + \gamma V(S_{t+2})$ 替换，得到如下式子，就是2步TD误差。

$$\begin{array}{rl} & {A_t^{(2)} = -V(S_t) + R_t + \gamma (R_{t+1} + \gamma V(S_{t+2}))}\\ & {\qquad = -V(S_t) + R_t + \gamma R_{t+1} + \gamma^2 V(S_{t+2})}\\ & {\qquad = \underbrace{R_t + \gamma V(S_{t+1}) - V(S_t)}_{\delta_t} + \gamma \left(\underbrace{R_{t+1} + \gamma V(S_{t+2}) - V(S_{t+1})}_{\delta_{t+1}}\right)}\\ & {\qquad = \delta_t + \gamma \delta_{t+1}} \end{array} \quad (5.33)$$
