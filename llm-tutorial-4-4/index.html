4.4 贝尔曼方程

Posted on 2025-04-13，14 min read

贝尔曼方程是在强化学习中成立的最重要的方程，为许多强化学习算法提供了重要基础。

这里使用骰子作为例子。我们使用的骰子是理想的六面体，每一面的数字出现的概率都是 $\frac{1}{6}$。在数学式中，我们用随机变量 $x$ 表示掷骰子出现的数字，$x$ 是1和6之间的整数。那么每个数字出现的概率就是 $\frac{1}{6}$。我们用 $p(x) = \frac{1}{6}$ 表示骰子的数字出现的概率。现在来计算掷骰子的期望值。计算式如下所示。

$$\begin{array}{l}\mathbb{E}[x] = 1\times \frac{1}{6} +2\times \frac{1}{6} +3\times \frac{1}{6} +4\times \frac{1}{6} +5\times \frac{1}{6} +6\times \frac{1}{6}\\ = 3.5 \end{array} \quad (4.15)$$

如上所述，期望值是在所有情况下“出现的数字”和“概率”相乘并加在一起得到的和。顺带一提，如果使用 $\sum$ 符号，那么期望值的数学式如下所示。

定义4.1—期望的定义以及相关性质

$$\begin{array}{l}\mathbb{E}[x] = \sum_{x}xp(x)\\ \mathbb{E}[f(x)] = \sum_{x}f(x)p(x)\\ \mathbb{E}[X|Y = y] = \sum_{x}x\cdot P(X = x|Y = y)\quad (\text{条件期望})\\ \mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]\quad (\text{期望的线性性质}) \end{array} \quad (4.16)$$

另外，$x$ 和 $y$ 同时发生的概率（这叫作“联合概率”）如所示。

$$p(x,y) = p(x)p(y|x) = p(y)p(x|y) \quad (4.17)$$

假设奖励用 $r(x,y)$ 来表示，那么奖励的期望值如下

$$\begin{array}{l}\mathbb{E}[r(x,y)] = \sum_{x}\sum_{y}p(x,y)r(x,y)\\ = \sum_{x}\sum_{y}p(x)p(y|x)r(x,y) \end{array} \quad (4.18)$$

回顾收益（回报）的定义。

$$G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \dots \quad (4.19)$$

那么有以下公式

$$G_{t+1} = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots \quad (4.20)$$

所以有以下递推公式：

$$\begin{array}{l}G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \dots \\ = R_t + \gamma (R_{t+1} + \gamma R_{t+2} + \dots) \\ = R_t + \gamma G_{t+1} \end{array} \quad (4.21)$$

这种递推关系被用于强化学习的许多理论和算法中。

下面将递推公式代入状态价值函数的定义式中。状态价值函数是收益的期望值，其数学式的定义如下所示。

$$v_{\pi}(s) = \mathbb{E}_{\pi}[G_t|S_t = s] \quad (4.22)$$

如上面的公式所示，状态 $s$ 的价值函数被表示为 $v_{\pi}(s)$。将递推公式带入上面的式子的 $G_t$ 中，得到下面的式子：

$$\begin{array}{rl} & {v_{\pi}(s) = \mathbb{E}_{\pi}[G_t|S_t = s]}\\ & {\qquad = \mathbb{E}_{\pi}[R_t + \gamma G_{t+1}|S_t = s]}\\ & {\qquad = \mathbb{E}_{\pi}[R_t|S_t = s] + \gamma \mathbb{E}_{\pi}[G_{t+1}|S_t = s]} \end{array} \quad (4.23)$$

期望的线性性质

$$\mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]$$

先来推导上面公式中的第一项 $\mathbb{E}_{\pi}[R_t|S_t = s]$

$\mathbb{E}_{\pi}[R_t|S_t = s]$ 的含义是在t时刻，环境的状态是 $s$，那么在t时刻，获得的即时奖励的期望是多少呢？那么需要考虑所有的情况，然后加起来就可以了。

$$\mathbb{E}_{\pi}[R_t|S_t = s] = \sum_{a}\sum_{s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)r(s,a,s^{\prime}) \quad (4.24)$$

如上面的数学式所示，将智能体行动的概率 $\pi(a|s)$、要转移的状态的概率 $p(s'|s,a)$ 和奖励函数 $r(s,a,s')$ 相乘。对所有候选项都进行上述计算，得到它们的总和。

$s \rightarrow s'$ 的转移概率

由于 $s$ 是确定的，所以 $p(s,a) = \pi(a|s)$

$$p(s^{\prime}|s) = \sum_{a}p(s^{\prime},a|s) = \sum_{a}p(s^{\prime}|s,a)p(a|s) = \sum_{a}p(s^{\prime}|s,a)\pi (a|s) \quad (4.25)$$

证明

$$\mathbb{E}_{\pi}[R_t|S_t = s] = \mathbb{E}_{\pi}[R_t = r(s,a,s^{\prime})|S_t = s] \quad (4.26)$$

上面的期望，计算的是随机变量 $R_t$ 的期望。而 $S_t = s$ 是确定好的条件。由于 $r(s,a,s')$ 在 $s,a,s'$ 确定的情况下，计算出来的确定的值。所以 $R_t = r(s,a,s')$ 发生的概率是 $p(s,a,s')$。所以有如下：

$$\begin{array}{rl}\mathbb{E}_{\pi}[R_t|S_t = s] = \mathbb{E}_{\pi}[R_t = r(s,a,s^{\prime})|S_t = s] & \\ = \sum_{a}\sum_{s^{\prime}}r(s,a,s^{\prime})p(s,a,s^{\prime}) & \\ = \sum_{a}\sum_{s^{\prime}}r(s,a,s^{\prime})p(s^{\prime}|s,a)p(s,a) & \\ = \sum_{a}\sum_{s^{\prime}}r(s,a,s^{\prime})p(s^{\prime}|s,a)\pi (a|s) & \\ = \sum_{a,s^{\prime}}r(s,a,s^{\prime})p(s^{\prime}|s,a)\pi (a|s) & \end{array} \quad (4.27)$$

要注意的是：$S_t = s$ 是确定的，所以随机变量为 $a,s'$。所以需要遍历所有可能的 $a,s'$ 事件。

第一项推导完毕，接下来推导第二项。

剩下的项是 $\gamma \mathbb{E}_{\pi}[G_{t+1}|S_t = s]$。由于 $\gamma$ 是常数，因此我们要看的是 $\mathbb{E}_{\pi}[G_{t+1}|S_t = s]$。这个式子虽然与状态价值函数的定义式相似，但在 $G_{t+1}$ 的部分有所不同。状态价值函数的式子如下所示，式子中是 $G_t$，而不是 $G_{t+1}$。

$$v_{\pi}(s) = \mathbb{E}_{\pi}[G_t|S_t = s] \quad (4.29)$$

因此，我们首先要将 $t+1$ 代入上面的式子的 $t$ 中。式子变化如下。

$$v_{\pi}(s^{\prime}) = \mathbb{E}_{\pi}[G_{t+1}|S_{t+1} = s^{\prime}] \quad (4.30)$$

这就是状态 $S_{t+1} = s'$ 时的价值函数。接下来要关注的是 $\mathbb{E}_{\pi}[G_{t+1}|S_t = s]$。这是在当前时刻为 $t$ 时，下一个时刻（$t+1$）的收益期望值。解决的关键在于将条件 $S_t = s$ 变为 $S_{t+1} = s$ 的形式。换句话说，就是要进入下一个时刻。

通过观察可以得到

$$\begin{array}{l}\mathbb{E}_{\pi}[G_{t+1}|S_t = s] = \sum_{a,s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)\mathbb{E}_{\pi}[G_{t+1}|S_{t+1} = s^{\prime}]\\ = \sum_{a,s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)v_{\pi}(s^{\prime}) \end{array} \quad (4.31)$$

证明

思路就是将 $s \rightarrow s'$ 的所有路径都遍历计算一遍。

$$\begin{array}{rl} \mathbb{E}_{\pi}[G_{t+1}|S_t = s] & = \sum_{G_{t+1}}p(G_{t+1}|S_t = s) \cdot G_{t+1}\\ & = \sum_{G_{t+1}}\left\{\sum_{s^{\prime}}p(G_{t+1},S_{t+1} = s^{\prime} \mid S_t = s)\right\} \cdot G_{t+1}\\ & = \sum_{G_{t+1}}\left\{\sum_{s^{\prime}}p(G_{t+1}|S_{t+1} = s^{\prime},S_t = s)p(S_{t+1} = s^{\prime}|S_t = s)\right\} G_{t+1}\\ & = \sum_{G_{t+1}}\left\{\sum_{s^{\prime}}p(G_{t+1}|S_{t+1} = s^{\prime})p(S_{t+1} = s^{\prime}|S_t = s)\right\} \cdot G_{t+1} \quad (\text{马尔可夫性质})\\ & = \sum_{s^{\prime}}p(S_{t+1} = s^{\prime}|S_t = s)\left\{\sum_{G_{t+1}}p(G_{t+1}|S_{t+1} = s^{\prime}) \cdot G_{t+1}\right\}\\ & = \sum_{s^{\prime}}p(S_{t+1} = s^{\prime}|S_t = s)\mathbb{E}_{\pi}[G_{t+1}|S_{t+1} = s^{\prime}]\\ & = \sum_{a,s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)v_{\pi}(s^{\prime})\\ & = \mathbb{E}_{\pi}[v_{\pi}(s^{\prime})|S_t = s] \quad (\text{期望形式}) \end{array} \quad (4.32)$$

在 $S_{t+1}$ 确定下来之后，$G_{t+1}$ 不再依赖 $S_t$。因为 $G_{t+1} = R_{t+1} + \gamma G_{t+2} = r(S_{t+1} = s', a, S_{t+2} = s'') + \gamma G_{t+2}$。

完成第二项的展开以后，汇总一下得到

定理4.1—贝尔曼方程

$$\begin{array}{rl} & {v_{\pi}(s) = \mathbb{E}_{\pi}[R_t|S_t = s] + \gamma \mathbb{E}_{\pi}[G_{t+1}|S_t = s]}\\ & {\qquad = \sum_{a,s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)r(s,a,s^{\prime}) + \gamma \sum_{a,s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)v_{\pi}(s^{\prime})}\\ & {\qquad = \sum_{a,s^{\prime}}\pi (a|s)p(s^{\prime}|s,a)\{r(s,a,s^{\prime}) + \gamma v_{\pi}(s^{\prime})\}} \end{array} \quad (4.33)$$

上面的式子就是大名鼎鼎的贝尔曼方程。贝尔曼方程是表示状态 $s$ 的价值函数和下一个可能的状态 $s'$ 的价值函数之间关系的式子。这个贝尔曼方程对所有状态 $s$ 和所有策略 $\pi$ 都成立。

状态价值函数的贝尔曼方程的另一种重要的表示形式：贝尔曼期望方程。

定理4.2—贝尔曼期望方程

$$V_{\pi}(S_t) = \mathbb{E}_{\pi}[R_t + \gamma V_{\pi}(S_{t+1})|S_t] \quad (4.34)$$

贝尔曼期望方程的推导过程如下：

$$\begin{array}{rl} & {V_{\pi}(S_t) = \mathbb{E}_{\pi}[R_t|S_t = s] + \gamma \mathbb{E}_{\pi}[G_{t+1}|S_t = s]}\\ & {\qquad = \mathbb{E}_{\pi}[R_t|S_t = s] + \gamma \mathbb{E}_{\pi}[V_{\pi}(s^{\prime})|S_t = s]}\\ & {\qquad = \mathbb{E}_{\pi}[R_t + \gamma V_{\pi}(s^{\prime})|S_t = s]} \end{array} \quad (4.35)$$
