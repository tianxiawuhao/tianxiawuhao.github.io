王树森深度强化学习笔记12：策略梯度中的基准（Policy Gradient with Baseline）

Posted on 2024-01-26，2 min read

在策略梯度中加入基线（Baseline）可以降低方差、加快收敛，是 REINFORCE 走向 Actor-Critic 的关键一步。本文按王树森《深度强化学习》课程笔记整理。

一、策略梯度回顾

对离散动作空间，策略梯度定理为

\[\nabla_\theta J(\theta) = \mathbb{E}_{A\sim\pi(\cdot\mid s;\theta)}\Big[\nabla_\theta \ln \pi(A\mid s;\theta)\cdot Q_\pi(s,A)\Big]\]

其中 \(Q_\pi(s,a)\) 是动作价值函数，用来给动作打分；梯度按「动作有多好」加权。

二、引入基准（Baseline）

取任意不依赖动作 \(A\) 的量 \(b\)（常数、状态价值 \(V_\pi(s)\)、回报均值都可以），把它从 \(Q_\pi\) 中减去：

\[\nabla_\theta J(\theta) = \mathbb{E}\Big[\nabla_\theta \ln \pi(A\mid s;\theta)\cdot\big(Q_\pi(s,A)-b\big)\Big]\]

减掉 \(b\) 为什么不会改变梯度？因为当 \(b\) 与动作 \(A\) 无关时

\[\mathbb{E}\Big[\nabla_\theta \ln \pi(A\mid s;\theta)\cdot b\Big] = b\sum_a \nabla_\theta \pi(a\mid s;\theta) = b\,\nabla_\theta \underbrace{\sum_a \pi(a\mid s;\theta)}_{=1} = 0\]

所以带基线的策略梯度仍然是无偏的，改变的是它的方差。

三、蒙特卡洛近似

期望无法直接计算，改为按策略 \(\pi\) 采样动作 \(a_t\)：

\[g(a_t) = \nabla_\theta \ln \pi(a_t\mid s_t;\theta)\cdot\big(Q_\pi(s_t,a_t)-b\big)\]

\(g(a_t)\) 是策略梯度的无偏估计，用随机梯度上升更新参数：\(\theta \leftarrow \theta + \alpha\,g(a_t)\)。\(b\) 不影响期望，却直接影响每次观测到的 \(g(a_t)\) 的大小——这正是方差差异的来源。

四、为什么取 \(V_\pi(s)\) 作基线

若取 \(b = V_\pi(s)\)，括号内就是优势函数：

\[A_\pi(s,a) = Q_\pi(s,a) - V_\pi(s)\]

它衡量「这个动作比平均水平好多少」：优于平均为正、劣于平均为负，符号有区分度，数值更接近 0，方差明显小于直接用 \(Q_\pi\)。

五、实践要点

  • 取值自由度：只要与动作无关，\(b\) 可以是任意数；实践中常用 \(V_\pi(s)\)，也可用常数或一个 batch 的平均回报。
  • 只降方差、不改期望：\(Q_\pi\) 与 \(Q_\pi-V_\pi\) 期望相同，但后者更接近 0，蒙特卡洛近似更稳定、收敛更快。
  • 与 Actor-Critic 衔接：用 Critic 网络 \(v(s;w)\) 近似 \(V_\pi\)，就得到带基线的策略梯度（A2C）形式；基线越准，方差越小。
  • 常见误区：基线不能依赖动作，否则期望不再是原来的梯度；基线本身不必很准，有偏的 \(V\) 依然能降低方差。
