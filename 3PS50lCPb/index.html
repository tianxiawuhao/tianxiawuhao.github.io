有限元分析

Posted on 2024-05-18，9 min read

有限元方法

有限元法基于数学与力学原理，采用计算机数值分析手段，获得复杂工程问题及科学研究中的定量结果，也被称为一种基于计算机计算的“虚拟实验”。在数学上，它是求解复杂微分方程近似解的有效工具；有限元分析的力学基础是弹性力学；其实现方法是数值离散技术，最终的载体是有限元分析软件。

有限元分析

有限元分析的核心思想是“化整为零”：用较简单的问题代替复杂问题后再求解。它将求解域看成由许多称为有限元的小的互连子域组成，对每一单元假定一个合适的（较简单的）近似解，然后推导求解整个域满足的条件（如结构的平衡条件），从而得到问题的解。

有限元求解的流程

第一步 预处理

根据实际问题定义求解模型，包括以下几个方面：

  • 定义问题的几何区域：根据实际问题近似确定求解域的物理性质和几何区域；

  • 定义单元的材料属性；

  • 定义边界条件；

  • 定义载荷。

第二步 离散化

选择合适的单元类型，对结构进行离散化

  • 按维度划分，常见单元类型如下

    1. 一维单元：一维单元用于模拟沿一条直线的结构，如梁或杆件。常见的一维单元包括梁单元（Beam Element）和杆单元（Truss Element）。梁单元通常用于模拟梁的弯曲和扭转行为，而杆单元则通常用于模拟受拉或受压的杆件。

    2. 二维单元：二维单元用于模拟平面结构，如板或壳体。常见的二维单元包括三角形单元（Triangle Element）和四边形单元（Quadrilateral Element）。这些单元可以用于模拟平面结构的应力、应变和变形等行为。

    3. 三维单元：三维单元用于模拟实体结构。常见的三维单元包括四面体单元（Tetrahedral Element）、六面体单元（Hexahedral Element）和棱柱单元（Prismatic Element），可用于分析实体结构的应力、应变与变形。

    4. 特殊单元：除上述结构单元外，还有弹簧单元、质量单元、间隙单元等特殊单元，用于模拟连接、约束等局部行为；它们可与结构单元配合使用，以贴合汽车车身、机翼等复杂结构的具体需求。

  • 按单元阶次分为以下类型

    1. 一阶单元（Linear Element）：使用线性插值函数近似描述单元内部解的变化，阶次低、计算快，但精度较低。

    2. 二阶单元（Quadratic Element）：使用二次插值函数，能更准确地近似单元内部解的变化，精度高于一阶单元，但计算成本稍高。

    3. 三阶单元（Cubic Element）：使用三次插值函数，对解的变化逼近更精确，精度更高，但计算成本相对更高。

    除了上述常见阶次外，还存在四阶、五阶等更高阶单元，通过更高次的插值函数更精确地逼近解的变化。实际应用中，需要根据具体工程问题选择合适的单元阶次，在精度与计算效率之间权衡：较低阶单元常用于初步设计与快速分析，较高阶单元用于更精确的分析与研究。

不同类型的有限元单元适用于不同的结构形状和分析需求。在实际应用中，需要根据具体的工程问题选择适合的有限元单元类型，以获得准确的分析结果。

第三步 单元刚度矩阵（单元的基函数）

可以使用不同的方法来推导有限元分析中的基本刚度矩阵，基本上都是基于平衡的概念：

  • 直接解析法：
    列出问题的微分方程，通过寻找满足全场条件的解析解函数直接求解；技术难度较高，一般只适用于较为简单的问题。【直接从强形式出发求解】

  • 数值解法：

    • 差分法：
      通过微分构造差商，把微分方程离散成线性方程组求解，实现相对简单，但计算量较大，适用于中等复杂的问题。相比解析法，差分法已经有了很大便利；若想操作更简单、能覆盖更广的问题，就需要引入试函数。

    • 试函数法【从弱形式出发求解】：
      用积分（加权）形式描述微分方程，而不是直接求解微分方程。假设试函数满足一定的边界条件，将其代入控制方程，令残差的加权积分（或泛函的变分）为零，得到线性方程组求解。该方法实现规范、计算量较小、精度较高，只要确定了试函数，后续过程就非常程式化，适用范围很广。试函数法在工程与数学上的不同发展，可分为变分法和加权残值法：

      • 变分法（以最小势能原理为代表）：

      当一个体系的总势能取最小时，系统处于稳定平衡状态。例如，小球在曲面上运动，到达曲面最低点时系统趋于稳定平衡。

      • 加权残值法（伽辽金法）：

      通过选取有限多项式函数（又称基函数或形函数），将它们叠加，再要求结果在求解域内及边界上的加权积分（权函数为试函数本身）满足原方程，便可以得到一组易于求解的线性代数方程，且自然边界条件能够自动满足。

第四步 总装（定义单元的连通性）

根据各个单元的连接情况，把已求得的单元刚度矩阵组装成整体刚度矩阵；整体刚度矩阵决定了结构对外加载荷的响应方式。总装发生在相邻单元的公共节点处，状态变量及其导数（如果可能）的连续性也在节点处建立。

第五步 求解计算

联立方程组的求解可用直接法（稀疏求解器）或迭代法（迭代求解器）。求解结果是单元节点处状态变量的近似值。

两种求解器可以配合使用，一般有两种集成方式：顺序耦合与协同仿真。顺序耦合：Standard 计算完成的结果作为 Explicit 的初始状态继续计算。协同仿真：在同一个模型中，一部分采用 Standard、一部分采用 Explicit，求解过程中两部分同时进行并适时交换数据。

稀疏求解器

  • 1、为矩阵提供直接求解。

  • 2、带宽未进行优化，因此节省了执行此运算所花的时间。

  • 3、仅存储非零项，而非整个矩阵。（正因为如此，才出现了“稀疏求解器”这一术语。）

  • 4、尽管要存储的刚度矩阵项更少，但需要更多变量才能存储非零项的位置。因此，稀疏求解器比其他求解器需要更多内存。

  • 5、对于中小型模型，稀疏求解器的求解速度通常最快。

迭代求解器

  • 1、为矩阵提供间接求解。因此，用户必须指定最大迭代次数，并指定判断解何时收敛的收敛准则；不能保证在指定的迭代次数内求出矩阵解。

  • 2、迭代求解器需要从初始猜测开始，因此某些求解器内置了预条件器（preconditioner），为提高模型求解效率提供了更多选项。

  • 3、带宽未进行优化，因此节省了执行此运算所花的时间。

  • 4、迭代求解器所需的内存比稀疏求解器更少。

  • 5、对于大型模型，若迭代能够收敛，迭代求解器的求解速度通常最快。模型“大小”取决于分析类型：对线性静力分析，15 万个方程（自由度）即属大型模型；而对需要求解大量时间步的机械运动仿真，5 万个方程就可能已算大型模型。

第六步 后处理

对所求出的解根据有关准则进行分析和评价。后处理使用户能简便提取信息，了解计算结果。

有限元分析的优点

优点一

在制造原型之前，我们可以在 CAD 模型上查看应力分布：它能预测哪些区域可能首先失效，以及在更高载荷下哪些次生区域随后失效。通过正确应用有限元分析，可以在仿真模型上高效地执行设计迭代。

优点二

可以看到物理样机搭建与测试过程中看不到的现象。

例如，让灰铸铁铸件过载：在它突然开裂或断裂之前，变形可能很不明显。若想让铸件在某个方向变得更硬，试验台架上很难测量到如此小的挠度；而通过有限元分析可以轻松看到挠度分布，这有助于理解载荷路径，并以最有效的方式加固结构。
