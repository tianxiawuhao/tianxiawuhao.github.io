第三章 Apache Kafka 与Spark的集成

Posted on 2021-04-21，6 min read

在本章中，我们将讨论如何将Apache Kafka与Spark Streaming API集成。

关于Spark

Spark Streaming API 支持实时数据流的可扩展、高吞吐量、容错流处理。数据可以从 Kafka、Flume、Twitter 等多种数据源中提取，并可用 map、reduce、join、window 等算子做复杂计算；处理后的数据可以推送到文件系统、数据库和实时仪表板。

弹性分布式数据集（RDD）是 Spark 的基本数据结构，它是一个不可变的分布式对象集合。RDD 中的每个数据集被划分为若干逻辑分区，可以在集群的不同节点上并行计算。

与Spark集成

Kafka 是 Spark 流式处理最常用的消息与集成平台：Kafka 充当实时数据流的中心枢纽，Spark Streaming 从中消费数据并用复杂算法处理；处理完成后，结果可以发布到另一个 Kafka 主题，或者写入 HDFS、数据库、实时仪表板。下图描述了这一概念流程。

这里 Kafka 起到缓冲层的作用：下游计算变慢时消息仍能暂存在 Kafka 中，不会立刻压垮计算任务，这也是它常被放在 Spark 之前的原因。

下面详细介绍 Kafka-Spark 相关 API。

SparkConf API

SparkConf 表示 Spark 应用程序的配置，用于以键值对的形式设置各种 Spark 参数。常用方法如下：

  • set(String key, String value) - 设置配置项。
  • remove(String key) - 从配置中移除指定配置项。
  • setAppName(String name) - 设置应用程序名称，该名称会显示在集群 Web UI 上。
  • get(String key) - 获取指定配置项的值。

StreamingContext API

StreamingContext 是 Spark Streaming 功能的主要入口点，它表示到 Spark 集群的连接，可用于在集群上创建 RDD、累加器和广播变量。签名定义如下所示。

public StreamingContext(String master, String appName, Duration batchDuration, 
   String sparkHome, scala.collection.Seq<String> jars, 
   scala.collection.Map<String,String> environment)
  • master - 要连接的集群 URL（例如 mesos://host:port、spark://host:port、local[4]）。
  • appName - 作业名称，显示在集群 Web UI 上。
  • batchDuration - 流式数据被切分成批次的时间间隔。
public StreamingContext(SparkConf conf, Duration batchDuration)

通过传入创建新 SparkContext 所需的配置来构造 StreamingContext。

  • conf - Spark 参数。
  • batchDuration - 流式数据被切分成批次的时间间隔。

KafkaUtils API

KafkaUtils API 用于把 Kafka 集群连接到 Spark 流，其中最主要的方法是 createStream，定义如下。

public static ReceiverInputDStream<scala.Tuple2<String,String>> createStream(
   StreamingContext ssc, String zkQuorum, String groupId,
   scala.collection.immutable.Map<String,Object> topics, StorageLevel storageLevel)

上面的方法用于创建从 Kafka Broker 拉取消息的输入流（DStream）。各参数含义如下：

  • ssc - StreamingContext 对象。
  • zkQuorum - ZooKeeper 集群地址（quorum）。
  • groupId - 该消费者的组 ID。
  • topics - 要消费的主题与消费者线程数的映射（Map）。
  • storageLevel - 接收对象的存储级别。

KafkaUtils 还有另一个方法 createDirectStream，用于创建直接从 Kafka Broker 拉取消息的输入流，不经过任何 Receiver。它配合 checkpoint 可以保证每条 Kafka 消息在转换中恰好被处理一次（exactly-once）。

下面用 Scala 编写示例应用。编译前需要先下载并安装 sbt（Scala 构建工具，作用类似 Maven）。主程序代码如下所示。

import java.util.HashMap

import org.apache.kafka.clients.producer.{KafkaProducer, ProducerConfig, ProducerRecord}
import org.apache.spark.SparkConf
import org.apache.spark.streaming._
import org.apache.spark.streaming.kafka._

object KafkaWordCount {
   def main(args: Array[String]) {
      if (args.length < 4) {
         System.err.println("Usage: KafkaWordCount <zkQuorum> <group> <topics> <numThreads>")
         System.exit(1)
      }

      val Array(zkQuorum, group, topics, numThreads) = args
      val sparkConf = new SparkConf().setAppName("KafkaWordCount")
      val ssc = new StreamingContext(sparkConf, Seconds(2))
      ssc.checkpoint("checkpoint")

      val topicMap = topics.split(",").map((_, numThreads.toInt)).toMap
      val lines = KafkaUtils.createStream(ssc, zkQuorum, group, topicMap).map(_._2)
      val words = lines.flatMap(_.split(" "))
      val wordCounts = words.map(x => (x, 1L))
         .reduceByKeyAndWindow(_ + _, _ - _, Minutes(10), Seconds(2), 2)
      wordCounts.print()

      ssc.start()
      ssc.awaitTermination()
   }
}

构建脚本

Spark-Kafka 集成依赖 Spark、Spark Streaming 和 Spark-Kafka 集成 jar 包。新建 build.sbt 文件，指定应用信息及其依赖关系；编译打包时 sbt 会自动下载所需的 jar。

name := "Spark Kafka Project"
version := "1.0"
scalaVersion := "2.10.5"

libraryDependencies += "org.apache.spark" %% "spark-core" % "1.6.0"
libraryDependencies += "org.apache.spark" %% "spark-streaming" % "1.6.0"
libraryDependencies += "org.apache.spark" %% "spark-streaming-kafka" % "1.6.0"

注意：这里的 Spark 1.6.0 与 Scala 2.10.5 沿用自原文，属于 Receiver 模式时代的版本组合。在新版本 Spark 中应改用与 Spark 版本一致的 spark-streaming-kafka-0-10 连接器，并把 scalaVersion 改为对应版本（例如 2.12）。

编译与打包

运行以下命令即可编译并打包出应用的 jar 文件，随后将该 jar 提交到 Spark 运行。

sbt package

提交到Spark

先启动 Kafka Producer CLI（在上一章中介绍过），创建一个名为 my-first-topic 的新 topic，并发送几条示例消息：

Another spark test message

然后运行以下命令，把应用程序提交到 Spark：

/usr/local/spark/bin/spark-submit \
  --packages org.apache.spark:spark-streaming-kafka_2.10:1.6.0 \
  --class "KafkaWordCount" --master local[4] \
  target/scala-2.10/spark-kafka-project_2.10-1.0.jar \
  localhost:2181 <group name> <topic name> <number of threads>

该应用的示例输出如下所示。

spark console messages ..
(Test,1)
(spark,1)
(another,1)
(message,1)
spark console message ..

可以看到，每个批次中出现的单词都会被统计并打印出来。至此，一个最小的 Kafka + Spark Streaming 集成示例就完成了。
