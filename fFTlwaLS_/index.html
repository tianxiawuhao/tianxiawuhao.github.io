RestTemplate

Posted on 2021-06-07，8 min read

RestTemplate 是 Spring 提供的同步 HTTP 客户端：URL 拼接、请求头组装、请求发送、响应反序列化都被收进一行方法调用里，常用于服务之间的同步调用。它由 spring-web 提供，既可以在 Spring Boot 中通过 @Bean 统一配置超时与重试，也可以脱离容器直接 new 出来用。需要注意：Spring Framework 6.1 起官方更推荐同步场景用 RestClient、异步场景用 WebClient，RestTemplate 已处于维护状态，新项目可优先考虑它们。

Spring 环境下的配置

首先导入 Spring Boot 的 Web 包

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

然后在启动类同包（或子包）下新建配置类 RestTemplateConfig.java，把 RestTemplate 注册成 Bean：

import org.apache.http.client.HttpClient;
import org.apache.http.client.config.RequestConfig;
import org.apache.http.impl.client.DefaultHttpRequestRetryHandler;
import org.apache.http.impl.client.HttpClientBuilder;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.client.ClientHttpRequestFactory;
import org.springframework.http.client.HttpComponentsClientHttpRequestFactory;
import org.springframework.web.client.RestTemplate;

@Configuration
public class RestTemplateConfig {

    @Bean
    public RestTemplate restTemplate() {

        //生成一个设置了连接超时时间、请求超时时间
        RequestConfig config = RequestConfig.custom()
                .setConnectionRequestTimeout(10000)
                .setConnectTimeout(10000)
                .setSocketTimeout(30000).build();

        // 设置异常重试
        HttpClientBuilder builder = HttpClientBuilder.create()
                .setDefaultRequestConfig(config)
                .setRetryHandler(new DefaultHttpRequestRetryHandler(3, false));
        HttpClient httpClient = builder.build();

        ClientHttpRequestFactory requestFactory =
                new HttpComponentsClientHttpRequestFactory(httpClient);
        RestTemplate restTemplate = new RestTemplate(requestFactory);
        // 日志拦截
        //restTemplate.setInterceptors(Collections.singletonList(new RestTemplateConsumerLogger()));

        return restTemplate;
    }
}

三个超时的单位都是毫秒：setConnectTimeout 建立连接、setConnectionRequestTimeout 从连接池取连接、setSocketTimeout 读取数据；new DefaultHttpRequestRetryHandler(3, false) 表示最多重试 3 次且请求已发出后不再重试。注意版本差异：这里用的是 HttpClient 4（org.apache.http.*），Spring Boot 3.x 集成的是 HttpClient 5（org.apache.hc.client5.*），迁移时需按新包名改写。

RestTemplate

RestTemplate 定义了 36 个与 REST 资源交互的方法，大多数都对应 HTTP 的方法。其中只有 11 个独立的方法：10 个各有 3 种重载形式，第 11 个重载了 6 次，合计 36 个方法。

  1. getForEntity() 发送一个HTTP GET请求，返回的ResponseEntity包含了响应体所映射成的对象

  2. getForObject() 发送一个HTTP GET请求，返回的请求体将映射为一个对象

  3. postForEntity() POST 数据到一个URL，返回包含一个对象的ResponseEntity，这个对象是从响应体中映射得到的

  4. postForObject() POST 数据到一个URL，返回根据响应体匹配形成的对象

  5. exchange() 在URL上执行特定的HTTP方法，返回包含对象的ResponseEntity，这个对象是从响应体中映射得到的

  6. execute() 在URL上执行特定的HTTP方法，返回一个从响应体映射得到的对象

  7. delete() 在特定的URL上对资源执行HTTP DELETE操作

  8. headForHeaders() 发送HTTP HEAD请求，返回包含特定资源URL的HTTP头

  9. optionsForAllow() 发送HTTP OPTIONS请求，返回对特定URL的Allow头信息

  10. postForLocation() POST 数据到一个URL，返回新创建资源的URL

  11. put() PUT 资源到特定的URL

getForEntity

get 请求就和直接在浏览器地址栏中发送请求一样。

下面四段代码依次演示：URL 占位符传参、映射为自定义对象、Map 传参，以及先用 UriComponentsBuilder 构建 URI 再发起请求。

RestTemplate restTemplate = new RestTemplate();
ResponseEntity<String> responseEntity=restTemplate.getForEntity(url+"?name={1}", String.class, "username");
String body = responseEntity.getBody();

RestTemplate restTemplate = new RestTemplate();
ResponseEntity<TokenBeen> responseEntity =restTemplate.getForEntity(url+"?name={1}", TokenBeen.class, "username");
if(responseEntity!=null){
    TokenBeen body = responseEntity.getBody();
}

//注意map的key要和参数中占位符相同
RestTemplate restTemplate = new RestTemplate();
Map<String, String> params = new HashMap<>();
params.put("name", "username");
ResponseEntity<String> responseEntity = restTemplate.getForEntity(url+"?name={name}", String.class, params);
String body = responseEntity.getBody();

RestTemplate restTemplate = new RestTemplate();
UriComponents uriComponents = UriComponentsBuilder.fromUriString(url+"?name={name}").build().expand("username").encode();
URI uri = uriComponents.toUri();
ResponseEntity<String> responseEntity = restTemplate.getForEntity(uri, String.class);
String body = responseEntity.getBody();

@GetMapping("getForEntity/{id}")
public User getById(@PathVariable(name = "id") String id) {
    ResponseEntity<User> response = restTemplate.getForEntity("http://localhost/get/{id}", User.class, id);
    User user = response.getBody();
    return user;
}

getForObject

getForObject 和 getForEntity 用法几乎相同。getForObject 可以看作是对 getForEntity 的进一步封装：它直接把返回值取成响应体，省去了我们再调用 getBody() 的步骤，代价是拿不到状态码和响应头。

RestTemplate restTemplate = new RestTemplate();
//注意参数中是uri
UriComponents uriComponents = UriComponentsBuilder.fromUriString(url+"?name={name}").build().expand("username").encode();
URI uri = uriComponents.toUri();
String body = restTemplate.getForObject(uri, String.class);

RestTemplate restTemplate = new RestTemplate();
//注意参数中是uri
UriComponents uriComponents = UriComponentsBuilder.fromUriString(url+"?name={name}").build().expand("username").encode();
URI uri = uriComponents.toUri();
TokenBeen body = restTemplate.getForObject(uri, TokenBeen.class);

@GetMapping("getForObject/{id}")
public User getById(@PathVariable(name = "id") String id) {
    User user = restTemplate.getForObject("http://localhost/get/{id}", User.class, id);
    return user;
}

postForEntity

postForEntity 与 getForEntity 对称：发送 POST 请求并返回 ResponseEntity，既能从响应体映射出对象，也能读取状态码与响应头。它同样有三种重载：

public <T> ResponseEntity<T> postForEntity(String url, @Nullable Object request, Class<T> responseType, Object... uriVariables)throws RestClientException {} 
public <T> ResponseEntity<T> postForEntity(String url, @Nullable Object request, Class<T> responseType, Map<String, ?> uriVariables) throws RestClientException {} 
public <T> ResponseEntity<T> postForEntity(URI url, @Nullable Object request, Class<T> responseType) throws RestClientException {}

RestTemplate restTemplate = new RestTemplate();
HttpHeaders headers = new HttpHeaders();
//header参数
MediaType type = MediaType.parseMediaType("application/json; charset=UTF-8");
headers.setContentType(type);
headers.add("Accept", MediaType.APPLICATION_JSON.toString());
//body参数
JSONObject param = new JSONObject();
param.put("username", "123");
HttpEntity<JSONObject> formEntity = new HttpEntity<>(param, headers);
//发送请求
String result = restTemplate.postForObject(url, formEntity, String.class);

@RequestMapping("saveUser")
public String save(User user) {
    ResponseEntity<String> response = restTemplate.postForEntity("http://localhost/save", user, String.class);
    String body = response.getBody();
    return body;
}

postForObject

用法与 getForObject 一样，只是请求方法换成 POST：返回的同样是响应体映射后的对象，不必再从 ResponseEntity 中取一次。

@RequestMapping("saveUser")
public String save(User user) {
    String body = restTemplate.postForObject("http://localhost/save", user, String.class);
    return body;
}

exchange

exchange 是最通用的方法：可以指定任意 HTTP 方法（GET、POST、PUT、DELETE 等），还能通过 ParameterizedTypeReference 把泛型信息一并传给消息转换器，避免泛型被擦除。

@PostMapping("demo")
public void demo(Integer id, String name){

    HttpHeaders headers = new HttpHeaders();//header参数
    headers.add("authorization", auth);
    headers.setContentType(MediaType.APPLICATION_JSON);

    JSONObject content = new JSONObject();//放入body中的json参数
    content.put("userId", id);
    content.put("name", name);

    //post 发送
    HttpEntity<JSONObject> postRequest = new HttpEntity<>(content, headers); //组装
    ResponseEntity<String> postResponse = restTemplate.exchange("http://localhost:8080/demo", HttpMethod.POST, postRequest, String.class);

    //返回带泛型的对象：用 ParameterizedTypeReference 保留泛型信息
    ParameterizedTypeReference<RestBean<String>> responseBodyType = new ParameterizedTypeReference<RestBean<String>>() {};
    ResponseEntity<RestBean<String>> restBeanResponse = restTemplate.exchange("http://localhost:8080/demo", HttpMethod.POST, postRequest, responseBodyType);

    //get 发送
    HttpEntity<String> getRequest = new HttpEntity<>("parameters", headers); //组装
    ResponseEntity<String> getResponse = restTemplate.exchange("http://localhost:8080/demo", HttpMethod.GET, getRequest, String.class);
    //返回指定对象
    ResponseEntity<User> userResponse = restTemplate.exchange("http://localhost:8080/demo", HttpMethod.GET, getRequest, User.class);
}

exchange 的四个参数依次是 URL、HTTP 方法、请求实体（无需请求体时可传 null）、响应体要转换成的类型。示例假设类中已注入 RestTemplate（例如 @Resource private RestTemplate restTemplate;）。
