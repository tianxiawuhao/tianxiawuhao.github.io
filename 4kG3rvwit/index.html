centos7安装Docker详细步骤

Posted on 2022-05-26，2 min read

一、安装前必读

本文以 CentOS 7 为例，机器内核为 3.10（CentOS 7 自带内核），满足 Docker 官方对内核版本的要求。下文所有命令均以 root 用户登录执行，普通用户执行时请在每条命令前加 sudo。

1. 查看当前的内核版本

uname -r

2. 使用 root 权限更新 yum 包（生产环境中此步操作需慎重，按自己情况决定；学习环境随意）

yum -y update

这一步不是必须执行的，看个人情况；如果后面安装时出现依赖不兼容的情况，就必须先 update 了。

注意两者的区别：yum -y update 升级所有包，同时也会升级软件和系统内核；yum -y upgrade 只升级所有包，不升级软件和系统内核。生产环境升级内核可能影响已有业务，建议谨慎选择。

3. 卸载旧版本（如果之前安装过的话）

yum remove docker docker-common docker-selinux docker-engine

二、安装 Docker 的详细步骤

1. 安装需要的软件包：yum-utils 提供 yum-config-manager 功能，另外两个包是 devicemapper 驱动依赖。

yum install -y yum-utils device-mapper-persistent-data lvm2

2. 设置 yum 源：下面两个源都可以使用，国内服务器推荐阿里仓库，下载速度更快。

# 中央仓库（Docker 官方，国内访问可能较慢）
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 阿里仓库（国内推荐）
yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

3. 选择 Docker 版本并安装

（1）查看可用版本有哪些：

yum list docker-ce --showduplicates | sort -r

（2）选择一个版本并安装，把版本号换成上一步列出的完整版本，例如 docker-ce-18.03.1.ce：

yum -y install docker-ce-18.03.1.ce

4. 启动 Docker 并设置开机自启

systemctl start docker
systemctl enable docker
# 查看服务状态，确认出现 active (running)
systemctl status docker

到这里 Docker 就装好了，可以先跑一个测试容器，确认能正常拉取镜像并运行：

docker run hello-world
