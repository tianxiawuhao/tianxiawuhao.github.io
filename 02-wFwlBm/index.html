二、表格形式的Sarsa（Sarsa：Tabular Version）

要学习动作价值函数 \(Q_\pi(s,a)\)，当状态和动作都有限时，可以画一张表格：一行对应一个状态 \(s_i\)，一列对应一个动作 \(a_j\)，表中每个元素就是该状态-动作对的动作价值 \(Q_\pi(s_i,a_j)\)。Sarsa 要做的就是不断更新这张表格，每次只改动其中一个元素。

观测到一个四元组 \((s_t,a_t,r_t,s_{t+1})\)，称为 transition；再用策略 \(\pi\) 采样出下一动作 \(a_{t+1}\)，接着计算 TD target \(y_t\)。例如若 \(s_{t+1}\) 是 \(s_2\)、采样得到 \(a_{t+1}=a_3\)，查表即可读出对应的 \(Q_\pi(s_{t+1},a_{t+1})\)。

同时，我们也能计算出 TD error \(\delta_t\)。

然后用 TD error 更新 \(Q_\pi(s_t,a_t)\)，其中 \(\alpha\) 是学习率。

三、神经网络形式的Sarsa（Sarsa：Neural Network Version）

我们可以用一个价值网络来近似 \(Q_\pi(s,a)\)，记作 \(q(s,a;\boldsymbol{w})\)。注意，动作价值函数 \(Q_\pi\) 和价值网络 \(q\) 都与策略 \(\pi\) 有关：策略越好，这两个函数给出的估计也越准。

神经网络 \(q(s,a;\boldsymbol{w})\) 被称为价值网络：输入一个状态 \(s\)，输出该状态下每个动作的价值。若动作共有 \(n\) 个，网络就输出一个 \(n\) 维向量，其中第 \(j\) 个元素是对 \(Q_\pi(s,a_j)\) 的近似。

TD target 记作 \(y_t\)，等于实际观测到的奖励 \(r_t\) 与折扣后的网络预测值 \(\gamma\cdot q(s_{t+1},a_{t+1};\boldsymbol{w})\) 之和：

\[ y_t = r_t + \gamma\cdot q(s_{t+1},a_{t+1};\boldsymbol{w}) \]

TD error 记作 \(\delta_t = y_t - q(s_t,a_t;\boldsymbol{w})\)，即 TD target 与价值网络当前估计之差，我们希望它越小越好。

Loss 记作 \(L=\frac{1}{2}\delta_t^2\)，取 TD error 平方的一半；我们希望不断更新价值网络的参数 \(\boldsymbol{w}\) 来减小 Loss。

Gradient：对 Loss 求关于 \(\boldsymbol{w}\) 的梯度，把 TD target \(y_t\) 视为常数，有 \(\nabla_{\boldsymbol{w}}L=-\delta_t\cdot\nabla_{\boldsymbol{w}}q(s_t,a_t;\boldsymbol{w})\)，再用梯度下降寻找 Loss 的局部最小值。

Gradient descent：梯度下降用于更新价值网络参数 \(\boldsymbol{w}\leftarrow\boldsymbol{w}-\alpha\nabla_{\boldsymbol{w}}L\)，即 \(\boldsymbol{w}\leftarrow\boldsymbol{w}+\alpha\delta_t\nabla_{\boldsymbol{w}}q(s_t,a_t;\boldsymbol{w})\)，其中 \(\alpha\) 是学习率。

四、总结（Summary）

我们采用 Sarsa 算法，主要是为了学习动作价值函数 \(Q_\pi(s,a)\)。

这里有两种形式：

①表格形式（直接学习Qπ）

表格形式适用于状态与动作数量都不大的有限场景：用一张表格记录每种状态-动作对对应的 Qπ(s,a) 值，并通过 TD 算法逐步更新表中每个 \(Q_\pi(s,a)\) 的值。

②神经网络形式（采用函数近似）

这种形式并不直接存储 Qπ(s,a)，而是用价值网络 \(q(s,a;\boldsymbol{w})\) 近似动作价值函数 \(Q_\pi(s,a)\)；它实际上是用 TD 算法更新价值网络参数 \(\boldsymbol{w}\)，使 q(s,a;w) 越来越好。应用有学习笔记4的AC算法中的Critic网络。
