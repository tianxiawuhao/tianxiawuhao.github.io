二、表格形式的Sarsa（Sarsa：Tabular Version）

要学习动作价值函数 Qπ(s,a)，当状态和动作都有限时，可以画一张表格：一行对应一个状态 s_i，一列对应一个动作 a_j，表中每个元素就是该状态-动作对的动作价值 Qπ(s_i,a_j)。我们要做的，就是用 Sarsa 算法去更新表格，每次更新一个元素。

观测到一个四元组 (s_t, a_t, r_t, s_{t+1})，称为 transition；再用策略 π 采样出下一动作 a_{t+1}，接着计算 TD target y_t。例如假设 s_{t+1} 为 s_2、采样得到 a_{t+1}=a_3，则查表即可得到对应的 Qπ(s_{t+1}, a_{t+1})。

同时，我们也能计算出 TD error δ_t。

然后利用 δ_t 更新 Qπ(s_t,a_t)，其中 α 是学习率。

三、神经网络形式的Sarsa（Sarsa：Neural Network Version）

我们可以采用价值网络来近似Qπ(s,a)，记为q(s,a;w)。注意，动作价值函数Qπ和价值网络q都与策略π有关，策略π的好坏会影响这两个函数。

神经网络q(s,a;w)被称为价值网络，它的输入是一个状态s，输出是状态s下对应动作的价值。如果有n个动作，那么价值网络q就会输出一个n维向量，向量元素对应在状态s下，各动作a的价值。

TD target 记作 y_t，是实际观测的奖励 r_t 与折扣后的价值网络预测值 γ·q(s_{t+1}, a_{t+1}; w) 之和。

TD error 记作 δ_t，是价值网络对当前状态和动作的估计 q(s_t,a_t;w) 与 TD target 之差，我们希望它越小越好。

Loss 记作 L，通常取 TD error 平方的一半（L = ½·δ_t²）作为损失；我们希望不断更新价值网络的参数 w 来减小 Loss。

Gradient：对 Loss 求关于 w 的梯度，利用梯度下降找到 Loss 的局部最小值。

Gradient descent：梯度下降算法，用于更新价值网络参数 w。

四、总结（Summary）

我们采用 Sarsa 算法，主要是为了学习动作价值函数 Qπ(s,a)。

这里有两种形式：

①表格形式（直接学习Qπ）

表格形式适用于状态与动作数量都不大的有限场景：用一张表格记录每种状态-动作对对应的 Qπ(s,a) 值，并通过 TD 算法逐步更新表中每个 Qπ(s,a) 的值。

②神经网络形式（采用函数近似）

这种形式并不直接存储 Qπ(s,a)，而是用价值网络 q(s,a;w) 近似动作价值函数 Qπ(s,a)；它实际上是用 TD 算法更新价值网络参数 w，使 q(s,a;w) 越来越好。应用有学习笔记4的AC算法中的Critic网络。
