王树森深度强化学习笔记7：Q-Learning算法

Posted on 2024-01-05，3 min read

一、Sarsa算法与Q-Learning算法对比

首先来对比一下 Sarsa 和 Q-Learning。两者的差别集中在 TD Target 的计算方式上：Sarsa 使用行为策略实际采样到的下一动作，Q-Learning 则直接在下一状态上取最大的动作价值。

1）Sarsa算法

① Sarsa 算法用于训练动作价值函数 \(Q_\pi(s,a)\)。

② TD Target 记作 \(y_t\)，它是当前观测到的奖励 \(r_t\)，与动作价值函数对下一状态、下一动作的预测值乘以折扣因子 \(\gamma\) 之和：

\[ y_t = r_t + \gamma\, Q_\pi(s_{t+1}, a_{t+1}) \]

2）Q-Learning算法

① Q-Learning 用于学习最优动作价值函数 \(Q^\star(s,a)\)。

② TD Target 记作 \(y_t\)，是当前观测到的奖励 \(r_t\)，与价值函数对下一状态下最优动作的预测值乘以折扣因子 \(\gamma\) 之和：

\[ y_t = r_t + \gamma\, \max_{a} Q(s_{t+1}, a) \]

二、推导TD Target（Derive TD Target）

我们已经知道，对于任意策略 \(\pi\)，动作价值函数都满足如下的贝尔曼等式：

\[ Q_\pi(s_t,a_t) = \mathbb{E}\Big[\, R_t + \gamma\, Q_\pi(S_{t+1}, A_{t+1}) \;\Big|\; S_t = s_t,\; A_t = a_t \,\Big] \]

在最优策略 \(\pi^\star\) 下，我们往往用 \(Q^\star\) 替换上式中的 \(Q_\pi\)，因此得到如下的等式：

我们推导一下这个式子。由于 \(Q^\star(S_{t+1}, \cdot)\) 是下一状态 \(S_{t+1}\) 下各个动作的价值，因此 \(A_{t+1}\) 必然要取使 \(Q^\star(S_{t+1}, a)\) 最大化的动作 \(a^\star\)，于是有了如下的结论：

代入上面的等式，就可以得到如下等式：

\[ Q^\star(s_t,a_t) = \mathbb{E}\Big[\, R_t + \gamma\, \max_{a} Q^\star(S_{t+1}, a) \;\Big|\; S_t = s_t,\; A_t = a_t \,\Big] \]

然而，直接求式子中的期望十分困难，因此这里采用蒙特卡洛近似：

用观测到的奖励 \(r_t\) 近似随机变量 \(R_t\)，用观测到的下一状态 \(s_{t+1}\) 近似 \(S_{t+1}\)，于是蒙特卡洛近似后的式子如下：

\[ y_t = r_t + \gamma\, \max_{a} Q^\star(s_{t+1}, a) \]

至此，我们得到了 TD Target \(y_t\)。

三、表格形式的Q-Learning（Q-Learning：Tabular Version）

表格版 Q-Learning 用一张表存放 \(Q^\star(s,a)\)，每观测到一个 transition 就更新一次表格，整体流程如下：

具体步骤如下：

① 观测到一个四元组 \((s_t,a_t,r_t,s_{t+1})\)，这里称之为一个 transition。

② 上一节已经推导出 TD Target 的公式。实际中 Q 是一张表格：先找到状态 \(s_{t+1}\) 一行中最大的动作价值 \(Q(s_{t+1}, a^\star)\)，再据此计算 TD Target \(y_t\)：

\[ y_t = r_t + \gamma\, \max_{a} Q(s_{t+1}, a) \]

③ 接下来计算 TD error \(\delta_t\)：

\[ \delta_t = Q(s_t,a_t) - y_t \]

④ 最后，用如下公式更新表格中的 \(Q(s_t, a_t)\)（\(\alpha\) 为学习率）：

\[ Q(s_t,a_t) \leftarrow Q(s_t,a_t) - \alpha\, \delta_t \]

四、神经网络形式的Q-Learning（Q-Learning：DQN Version）

我们采用 DQN \(Q(s,a;w)\) 来近似最优动作价值函数 \(Q^\star(s,a)\)。

DQN 采用如下公式控制 Agent，而我们训练 DQN 的目的，就是学到更好的神经网络参数 \(w\)：

\[ a^\star = \arg\max_{a} Q(s, a; w) \]

具体步骤如下：

① 观测到一个四元组 \((s_t,a_t,r_t,s_{t+1})\)，这里称之为一个 transition。

② 计算 TD Target \(y_t\)。与上一小节类似，这里只是把表格中的 \(Q(s_{t+1},a)\) 换成了 DQN 的 \(Q(s_{t+1},a^\star;w)\)：

\[ y_t = r_t + \gamma\, \max_{a} Q(s_{t+1}, a; w) \]

③ TD error \(\delta_t\) 的计算也类似：

\[ \delta_t = Q(s_t,a_t;w) - y_t \]

④ 最后，采用梯度下降来更新神经网络参数 \(w\)：

\[ w \leftarrow w - \alpha\, \delta_t\, \nabla_w Q(s_t,a_t;w) \]

五、总结（Summary）

这里要注意 Q-Learning 与 Sarsa 的区别：Sarsa 算法学习的是动作价值函数 \(Q_\pi\)（同策略，on-policy），而 Q-Learning 学习的是最优动作价值函数 \(Q^\star\)（异策略，off-policy）。但两者的目的都是让 Agent 获得更高的分数。
