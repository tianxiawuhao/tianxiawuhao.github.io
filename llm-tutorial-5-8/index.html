5.8 相关数学证明

Posted on 2025-04-18，19 min read

5.8.1 策略梯度法的证明

当 $J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}[G(\tau)]$ 时，其梯度如下面的式子所示。

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}G(\tau)\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \quad (5.42)$$

下面对上面的式子进行证明。

$$\begin{array}{rl} \nabla_{\theta}J(\theta) &= \nabla_{\theta}\mathbb{E}_{\tau \sim \pi_{\theta}}[G(\tau)]\\ &= \nabla_{\theta}\sum_{\tau}\mathrm{Pr}(\tau)G(\tau)\ (\text{展开期望值})\\ &= \sum_{\tau}\nabla_{\theta}(\mathrm{Pr}(\tau)G(\tau))\ (\text{将}\nabla_{\theta}\text{移动到}\sum\text{中})\\ &= \sum_{\tau}\{G(\tau)\nabla_{\theta}\mathrm{Pr}(\tau) + \mathrm{Pr}(\tau)\nabla_{\theta}G(\tau)\}\ (\text{积的微分})\\ &= \sum_{\tau}G(\tau)\nabla_{\theta}\mathrm{Pr}(\tau)\ (\nabla_{\theta}G(\tau)\text{永远为0})\\ &= \sum_{\tau}G(\tau)\mathrm{Pr}(\tau)\frac{\nabla_{\theta}\mathrm{Pr}(\tau)}{\mathrm{Pr}(\tau)}\ (\text{乘以}\frac{\mathrm{Pr}(\tau)}{\mathrm{Pr}(\tau)})\\ &= \sum_{\tau}G(\tau)\mathrm{Pr}(\tau)\nabla_{\theta}\log \mathrm{Pr}(\tau)\ (\text{log梯度技巧})\\ &= \mathbb{E}_{\tau \sim \pi_{\theta}}[G(\tau)\nabla_{\theta}\log \mathrm{Pr}(\tau)] \end{array} \quad (5.43)$$

这里对“log梯度的技巧”进行说明。这个技巧利用了以下等式。

$$\nabla_{\theta}\log \mathrm{Pr}(\tau|\theta) = \frac{\nabla_{\theta}\mathrm{Pr}(\tau|\theta)}{\mathrm{Pr}(\tau|\theta)} \quad (5.44)$$

log梯度技巧

$$(\log f(x))' = \frac{f'(x)}{f(x)} \quad (5.45)$$

根据上面的式子，我们就知道

$$\nabla_{\theta}\mathrm{Pr}(\tau|\theta) = \mathrm{Pr}(\tau|\theta)\nabla_{\theta}\log \mathrm{Pr}(\tau|\theta) \quad (5.46)$$

这就是著名的 log梯度的技巧。是机器学习领域常用的数学式的变形形式。

接下来，我们将利用以下等式进一步展开式（5.43）。

$$\begin{array}{rl} \mathrm{Pr}(\tau|\theta) &= p(S_0)\pi_{\theta}(A_0|S_0)p(S_1|S_0,A_0)\cdots \pi_{\theta}(A_T|S_T)p(S_{T+1}|S_T,A_T)\\ &= p(S_0)\prod_{t = 0}^{T}\pi_{\theta}(A_t|S_t)p(S_{t+1}|S_t,A_t) \end{array} \quad (5.47)$$

轨迹的概率

轨迹是：$\tau = (S_0, A_0, S_1, A_1, S_2, A_2, S_3)$，那么轨迹的概率如下计算：

$$\begin{array}{rl} \mathrm{Pr}(\tau) &= p(S_0, A_0, S_1, A_1, S_2, A_2, S_3)\\ &= p(S_3|S_0, A_0, S_1, A_1, S_2, A_2)p(S_0, A_0, S_1, A_1, S_2, A_2)\\ &= p(S_3|S_2, A_2)p(S_0, A_0, S_1, A_1, S_2, A_2)\\ &= p(S_3|S_2, A_2)p(A_2|S_0, A_0, S_1, A_1, S_2)p(S_0, A_0, S_1, A_1, S_2)\\ &= p(S_3|S_2, A_2)p(A_2|S_2)p(S_0, A_0, S_1, A_1, S_2)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_0, A_0, S_1, A_1)p(S_0, A_0, S_1, A_1)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_1, A_1)p(S_1|S_0, A_0)p(S_0, A_0, S_1)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_1, A_1)p(A_1|S_0, A_0, S_1)p(S_0, A_0, S_1)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_1, A_1)p(A_1|S_1)p(S_0, A_0, S_1)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_1, A_1)\pi_{\theta}(A_1|S_1)p(S_0, A_0, S_1)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_1, A_1)\pi_{\theta}(A_1|S_1)p(S_1|S_0, A_0)p(A_0|S_0)p(S_0)\\ &= p(S_3|S_2, A_2)\pi_{\theta}(A_2|S_2)p(S_2|S_1, A_1)\pi_{\theta}(A_1|S_1)p(S_1|S_0, A_0)\pi_{\theta}(A_0|S_0)p(S_0) \end{array} \quad (5.48)$$

这里，$p(S_0)$ 表示初始状态 $S_0$ 的概率。上面的式子表明，得到轨迹 $\tau$ 的概率可以用初始状态的概率、策略以及下一个状态的转移概率的乘积来表示。另外，我们可以用下面的式子来表示 $\log \mathrm{Pr}(\tau|\theta)$。

$$\log \mathrm{Pr}(\tau|\theta) = \log p(S_0) + \sum_{t = 0}^{T}\log p(S_{t+1}|S_t, A_t) + \sum_{t = 0}^{T}\log \pi_{\theta}(A_t|S_t) \quad (5.49)$$

由于 $\log xy = \log x + \log y$，所以可以像上面的式子那样表示为和的形式。基于上面的式子，可以将 $\nabla_{\theta}\log \mathrm{Pr}(\tau|\theta)$ 展开为如下形式。

$$\begin{array}{rl} \nabla_{\theta}\log \mathrm{Pr}(\tau|\theta) &= \nabla_{\theta}\left\{\log p(S_0) + \sum_{t = 0}^{T}\log p(S_{t+1}|S_t, A_t) + \sum_{t = 0}^{T}\log \pi_{\theta}(A_t|S_t)\right\}\\ &= \nabla_{\theta}\sum_{t = 0}^{T}\log \pi_{\theta}(A_t|S_t) \end{array} \quad (5.50)$$

$\nabla_{\theta}$ 是对 $\theta$ 的梯度。与 $\theta$ 无关的元素的梯度 $\nabla_{\theta}\log p(S_0)$ 和 $\nabla_{\theta}\sum_{t = 0}^{T}\log p(S_{t+1}|S_t, A_t)$ 为0。因此，从上面的式子可以得到下列式子。

$$\begin{array}{rl} \nabla_{\theta}J(\theta) &= \mathbb{E}_{\tau \sim \pi_{\theta}}[G(\tau)\nabla_{\theta}\log \mathrm{Pr}(\tau|\theta)]\\ &= \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}G(\tau)\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \end{array} \quad (5.51)$$

这样我们就完成了 $\nabla_{\theta}J(\theta)$ 的推导。

从极大似然估计的角度看策略梯度

$$\begin{array}{rl} J(\theta) &= \sum_{t = 0}^{T}G(\tau)\log \pi_{\theta}(A_t|S_t)\\ &= G(\tau)\log \left(\prod_{t = 0}^{T}\pi_{\theta}(A_t|S_t)\right) \end{array} \quad (5.52)$$

最大化目标就会提升某些状态对应的动作的概率。

5.8.2 基线（Baseline）的推导

$$\begin{array}{rl} \nabla_{\theta}J(\theta) &= \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}G_t\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right]\\ &= \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}(G_t - b(S_t))\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right]\\ &= \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}G_t\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] - \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}b(S_t)\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right]\\ &= \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}G_t\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \quad (\text{证明这一项等于0即可}) \end{array} \quad (5.53)$$

如上面的式子所示，我们可以使用 $G_t - b(S_t)$ 代替 $G_t$。$b(S_t)$ 是任何函数，我们称之为“基线”。下面进行上式的推导。

首先，证明以下式子成立。

$$\mathbb{E}_{x \sim P_{\theta}}[\nabla_{\theta}\log P_{\theta}(x)] = 0 \quad (5.54)$$

这里假设随机变量 $x$ 是基于概率分布 $P_{\theta}(x)$ 生成的。$P_{\theta}$ 会根据参数 $\theta$ 改变概率分布的形状。此时有以下式子成立。

$$\sum_{x}P_{\theta}(x) = 1 \quad (5.55)$$

由于 $P_{\theta}(x)$ 是概率分布，因此所有 $x$ 的值的和为1。然后，求这个式子的梯度。

$$\nabla_{\theta}\sum_{x}P_{\theta}(x) = \nabla_{\theta}1 = 0 \quad (5.56)$$

接下来，使用log梯度的技巧将式子展开，过程如下所示。

$$\begin{array}{rl} 0 &= \nabla_{\theta}\sum_{x}P_{\theta}(x)\\ &= \sum_{x}\nabla_{\theta}P_{\theta}(x)\\ &= \sum_{x}P_{\theta}(x)\nabla_{\theta}\log P_{\theta}(x)\ (\text{log梯度技巧})\\ &= \mathbb{E}_{x \sim P_{\theta}}[\nabla_{\theta}\log P_{\theta}(x)] \end{array} \quad (5.57)$$

式（5.54）证明完毕。接下来将证明的式子用于我们的问题。具体来说，用 $A_t$ 代替式（5.54）中的 $x$，然后使用 $\pi_{\theta}(\cdot|S_t)$ 代替 $P_{\theta}(\cdot)$。这样就可以得到以下式子。

$$\mathbb{E}_{A_t \sim \pi_{\theta}}[\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)] = 0 \quad (5.58)$$

上面的式子是对 $A_t$ 的期望值。因此，我们可以像下面的式子那样，将任何函数 $b(S_t)$ 放入期望值中。$\mathbb{E}[x] = 0 \rightarrow \mathbb{E}[cx] = c \cdot 0 = 0$。

$$\mathbb{E}_{A_t \sim \pi_{\theta}}[b(S_t)\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)] = 0 \quad (5.59)$$

$b(S_t)$ 是以 $S_t$ 为参数的函数，即使 $A_t$ 发生变化，它的值也不会改变。由于式（5.59）是对 $A_t$ 的期望值，因此即使在期望值中加入函数 $b(S_t)$，等式也成立。

危险

动作 $A_t$ 的变化会导致收益 $G_t$ 的变化，因此以下式子不成立。

$$\mathbb{E}_{A_t \sim \pi_{\theta}}[G_t\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)] = 0 \quad (5.60)$$

式（5.59）在整个 $t = 0 \sim T$ 的范围都成立，所以可以得到以下式子。

$$\mathbb{E}_{A_t \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}b(S_t)\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] = 0 \quad (5.61)$$

所以基线证明完毕。

5.8.3 REINFORCE 证明

可以证明：把整条轨迹回报 $G(\tau)$ 换成从时刻 $t$ 开始的回报 $G(t)$，本质上是利用了因果性：时刻 $t$ 的动作不会影响时刻 $t$ 之前已经发生的奖励。因此，过去奖励那部分在期望下对梯度贡献为0。

将 $G(\tau)$ 拆成过去和未来两部分

对某个时刻 $t$，可以把整条轨迹回报拆成：

$$G(\tau) = \sum_{k = 0}^{t - 1}\gamma^k R_k + \sum_{k = t}^{T - 1}\gamma^k R_k \quad (5.62)$$

记过去回报为

$$G_{< t} = \sum_{k = 0}^{t - 1}\gamma^k R_k \quad (5.63)$$

未来回报为

$$G_{\geq t} = \sum_{k = t}^{T - 1}\gamma^k R_k \quad (5.64)$$

于是有

$$G(\tau) = G_{< t} + G_{\geq t} \quad (5.65)$$

代入梯度中的第 $t$ 项：

$$\mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)G(\tau)] \quad (5.66)$$

得到

$$\mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)G_{< t}] + \mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)G_{\geq t}] \quad (5.67)$$

关键是证明第一项为0。

在上一节中，我们证明过：由于 $G_{< t}$ 不依赖于 $A_t$ 变化，所以相当于是常数。

所以第一项为0。

如果定义从时刻t开始的“reward-to-go”为

$$G_t = \sum_{k = t}^{T - 1}\gamma^{k - t}R_k \quad (5.68)$$

那么上式也常写为

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T - 1}\gamma^{t}\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)G_t\right] \quad (5.69)$$

很多教材会把折扣因子的位置简化或吸收到 $G_t$ 的定义中，因此也常见写法：

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T - 1}\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)G_t\right] \quad (5.70)$$

直观解释

原始形式中，第 $t$ 个策略梯度项是：

$$\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)G(\tau) \quad (5.71)$$

但 $A_t$ 只会影响：

  • 当前奖励；
  • 未来状态；
  • 未来奖励。

它不可能影响已经发生的过去奖励。因此把过去奖励乘到

$$\nabla_{\theta}\log \pi_{\theta}(A_t|S_t) \quad (5.72)$$

上，只会增加噪声，不会改变期望值。

所以用 $G_t$ 代替 $G(\tau)$ 不会改变梯度的无偏性，但可以降低方差。

结论

REINFORCE中将整条轨迹回报 $G(\tau)$ 替换为从当前时刻开始的回报 $G(t)$ 是成立的，因为对于任意时刻 $t$，过去奖励部分满足

$$\mathbb{E}\left[\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\sum_{k = 0}^{t - 1}\gamma^{k}R_k\right] = 0 \quad (5.73)$$

因此删掉过去奖励不会引入偏差，只是减少了方差（噪声）。这就是所谓的“reward-to-go trick”或“因果性改进”。
