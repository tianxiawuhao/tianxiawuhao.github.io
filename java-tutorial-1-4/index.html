1.4 数组与常见算法

Posted on 2024-06-23，11 min read

学了变量之后，你很快会遇到一个尴尬的问题：要存 100 个学生成绩，难道写 100 个变量？数组就是为解决这类“同类型批量数据”而生的容器。但数组真正的价值不只是“能存很多”，而是它内存连续、可随机访问——正因为这个特性，它成了排序和查找算法的第一个练兵场。本章会把一维、二维数组的用法讲清楚，然后手写选择排序、冒泡排序和二分查找，最后落到日常工作真正会用的 Arrays 工具类。适合已经会写 for 循环和方法的读者。

数组：一段连续的内存

数组（array）是存放同一种数据类型、长度固定、内存连续的一组数据的容器。三个定语缺一不可：类型必须一致，长度在创建时确定且之后不可改变，元素在内存里一个挨着一个排列。

使用数组分两步：声明变量、分配空间。声明只是告诉编译器“这个变量将来指向一个 int 数组”，真正向堆内存申请空间的是 new：

// 声明 + 分配空间：元素自动初始化为 0
int[] scores = new int[5];

// 合法：类型写在变量名后面，但不推荐，容易读错
int other[] = new int[5];

// 声明的同时初始化：长度由元素个数推断，不能同时写 [5]
int[] nums = {90, 85, 77, 60, 98};
int[] nums2 = new int[]{90, 85, 77, 60, 98};   // 等价写法

不同类型元素的默认值不同，这是新手最容易踩的坑：new int[5] 的元素是 0，引用类型数组的元素是 null，boolean 是 false。数组本身也是对象，声明后没有赋值时默认值同样是 null，此时访问 arr.length 会抛空指针异常。

数组有三个必须记住的规则。第一，length 是属性不是方法，写 arr.length() 编译不过（字符串的 length() 才是方法）。第二，下标从 0 开始，最后一个元素的下标是 length - 1；越界访问会抛 ArrayIndexOutOfBoundsException。第三，数组一旦创建，长度不可变，想“扩容”只能新建一个更长的数组再把数据复制过去——这正是后面 ArrayList 自动做的事。

因为元素等长且连续，定位第 i 个元素只需一步乘法：首地址 + i × 元素大小。这就是“随机访问”——不管取第一个还是第一万个，耗时都一样。代价是插入和删除中间元素必须整体搬动，这个取舍会一直贯穿数据结构的学习。

遍历数组的标准写法有两种，按场景选：

int[] nums = {90, 85, 77, 60, 98};

// 普通 for：需要下标（要修改元素、要比较相邻元素）时用
for (int i = 0; i < nums.length; i++) {
    System.out.println("第 " + i + " 个：" + nums[i]);
}

// 增强 for（for-each）：只关心"每个值"时用，更简洁
int sum = 0;
for (int n : nums) {
    sum += n;
}
System.out.println("总分：" + sum);

// 求最大值：把第一个元素当作擂主，后来者挑战
int max = nums[0];
for (int i = 1; i < nums.length; i++) {
    if (nums[i] > max) {
        max = nums[i];
    }
}
System.out.println("最高分：" + max);
注意：增强 for 遍历时，变量 n 是元素值的副本，循环体内给 n 赋值不会改到数组本身。要在遍历中修改元素，必须用普通 for 配合下标。

二维数组

二维数组可以理解为“数组的数组”，适合表示表格、矩阵、棋盘这类有行有列的数据。int[][] matrix = new int[3][4] 表示 3 行 4 列。

// 3 行 4 列，元素全部为 0
int[][] grid = new int[3][4];

// 直接初始化：外层大括号是"行"，内层是"列"
int[][] scores = {
    {90, 85, 77},
    {60, 98, 72},
    {88, 91, 95}
};

System.out.println(scores.length);      // 3，行数
System.out.println(scores[0].length);   // 3，第 0 行的列数
System.out.println(scores[1][2]);       // 72，第 1 行第 2 列

// 双层遍历累加
int total = 0;
for (int i = 0; i < scores.length; i++) {
    for (int j = 0; j < scores[i].length; j++) {
        total += scores[i][j];
    }
}
System.out.println("总和：" + total);

// 增强 for 的双层写法
for (int[] row : scores) {
    for (int v : row) {
        System.out.print(v + "\t");
    }
    System.out.println();
}

有一个细节值得单独强调：Java 的二维数组不要求每行等长，因为它的本质是“一维数组，每个元素再指向一个一维数组”。所以下面这种“锯齿数组”完全合法：

int[][] jagged = new int[3][];   // 只确定行数
jagged[0] = new int[]{1};
jagged[1] = new int[]{1, 2};
jagged[2] = new int[]{1, 2, 3};

// 遍历时必须按行取长度，写成 jagged[i].length 而不是固定的列数
for (int i = 0; i < jagged.length; i++) {
    for (int j = 0; j < jagged[i].length; j++) {
        System.out.print(jagged[i][j] + " ");
    }
    System.out.println();
}

正因为是“数组的数组”，int[][] a = b; 只是复制了外层引用，改 a[0][0] 会连带改到 b[0][0]。要真正复制二维数组，需要逐行 clone() 或用循环复制，不能指望一次赋值。

三种常见算法：从手写到理解 JDK

有了数组，最经典的练习就是排序和查找。这里不追求把八种排序都堆一遍，而是选三个最有代表性的手写实现，把“算法思想 → 代码 → 复杂度”这条线走通。

选择排序：每轮选出一个最小值

选择排序（selection sort）的思路非常直白：把数组分成“已排序的前半段”和“未排序的后半段”，每一轮从未排序区找出最小元素，放到已排序区的末尾。第 i 轮需要在 i 与 i+1 ~ n-1 之间比较，共 n-1-i 次；累加起来比较次数为 \((n-1)+(n-2)+\dots+1=\frac{n(n-1)}{2}\)，时间复杂度为 \(O(n^2)\)。

import java.util.Arrays;

public class SelectSortDemo {

    public static void selectionSort(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) {
            int minIndex = i;                       // 先假设 i 就是最小值的下标
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;                   // 只记录下标，不急着交换
                }
            }
            if (minIndex != i) {                    // 确实找到了更小的，才交换
                int temp = arr[i];
                arr[i] = arr[minIndex];
                arr[minIndex] = temp;
            }
        }
    }

    public static void main(String[] args) {
        int[] arr = {70, 80, 31, 37, 10, 1, 48, 60, 33, 80};
        selectionSort(arr);
        System.out.println(Arrays.toString(arr));
        // [1, 10, 31, 33, 37, 48, 60, 70, 80, 80]
    }
}

请注意这里只用一个临时变量做交换，并且把交换放在内层循环之外。有些教材把交换写在内层循环里，一轮下来可能交换很多次，效率更差。还有教材用异或交换（a ^= b; b ^= a; a ^= b;）来省一个临时变量，但当两个下标指向同一元素时，异或会把它清零，属于炫技而危险的写法，一律不要用。

冒泡排序：相邻比较，大的往后漂

冒泡排序（bubble sort）每轮从头开始比较相邻的两个元素，顺序不对就交换，一轮结束后最大值必然“冒”到末尾。第 i 轮只需比较到 n-1-i 即可。它和选择排序时间复杂度同为 \(O(n^2)\)，但交换次数通常更多。

import java.util.Arrays;

public class BubbleSortDemo {

    public static void bubbleSort(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) {
            boolean swapped = false;                    // 本轮是否发生过交换
            // 后面的 i 个元素已经有序，不必再比
            for (int j = 0; j < arr.length - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {              // 相邻比较
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true;
                }
            }
            if (!swapped) {                             // 本轮一次都没换，说明已经有序
                break;
            }
        }
    }

    public static void main(String[] args) {
        int[] arr = {5, 1, 7, 3, 1, 6, 9, 4};
        bubbleSort(arr);
        System.out.println(Arrays.toString(arr));
        // [1, 1, 3, 4, 5, 6, 7, 9]
    }
}

swapped 这个标记很有价值：对已经有序或接近有序的数组，它能让冒泡排序最好情况降到 \(O(n)\)。这也是“算法实现”和“算法思想”之间的差距——同样的思路，加上一点判断就能大幅改善实际表现。

二分查找：有序数组上的折半搜索

如果数组已经有序，就不必从头一个个找。二分查找（binary search）每次拿中间元素与目标值比较：相等就命中；目标更小，说明答案只可能在左半段；更大则只可能在右半段。每比较一次，搜索范围减半，最多比较 \(\lceil\log_2 n\rceil\) 次，时间复杂度 \(O(\log n)\)。

public class BinarySearchDemo {

    /**
     * 在升序数组 a 中查找 key。
     * @return 找到时返回下标；未找到时返回 -(应插入位置) - 1
     */
    public static int binarySearch(int[] a, int key) {
        int low = 0;
        int high = a.length - 1;
        while (low <= high) {
            int mid = (low + high) >>> 1;   // 无符号右移一位，等价于 /2
            if (a[mid] == key) {
                return mid;
            } else if (a[mid] < key) {
                low = mid + 1;                  // 答案在右半段
            } else {
                high = mid - 1;                 // 答案在左半段
            }
        }
        return -(low + 1);                      // 未找到，low 就是应插入位置
    }

    public static void main(String[] args) {
        int[] a = {1, 3, 5, 7, 9, 11, 13};
        System.out.println(binarySearch(a, 7));    // 3
        System.out.println(binarySearch(a, 8));    // -5，8 应插在下标 4
    }
}

有两个细节要记住。一是循环条件必须是 low <= high（相等时还要比一次），写成 < 会漏掉只剩一个元素的情况。二是这里用无符号右移 >>> 1 而不是 / 2，这样即使 low + high 因溢出变成负数，右移结果依然是正确的非负数。当然，low + (high - low) / 2 也是同样安全且更易读的写法。

复杂度速查

算法平均时间最好 / 最坏空间是否稳定
选择排序\(O(n^2)\)\(O(n^2)\) / \(O(n^2)\)\(O(1)\)不稳定
冒泡排序\(O(n^2)\)\(O(n)\) / \(O(n^2)\)\(O(1)\)稳定
二分查找\(O(\log n)\)\(O(1)\) / \(O(\log n)\)\(O(1)\)—

这里的“稳定”指值相等的元素在排序后是否保持原有相对顺序。选择排序因为会把远处的元素直接换到前面，无法保证这一点；冒泡排序只在相邻元素逆序时才交换，所以稳定。

Arrays 工具类：生产代码真正用到的部分

理解了原理之后就该知道：实际开发不要手写排序。java.util.Arrays 提供了经过大量优化的数组工具方法，下面这些是最常用的。

import java.util.Arrays;

public class ArraysDemo {
    public static void main(String[] args) {
        int[] a = {5, 2, 9, 1, 5, 6};

        // 1. 排序：默认升序
        Arrays.sort(a);
        System.out.println(Arrays.toString(a));       // [1, 2, 5, 5, 6, 9]

        // 2. 二分查找：必须先在同一个数组上排好序，否则结果无意义
        System.out.println(Arrays.binarySearch(a, 6));  // 4
        System.out.println(Arrays.binarySearch(a, 3));  // -3：3 应插在下标 2

        // 3. 复制：copyOf 多出的位置补默认值
        int[] b = Arrays.copyOf(a, 3);
        System.out.println(Arrays.toString(b));       // [1, 2, 5]
        int[] c = Arrays.copyOf(a, 8);
        System.out.println(Arrays.toString(c));       // [1, 2, 5, 5, 6, 9, 0, 0]

        // 4. 定范围复制：含头不含尾
        int[] d = Arrays.copyOfRange(a, 1, 4);
        System.out.println(Arrays.toString(d));       // [2, 5, 5]

        // 5. 填充
        int[] e = new int[4];
        Arrays.fill(e, 7);
        System.out.println(Arrays.toString(e));       // [7, 7, 7, 7]

        // 6. 比较内容：Arrays.equals 逐个比较元素，不要用 ==
        System.out.println(Arrays.equals(new int[]{1, 2}, new int[]{1, 2}));  // true

        // 7. 转字符串：直接打印数组只会得到类似 [I@1b6d3586 的地址串
        System.out.println(Arrays.toString(a));
    }
}

Arrays.sort 内部并不是同一种算法。对 int[]、long[] 等基本类型数组，它使用双轴快速排序（Dual-Pivot Quicksort，Java 7 起），因为这类元素不需要比较对象，速度最快。对 Integer[]、String[] 等对象数组，它使用 TimSort（归并排序的改进版），因为归并排序是稳定的，能保留相等元素的原有顺序。这也提醒一件事：两种重载的稳定性不同，需要稳定性时应当使用对象数组。

import java.util.Arrays;
import java.util.Comparator;

// 降序：基本类型不能直接用 Comparator，先装箱再指定比较器
Integer[] boxed = {5, 2, 9, 1};
Arrays.sort(boxed, Comparator.reverseOrder());
System.out.println(Arrays.toString(boxed));   // [9, 5, 2, 1]

// 自定义规则：按字符串长度排序
String[] words = {"java", "c", "python", "go"};
Arrays.sort(words, Comparator.comparingInt(String::length));
System.out.println(Arrays.toString(words));   // [c, go, java, python]

另外 Arrays.asList(...) 可以把数组转成 List，方便调用集合的方法。但要特别注意，它返回的是固定长度的视图，调用 add / remove 会抛 UnsupportedOperationException；需要可变列表时，得再包一层 new ArrayList<>(...)。

常见坑与小结

  • 越界：ArrayIndexOutOfBoundsException 几乎都来自把循环上界写成了 <= arr.length，正确写法是 < arr.length。
  • 打印数组：System.out.println(arr) 输出的是对象哈希，请用 Arrays.toString(arr)；二维数组要用 Arrays.deepToString(arr)。
  • 比较数组：== 比的是引用地址，元素内容相同也不会返回 true，要用 Arrays.equals。
  • 对未排序数组做二分：Arrays.binarySearch 不校验有序性，结果会静默错误，不抛异常。
  • 把 binarySearch 的负值当“没找到”随便判断：它同时编码了插入位置，判断“是否找到”应当写 index >= 0。

本章从“内存连续”这一个特性出发，串起了数组的声明、遍历、二维结构、三种基础算法和 Arrays 工具类。你应当记住三件事：数组长度不可变、下标从 0 开始、越界即异常。手写排序是为了理解复杂度，工程里请直接用 Arrays.sort。二分查找的前提是有序，而它的返回值里藏着插入位置。下一步学集合框架时你会看到，ArrayList 本质上就是“会自动扩容的数组”，而 HashMap 用数组加链表解决散列冲突——数组是一切容器的地基。
