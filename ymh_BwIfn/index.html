Jenkins配置

插件安装

系统管理 → 插件管理 → 可选插件 → 搜索要安装的插件（gitlab hook-plugin 和 gitlab-plugin）
如果找不到上面两个插件，安装gitlab和gitlab hook即可

gitlab配置

打开要关联 Jenkins 项目的设置选项，找到 Webhooks 选项，把 Jenkins 中的项目触发器 URL 以及 Secret token 配置到 GitLab 的 Webhooks 选项中。
