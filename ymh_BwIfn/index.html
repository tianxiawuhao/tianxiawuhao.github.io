gitlab提交代码自动触发Jenkins构建操作

Posted on 2022-06-16，1 min read

本文记录如何把 GitLab 与 Jenkins 关联起来：向 GitLab 推送代码后由 Webhook 通知 Jenkins，从而自动触发构建。

Jenkins 配置

插件安装

系统管理 → 插件管理 → 可选插件 → 搜索要安装的插件（gitlab-plugin 和 gitlab hook-plugin）。如果找不到上面两个插件，安装 gitlab 和 gitlab hook 即可。

注意：gitlab hook-plugin 已废弃，目前的集成能力由 gitlab-plugin 提供。安装后在任务配置中勾选 “Build when a change is pushed to GitLab”，页面会给出 GitLab CI Service URL 和 Secret token，把它们填到 GitLab 的 Webhooks 中即可。

创建测试项目

GitLab 配置

打开要关联 Jenkins 项目的设置选项，找到 Webhooks 选项，把 Jenkins 中的项目触发器 URL 以及 Secret token 配置到 GitLab 的 Webhooks 选项中。URL 填 Jenkins 给出的触发器地址，Secret token 必须与 Jenkins 任务里的一致，否则请求会被拒绝。

验证效果

在 GitLab 的 Webhook 列表中点击 Test，测试 Jenkins 会不会自动构建。返回 HTTP 200 说明这次 Webhook 调用已经被 Jenkins 成功接收。

下面我们去到Jenkins中看下是否有构建历史

再手动 push 代码到 GitLab，验证是否会自动触发 Jenkins 的构建任务：在服务器上向远程 GitLab 分支推送文件，如果 Jenkins 的构建历史中出现了这次 push 触发的构建记录，就说明 Webhook 已经生效。
