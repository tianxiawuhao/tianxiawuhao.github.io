Centos7安装Harbor

Posted on 2022-11-29，4 min read

Harbor 是一个开源的容器镜像仓库（Registry），由 VMware 发起、现为 CNCF 毕业项目。它在 Docker Registry 的基础上增加了 Web 管理界面、基于角色的访问控制、镜像复制与漏洞扫描等能力，因此安装前必须先有 Docker 环境，同时再装好 docker-compose。

Docker 的安装可参考：CentOS 7 安装 Docker 详细步骤；docker-compose 也需要提前安装好。

下面按「下载安装包 → 解压部署 → 修改配置 → prepare/install → 验证」的顺序，记录一次 Harbor 离线安装的完整过程。

一、Harbor 的离线安装

1、下载 Harbor 的离线安装包：

下载地址：https://github.com/goharbor/harbor/releases

我下载的是当时的最新版 v1.10.10。Harbor 2.x 之后的版本在界面和部分命令上有所变化，但「离线包 + docker-compose 部署」的整体流程仍然一致，实际操作请以官方文档为准。

2、上传并解压到 /usr/local/目录下：

[root@node1 ~]# tar -zxvf harbor-offline-installer-v1.10.10.tgz 
 
[root@node1 ~]# mv harbor /usr/local/
[root@node1 ~]# cd /usr/local/harbor/
[root@node1 harbor]# ls
common.sh  harbor.v1.10.10.tar.gz  harbor.yml  install.sh  LICENSE  prepare

3、修改harbor的核心配置文件：

[root@node1 harbor]# vim harbor.yml
## 唯一必须修改项
hostname: 10.206.73.155  #如果有计划好的域名，可以直接使用域名
 
# http related config
http:
  # port for http, default is 80. If https enabled, this port will redirect to https port
  port: 80
 
# 因为我暂时不需要https访问，所以https的配置去除
#https:
  #port: 443
  #certificate: /your/certificate/path
  #private_key: /your/private/key/path
 
harbor_admin_password: Harbor12345 #需要修改

4、检查并安装：

# 检查
./prepare
# 安装
./install

如果碰到 iptables 相关的 error，通常是 firewalld 的规则拦截了 Harbor 容器之间的转发。可以先关闭 firewalld 并重启 docker 服务；生产环境更稳妥的做法是按需放行 Harbor 使用的端口，而不是直接关掉防火墙。

systemctl stop firewalld
service docker restart

5、查看、启动、停止：

在harbor目录下使用docker-compose命令：

6、通过yml中配置的ip+port，以及admin的账号密码访问Harbor：

补充一、内部使用 Harbor 时只有 IP 和端口、没有域名怎么办？

先看一个常见的报错：在客户端执行 docker login 或 docker push 时，Docker 会失败并提示如下信息。

Error response from daemon: Get https://10.206.73.155/v2/: dial tcp 10.206.73.155:443: connect: connection refused

原因是：harbor.yml 中只开放了 HTTP 的 80 端口，而 Docker 客户端默认按 HTTPS（443 端口）访问仓库，连接自然被拒绝。内网环境通常没有域名和证书，最省事的做法就是把该地址声明为「非安全仓库」（insecure registry）。需要提醒的是，这种方式只适合内网自建仓库；如果仓库要跨公网访问，仍应配置域名与 HTTPS 证书。整个排查过程如下图：

具体操作是在 Docker 的核心配置文件 /etc/docker/daemon.json 中，把该 IP 加入非安全仓库白名单：

[root@master ~]# vim /etc/docker/daemon.json
{
    "registry-mirrors":[
        "https://otvq3lq9.mirror.aliyuncs.com"
    ],
    "insecure-registries":[
        "10.206.73.155"
    ],
    "max-concurrent-downloads":10,
    "log-driver":"json-file",
    "log-level":"warn",
    "log-opts":{
        "max-size":"50m",
        "max-file":"3"
    },
    "data-root":"/var/lib/docker"
}

重启 docker 守护进程（daemon）和 docker 服务：

[root@node2 ~]# systemctl daemon-reload
[root@node2 ~]# systemctl restart docker
