java基础之一lambda

Posted on 2021-05-07，14 min read

一、引言

java8最大的特性就是引入Lambda表达式，即函数式编程，可以将行为进行传递。总结就是：使用不可变值与函数，函数对不可变值进行处理，映射成另一个值。

二、java重要的函数式接口

1、什么是函数式接口

函数式接口是只有一个抽象方法的接口，用作 Lambda 表达式的类型。用 @FunctionalInterface 修饰接口后，编译器会检查它是否恰好只有一个抽象方法，否则编译报错；这个注解并非必须，但写上可以防止后续有人往接口里新增抽象方法而悄悄破坏已有的 Lambda 写法。函数式接口里可以同时存在多个 default 方法和 static 方法，它们都不算抽象方法。

1.1 java8自带的常用函数式接口

函数接口 抽象方法 功能 参数 返回类型 示例
Predicate test(T t) 判断真假 T boolean 金刚的身高大于185cm吗？
Consumer accept(T t) 消费消息 T void 输出一个值
Function R apply(T t) 将T映射为R（转换功能） T R 获得student对象的名字
Supplier T get() 生产消息 None T 工厂方法
UnaryOperator T apply(T t) 一元操作 T T 逻辑非（!）
BinaryOperator apply(T t, U u) 二元操作 (T，T) (T) 求两个数的乘积（*） 
public class Test {
    public static void main(String[] args) {
        Predicate<Integer> predicate = x -> x > 185;
        Student student = new Student("金刚", 23, 175);
        System.out.println("金刚的身高高于185吗？：" + predicate.test(student.getStature()));

        Consumer<String> consumer = System.out::println;
        consumer.accept("消费消息，输出一个值");

        Function<Student, String> function = Student::getName;
        String name = function.apply(student);
        System.out.println(name);

        Supplier<Integer> supplier = () -> Integer.valueOf(BigDecimal.TEN.toString());
        System.out.println(supplier.get());

        UnaryOperator<Boolean> unaryOperator = flag -> !flag;
        Boolean applied = unaryOperator.apply(true);
        System.out.println(applied);

        BinaryOperator<Integer> operator = (x, y) -> x * y;
        Integer integer = operator.apply(2, 3);
        System.out.println(integer);

        test(() -> "我是一个演示的函数式接口");
    }

    /**
     * 演示自定义函数式接口使用
     *
     * @param worker
     */
    public static void test(Worker worker) {
        String work = worker.work();
        System.out.println(work);
    }

    @FunctionalInterface
    public interface Worker {
        String work();
    }
}
//金刚的身高高于185吗？：false
//消费消息，输出一个值
//金刚
//10
//false
//6
//我是一个演示的函数式接口

以上演示了内置函数式接口的用法，以及自定义一个函数式接口并使用的方式。下面我们看看 Java 8 如何把函数式接口封装到流中，从而更高效地处理集合。

上面的 System.out::println、Student::getName 这种写法称为方法引用，它是 Lambda 的语法糖：当 Lambda 体只是「调用一个已经存在的方法」时，就可以直接把方法的名字拿来用。方法引用共有四种形式：

形式写法等价的 Lambda说明
静态方法引用Integer::parseIntx -> Integer.parseInt(x)调用某个类的静态方法
绑定实例方法引用System.out::printlnx -> System.out.println(x)调用某个具体对象的方法
未绑定实例方法引用String::lengths -> s.length()第一个参数作为方法的调用者
构造方法引用Student::new(name, age) -> new Student(name, age)参数列表要与构造器匹配

写 ClassName::methodName 时后面不需要括号，因为方法引用描述的是「方法本身」，而不是方法的调用结果。

示例：本篇所有示例都基于以下三个类。OutstandingClass：班级；Student：学生；SpecialityEnum：特长。

1.2 惰性求值与及早求值

惰性求值：只描述Stream，操作的结果也是Stream，这样的操作称为惰性求值。 惰性求值可以像建造者模式一样链式使用，最后再使用及早求值得到最终结果。

及早求值：得到最终的结果而不是Stream，这样的操作称为及早求值。

换个更直观的说法：惰性求值的操作只是把「要做什么」记录到流水线上，只有遇到及早求值操作时，整条流水线才会真正开始执行。下面这段代码因为没有任何及早求值操作，运行时不会打印任何内容：

Stream.of("a", "b", "c")
      .filter(s -> {
          System.out.println("filter: " + s); // 不会执行
          return true;
      });
// 加上及早求值操作后才会触发上面的逻辑
// long n = Stream.of("a", "b", "c").filter(s -> true).count();

惰性求值还带来了短路的可能：anyMatch、findFirst 这类操作只要拿到结果就停止处理剩余元素，因此 filter、map 里的代码不一定会对每个元素都执行。这也是 Stream 比手写循环更「聪明」的地方。

2、常用的流

2.1 collect(Collectors.toList())

将流转换为list。还有toSet()，toMap()等。及早求值。

public class TestCase {
    public static void main(String[] args) {
        List<Student> studentList = Stream.of(new Student("路飞", 22, 175),
                new Student("红发", 40, 180),
                new Student("白胡子", 50, 185)).collect(Collectors.toList());
        System.out.println(studentList);
    }
}
//输出结果
//[Student{name='路飞', age=22, stature=175, specialities=null}, 
//Student{name='红发', age=40, stature=180, specialities=null}, 
//Student{name='白胡子', age=50, stature=185, specialities=null}]

//转成map
public Map<Long, String> getIdNameMap(List<Account> accounts) {
    return accounts.stream().collect(Collectors.toMap(Account::getId, Account::getUsername));
}
//收集成实体本身map
public Map<Long, Account> getIdAccountMap(List<Account> accounts) {
    return accounts.stream().collect(Collectors.toMap(Account::getId, account -> account));
}
//account -> account是一个返回本身的lambda表达式，其实还可以使用Function接口中的一个默认方法代替，使整个方法更简洁优雅：
public Map<Long, Account> getIdAccountMap(List<Account> accounts) {
    return accounts.stream().collect(Collectors.toMap(Account::getId, Function.identity()));
}
//重复key的情况，下面name可能重复
public Map<String, Account> getNameAccountMap(List<Account> accounts) {
    return accounts.stream().collect(Collectors.toMap(Account::getUsername, Function.identity()));
}
//toMap有个重载方法，可以传入一个合并的函数来解决key冲突问题
public Map<String, Account> getNameAccountMap(List<Account> accounts) {
    return accounts.stream().collect(Collectors.toMap(Account::getUsername, Function.identity(), (key1, key2) -> key2));
}
//按id分组
Map<Long, List<Account>> map = accounts.stream().collect(Collectors.groupingBy(Account::getId));
//指定具体收集的map
public Map<String, Account> getNameAccountMap(List<Account> accounts) {
    return accounts.stream().collect(Collectors.toMap(Account::getUsername, Function.identity(), (key1, key2) -> key2, LinkedHashMap::new));
}

2.2 filter

顾名思义，起过滤筛选的作用。内部就是Predicate接口。惰性求值。

比如我们要筛选出身高小于 180 的同学。

public class TestCase {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>(3);
        students.add(new Student("路飞", 22, 175));
        students.add(new Student("红发", 40, 180));
        students.add(new Student("白胡子", 50, 185));

        List<Student> list = students.stream()
            .filter(stu -> stu.getStature() < 180)
            .collect(Collectors.toList());
        System.out.println(list);
    }
}
//输出结果
//[Student{name='路飞', age=22, stature=175, specialities=null}]

2.3 map

转换功能，内部就是Function接口。惰性求值

public class TestCase {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>(3);
        students.add(new Student("路飞", 22, 175));
        students.add(new Student("红发", 40, 180));
        students.add(new Student("白胡子", 50, 185));

        List<String> names = students.stream().map(student -> student.getName())
                .collect(Collectors.toList());
        System.out.println(names);
    }
}
//输出结果
//[路飞, 红发, 白胡子]

例子中将student对象转换为String对象，获取student的名字。

2.4 flatMap

将多个Stream合并为一个Stream。惰性求值

public class TestCase {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>(3);
        students.add(new Student("路飞", 22, 175));
        students.add(new Student("红发", 40, 180));
        students.add(new Student("白胡子", 50, 185));

        List<Student> studentList = Stream.of(students,
                asList(new Student("艾斯", 25, 183),
                        new Student("雷利", 48, 176)))
                .flatMap(students1 -> students1.stream()).collect(Collectors.toList());
        System.out.println(studentList);
    }
}
//输出结果
//[Student{name='路飞', age=22, stature=175, specialities=null}, 
//Student{name='红发', age=40, stature=180, specialities=null}, 
//Student{name='白胡子', age=50, stature=185, specialities=null}, 
//Student{name='艾斯', age=25, stature=183, specialities=null},
//Student{name='雷利', age=48, stature=176, specialities=null}]

调用Stream.of的静态方法将两个list转换为Stream，再通过flatMap将两个流合并为一个。

2.5 max和min

我们经常会在集合中求最大或最小值，使用流就很方便。及早求值。

public class TestCase {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>(3);
        students.add(new Student("路飞", 22, 175));
        students.add(new Student("红发", 40, 180));
        students.add(new Student("白胡子", 50, 185));

        Optional<Student> max = students.stream()
            .max(Comparator.comparing(stu -> stu.getAge()));
        Optional<Student> min = students.stream()
            .min(Comparator.comparing(stu -> stu.getAge()));
        //判断是否有值
        if (max.isPresent()) {
            System.out.println(max.get());
        }
        if (min.isPresent()) {
            System.out.println(min.get());
        }
    }
}
//输出结果
//Student{name='白胡子', age=50, stature=185, specialities=null}
//Student{name='路飞', age=22, stature=175, specialities=null}

max、min接收一个Comparator（例子中使用java8自带的静态函数，只需要传进需要比较值即可。）并且返回一个Optional对象，该对象是java8新增的类，专门为了防止null引发的空指针异常。可以使用max.isPresent()判断是否有值；可以使用max.orElse(new Student())，当值为null时就使用给定值；也可以使用max.orElseGet(() -> new Student());这需要传入一个Supplier的lambda表达式。

2.6 count

统计功能，一般都是结合filter使用，因为先筛选出我们需要的再统计即可。及早求值

public class TestCase {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>(3);
        students.add(new Student("路飞", 22, 175));
        students.add(new Student("红发", 40, 180));
        students.add(new Student("白胡子", 50, 185));

        long count = students.stream().filter(s1 -> s1.getAge() < 45).count();
        System.out.println("年龄小于45岁的人数是：" + count);
    }
}
//输出结果
//年龄小于45岁的人数是：2

2.7 reduce

reduce 操作可以实现从一组值中生成一个值。上面例子中用到的 count、min 和 max 方法，因为常用而被纳入标准库中；事实上，这些方法本质上都是 reduce 操作。及早求值。

public class TestCase {
    public static void main(String[] args) {
        Integer reduce = Stream.of(1, 2, 3, 4).reduce(0, (acc, x) -> acc+ x);
        System.out.println(reduce);
    }
}
//输出结果
//10

可以看到，reduce 接收了一个初始值为 0 的累加器，依次取出值与累加器相加，最后累加器的值就是最终的结果。

三、高级集合类及收集器

3.1 转换成值

收集器是一种通用的、从流生成复杂值的结构。只要将它传给 collect 方法，所有流就都可以使用它了。标准类库已经提供了一些有用的收集器，以下示例代码中的收集器都是从 java.util.stream.Collectors 类中静态导入的。

public class CollectorsTest {
    public static void main(String[] args) {
        List<Student> students1 = new ArrayList<>(3);
        students1.add(new Student("路飞", 23, 175));
        students1.add(new Student("红发", 40, 180));
        students1.add(new Student("白胡子", 50, 185));

        OutstandingClass ostClass1 = new OutstandingClass("一班", students1);
        //复制students1，并移除一个学生
        List<Student> students2 = new ArrayList<>(students1);
        students2.remove(1);
        OutstandingClass ostClass2 = new OutstandingClass("二班", students2);
        //将ostClass1、ostClass2转换为Stream
        Stream<OutstandingClass> classStream = Stream.of(ostClass1, ostClass2);
        OutstandingClass outstandingClass = biggestGroup(classStream);
        System.out.println("人数最多的班级是：" + outstandingClass.getName());

        System.out.println("一班平均年龄是：" + averageNumberOfStudent(students1));
    }

    /**
     * 获取人数最多的班级
     */
    private static OutstandingClass biggestGroup(Stream<OutstandingClass> outstandingClasses) {
        return outstandingClasses.collect(
                maxBy(comparing(ostClass -> ostClass.getStudents().size())))
                .orElseGet(OutstandingClass::new);
    }

    /**
     * 计算平均年龄
     */
    private static double averageNumberOfStudent(List<Student> students) {
        return students.stream().collect(averagingInt(Student::getAge));
    }
}
//输出结果
//人数最多的班级是：一班
//一班平均年龄是：37.666666666666664

maxBy或者minBy就是求最大值与最小值。

3.2 转换成块

常用的流操作是将其分解成两个集合，Collectors.partitioningBy帮我们实现了，接收一个Predicate函数式接口。

将示例学生分为会唱歌与不会唱歌的两个集合。

public class PartitioningByTest {
    public static void main(String[] args) {
        //省略List<student> students的初始化
        Map<Boolean, List<Student>> listMap = students.stream().collect(
            Collectors.partitioningBy(student -> student.getSpecialities().
                                      contains(SpecialityEnum.SING)));
    }
}

3.3 数据分组

数据分组是一种更自然的分割数据操作，与将数据简单分成 true 和 false 两部分不同，它可以用任意值对数据分组，Collectors.groupingBy 接收一个 Function 做转换。

例如把形状按类型分组：圆形一组、三角形一组、正方形一组——groupingBy 的分组键可以是任意表达式。

例子：根据学生第一个特长进行分组

public class GroupingByTest {
    public static void main(String[] args) {
        //省略List<student> students的初始化
         Map<SpecialityEnum, List<Student>> listMap = 
             students.stream().collect(
             Collectors.groupingBy(student -> student.getSpecialities().get(0)));
    }
}

Collectors.groupingBy与SQL 中的 group by 操作是一样的。

3.4 字符串拼接

如果要将所有学生的名字拼接起来，怎么做呢？通常只能创建一个 StringBuilder 循环拼接；而使用 Stream 的 Collectors.joining() 则简单容易。

public class JoiningTest {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>(3);
        students.add(new Student("路飞", 22, 175));
        students.add(new Student("红发", 40, 180));
        students.add(new Student("白胡子", 50, 185));

         String names = students.stream()
             .map(Student::getName).collect(Collectors.joining(",","[","]"));
        System.out.println(names);
    }
}
//输出结果
//[路飞,红发,白胡子]

joining接收三个参数，第一个是分界符，第二个是前缀符，第三个是结束符。也可以不传入参数Collectors.joining()，这样就是直接拼接。

四、Lambda 的语法与实现细节

4.1 Lambda 的语法形式

Lambda 的完整形态是 (参数列表) -> { 方法体 }，实际使用时可以按下面的规则省略：

  • 参数类型可以省略，编译器会根据函数式接口的抽象方法推断出类型；
  • 只有一个参数时，参数外面的圆括号可以省略，例如 x -> x + 1；
  • 方法体只有一条表达式时，大括号和 return 都可以省略，表达式的结果就是返回值；
  • 方法体有多条语句时必须使用大括号，有返回值时要显式写 return；
  • 没有参数时不能省略括号，例如 () -> new Student()。

需要特别注意的是，Lambda 的类型完全由上下文决定：同一个 x -> x + 1 赋给 Function<Integer, Integer> 或 UnaryOperator<Integer> 都是成立的，因此 Lambda 不能脱离目标类型单独存在，也不能写 Object o = x -> x; 这样的代码。

4.2 变量捕获与 effectively final

Lambda 可以直接使用外层的局部变量，但有一个硬性限制：被捕获的局部变量必须是 final 或 effectively final（事实不可变），也就是初始化之后没有再被赋值过，哪怕赋值语句写在 Lambda 后面也不允许。

public void demo() {
    int count = 0;                        // 之后没有被修改，属于 effectively final
    Runnable r = () -> System.out.println(count);
    r.run();                              // 输出 0

    // count++;                           // 一旦取消注释，上面的 Lambda 就会编译报错
}

这样要求的原因是：Lambda 捕获的是变量的值（复制一份），而不是变量本身。局部变量保存在栈帧上，Lambda 可能在方法返回之后才被执行，如果允许修改就会带来语义上的混乱；而实例字段和静态字段不受这个限制，因为它们捕获的是 this 或类引用，读写的始终是堆上的同一份数据。

4.3 与匿名内部类的区别

Lambda 和匿名内部类都能实现「把一段行为当作参数传递」，但两者并不等价，最典型的差别是 this 的含义：

public class ThisDemo {
    private String name = "外部类";

    public void anonymous() {
        Runnable r = new Runnable() {
            private String name = "匿名内部类";
            @Override
            public void run() {
                System.out.println(this.name);   // 匿名内部类自己的 name
            }
        };
        r.run();
    }

    public void lambda() {
        Runnable r = () -> System.out.println(this.name); // this 就是 ThisDemo 实例
        r.run();
    }
}
  • 匿名内部类会生成一个真实的类文件（形如 Outer$1.class），this 指向匿名内部类实例，因此它可以定义自己的字段，也可以调用接口的默认方法；Lambda 不会额外生成类文件，this 指向外层实例，所以不能在 Lambda 内部定义同名字段来「遮蔽」外层字段。
  • 匿名内部类可以写在任意可以写表达式的位置；Lambda 只能用于函数式接口，不能用于抽象类，也不能用于有多个抽象方法的接口。
  • Lambda 内部无法调用接口的默认方法（因为它没有自己的实例），这种情况下只能改回匿名内部类。
