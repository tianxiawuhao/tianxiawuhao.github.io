easyExcel

Posted on 2022-03-10，22 min read

EasyExcel 是阿里已开源的 Excel 处理工具，它没有重写 POI，而是把 POI 的流式能力（读用 SAX 事件模型、写用 SXSSF 行窗口）包装成了可以用注解描述的 API。因此它最大的价值不是“写得快”，而是“写得省”：内存占用与文件行数基本无关。

它的模型分三层，读写对称：一个 Excel（ReadWorkbook / WriteWorkbook）包含若干工作表（ReadSheet / WriteSheet），一张工作表里又可以放多个表格（WriteTable）。参数会沿着这三层向下继承：层级上没设置的，自动取上一级的值。

接下来的内容分为“读”和“写”两大块，每块都先看注解、再看参数，最后给出可直接编译运行的完整示例。篇末还有一节“常见坑与最佳实践”，把多数人踩过的坑集中列了一遍。

本文示例基于 EasyExcel 3.x（3.1.1 及以上）。EasyExcel 1.x 的 ExcelUtil 写法（带 Sheet、BaseRowModel、readBySax 的那一套）在 3.x 里已经被删除，直接拷贝会编译失败，详见后文“从 1.x 的 ExcelUtil 迁移到 3.x”一节。

读Excel

注解

使用注解很简单，只要在对应的实体类上面加上注解即可。

ExcelProperty

用于 Excel 与实体类的字段匹配，参数如下：

名称 默认值 描述
value 空 用于匹配excel中的头，必须全匹配,如果有多行头，会匹配最后一行头
order Integer.MAX_VALUE 优先级高于value，会根据order的顺序来匹配实体和excel中数据的顺序
index -1 优先级高于value和order，会根据index直接指定到excel中具体的哪一列
converter 自动选择 指定当前字段用什么转换器，默认会自动选择。读的情况下只要实现com.alibaba.excel.converters.Converter#convertToJavaData(com.alibaba.excel.converters.ReadConverterContext<?>) 方法即可

三个属性的优先级为 index > order > value：按下标定位最稳定，按表头文本匹配最灵活。一般建议只用其中一种，混用时容易出现“字段没丢，但值错位”的情况。

public class DemoData {
    // 按下标定位第 0 列，最稳，表头改名也不影响
    @ExcelProperty(index = 0)
    private String name;

    // 按表头文本匹配，支持多行表头（会匹配最后一行）
    @ExcelProperty("姓名")
    private String nickName;

    // order 控制列顺序：多个字段都写 order 时按 order 升序排列
    @ExcelProperty(value = "\u5e74\u9f84", order = 2)
    private Integer age;

    // 自定义转换器：读 excel 文本 -> Java 枚举
    @ExcelProperty(value = "\u72b6\u6001", converter = StatusConverter.class)
    private Status status;

    // 完全不参与读写
    @ExcelIgnore
    private String internalRemark;
}

注意：value 默认为空，不写 value 也不写 index 时，该字段仍会参与匹配，只是没有表头依据，实际顺序由字段声明顺序决定。

ExcelIgnore

默认所有字段都会和excel去匹配，加了这个注解会忽略该字段。读写都生效，读时表里有这一列也不会被映射到对象上。

ExcelIgnoreUnannotated

默认不加ExcelProperty 的注解的都会参与读写，加了不会参与。它是加在类上的，适合“只导出我明确标记过的字段”这种场景。

DateTimeFormat

日期转换，用String去接收excel日期格式的数据会调用这个注解,参数如下：

名称 默认值 描述
value 空 参照java.text.SimpleDateFormat书写即可
use1904windowing 自动选择 excel中时间是存储1900年起的一个双精度浮点数，但是有时候默认开始日期是1904，所以设置这个值改成默认1904年开始

NumberFormat

数字转换，用String去接收excel数字格式的数据会调用这个注解。

日期、数字与枚举转换

Excel 单元格只有字符串、数值、日期、布尔几种基本类型，日期在底层就是一个双精度浮点数。因此“Excel 与 Java 怎么互转”是最常见的需求，也是最容易出错的地方。

场景 写法 说明
日期字符串↔Date @DateTimeFormat("yyyy-MM-dd HH:mm:ss") 参照 SimpleDateFormat 书写，写入时按此格式输出，读取时按此格式解析
金额与小数位 @NumberFormat("#,##0.00") 参照 DecimalFormat；写入时也会作为单元格格式生效
枚举 converter = XxxConverter.class EasyExcel 不认识业务枚举，必须自定义转换器
单元格原始值 用 String 接收，配 @ExcelProperty(index = n) 不想让 EasyExcel 做类型推断时最保险

一个自定义枚举转换器长这样（读写共用一个类）：

import com.alibaba.excel.converters.Converter;
import com.alibaba.excel.converters.ReadConverterContext;
import com.alibaba.excel.converters.WriteConverterContext;
import com.alibaba.excel.enums.CellDataTypeEnum;
import com.alibaba.excel.metadata.data.WriteCellData;

public class StatusConverter implements Converter<Status> {

    @Override
    public Class<Status> supportJavaTypeKey() {
        return Status.class;
    }

    @Override
    public CellDataTypeEnum supportExcelTypeKey() {
        return CellDataTypeEnum.STRING;
    }

    /** 读：Excel 单元格 -> Java 枚举 */
    @Override
    public Status convertToJavaData(ReadConverterContext<?> context) {
        String value = context.getReadCellData().getStringValue();
        for (Status status : Status.values()) {
            if (status.getLabel().equals(value)) {
                return status;
            }
        }
        return Status.UNKNOWN;
    }

    /** 写：Java 枚举 -> Excel 单元格 */
    @Override
    public WriteCellData<?> convertToExcelData(WriteConverterContext<Status> context) {
        return new WriteCellData<>(context.getValue().getLabel());
    }
}

只需要实现 convertToJavaData 或 convertToExcelData 其一也能编译，但只要这个转换器同时用于读和写，就建议两个方法都实现，否则反向会回退到默认转换器。

读监听器与 doReadSync

EasyExcel 读文件是一行一行回调的，因此它不会把整个文件读进内存。接收数据的方式有两种：

  • 推模式：传入自定义 ReadListener，每读一行调一次 invoke，自己决定何时入库、何时清空缓存。
  • 拉模式：调 doReadSync()，它内部帮你收集数据并一次性返回 List<T>。写法最短，但内存与行数成正比，只适合小文件或工具类脚本。
import com.alibaba.excel.context.AnalysisContext;
import com.alibaba.excel.read.listener.ReadListener;
import com.alibaba.excel.util.ListUtils;
import lombok.extern.slf4j.Slf4j;

import java.util.List;

@Slf4j
public class DemoDataListener implements ReadListener<DemoData> {

    /** 每积攒 100 条就入库一次，防止几万条数据在内存里 OOM */
    private static final int BATCH_COUNT = 100;

    private List<DemoData> cachedDataList = ListUtils.newArrayListWithExpectedSize(BATCH_COUNT);

    private final DemoDataDao demoDataDao;

    /** 监听器是有状态的，每次读取都要 new，所以依赖通过构造方法传入 */
    public DemoDataListener(DemoDataDao demoDataDao) {
        this.demoDataDao = demoDataDao;
    }

    @Override
    public void invoke(DemoData data, AnalysisContext context) {
        cachedDataList.add(data);
        if (cachedDataList.size() >= BATCH_COUNT) {
            saveData();
            // 入库后重新 new 一个，帮助 GC 回收旧引用
            cachedDataList = ListUtils.newArrayListWithExpectedSize(BATCH_COUNT);
        }
    }

    @Override
    public void doAfterAllAnalysed(AnalysisContext context) {
        // 最后一批不足 BATCH_COUNT 的数据也要落库
        if (!cachedDataList.isEmpty()) {
            saveData();
        }
        log.info("所有数据解析完成！");
    }

    @Override
    public void onException(Exception exception, AnalysisContext context) throws Exception {
        // 单行转换失败等异常默认会直接抛出中断整个读取，
        // 这里可以记录日志后继续读，不再 throw
        log.error("解析第 {} 行失败", context.readRowHolder().getRowIndex(), exception);
    }

    private void saveData() {
        demoDataDao.save(cachedDataList);
    }
}

完整的读取调用与常见组合如下：

// 1. 最常用：读第一张表，逐行回调
EasyExcel.read(fileName, DemoData.class, new DemoDataListener(demoDataDao))
        .sheet()
        .doRead();

// 2. 按下标或名字指定工作表，并指定表头行数
EasyExcel.read(fileName, DemoData.class, new DemoDataListener(demoDataDao))
        .sheet(1)
        .headRowNumber(2)
        .doRead();

// 3. 一次读完所有工作表（每张表都会回调同一个监听器）
EasyExcel.read(fileName, DemoData.class, new DemoDataListener(demoDataDao)).doReadAll();

// 4. 不建模型，直接读成 Map：适合表头不固定的临时导入
List<Map<Integer, String>> rows = EasyExcel.read(fileName).sheet().doReadSync();

// 5. 小文件直接拿 List（内存与行数成正比，大文件请用方式 1）
List<DemoData> all = EasyExcel.read(fileName, DemoData.class, new DemoDataListener(demoDataDao))
        .sheet()
        .doReadSync();

常见误区：把监听器交给 Spring 管理（比如加 @Component）。监听器里有缓存列表这种状态，被复用会串数据；正确做法是每次读取 new 一个，把 DAO 通过构造方法传进去。

读 Excel 的常见坑

  • 表头行数写错：headRowNumber 默认是 1。如果 Excel 有标题行、说明行，或者多级表头，真实数据从第 3 行才开始，就必须显式写 headRowNumber(2) 或 (3)。不写的话表头会被当成数据读进来，或者字段全是 null。
  • 多行表头与 value 的对应：@ExcelProperty 的 value 写成数组时表示多级表头，匹配的是最后一行；数组长度要和表头层数一致，否则按 index 或声明顺序兜底，容易错列。
  • 合并单元格：EasyExcel 默认只把值放在合并区域的左上角单元格，其余行是空的。需要把合并区域的值补齐到每一行时，用 extraReadSet 声明要额外读取的内容，或在 invoke 里根据上一行自行回填。
  • 大数据量用 doReadSync 等于白省内存：doReadSync 最终还是把数据堆进一个 List 返回，行数一大就 OOM，请改回监听器分批入库。
  • 表名/表序号笔误：sheetNo 和 sheetName 建议只选一个，都写时以 sheetNo 为准；sheetNo 是下标，从 0 开始，不是 Excel 界面上显示的顺序号。
  • 日期读出来是个数字：底层存的是序列号，给 Date 字段加 @DateTimeFormat，或者改用 String 加 @DateTimeFormat 接收。
  • csv 编码：读 csv 时通过 charset 指定编码，否则中文表头会乱码；xls/xlsx 不需要这个参数。

批量写入与 Sheet 分页

导出几十万行时，最容易犯的错误是先把全部数据查成一个 List 再 doWrite。正确姿势是：一个 ExcelWriter + 分页多次 write，表头只会写一次，数据逐页追加。

import java.io.File;
import java.io.InputStream;
import java.util.Map;

import com.alibaba.excel.EasyExcel;
import com.alibaba.excel.ExcelWriter;
import com.alibaba.excel.write.metadata.WriteSheet;

public class BatchWriteDemo {

    private static final int PAGE_SIZE = 5000;
    private static final int SHEET_MAX_ROWS = 100_000;

    public static void main(String[] args) {
        String fileName = "/tmp/demo/batch.xlsx";
        // 1. 构建 writer：只创建一次，Excel 的写入上下文都在它手里
        ExcelWriter excelWriter = EasyExcel.write(fileName, DemoData.class).build();
        try {
            int pageNo = 0;
            // 2. 每张 sheet 只建一次，后续可以反复 write 到同一张 sheet
            WriteSheet writeSheet = EasyExcel.writerSheet(0, "第1批").build();
            while (true) {
                List<DemoData> page = queryPage(pageNo++, PAGE_SIZE);
                if (page.isEmpty()) {
                    break;
                }
                excelWriter.write(page, writeSheet);
                // 3. 写满一页上限就换一张 sheet，避免单表行数过多
                if (pageNo % (SHEET_MAX_ROWS / PAGE_SIZE) == 0) {
                    int sheetNo = pageNo / (SHEET_MAX_ROWS / PAGE_SIZE);
                    writeSheet = EasyExcel.writerSheet(sheetNo, "第" + (sheetNo + 1) + "批").build();
                }
            }
        } finally {
            // 4. 无论成功失败都要 finish：它负责刷盘、合并临时文件、关闭输出流
            excelWriter.finish();
        }
    }

    private static List<DemoData> queryPage(int pageNo, int pageSize) {
        // 用 limit/offset 或游标分页查询，每次只返回一页，别查全量
        return demoDataDao.selectPage(pageNo * pageSize, pageSize);
    }
}

几个必须记住的规则：

  • 同一个 ExcelWriter 复用到最后。每次 EasyExcel.write(...).sheet().doWrite() 都是一份新工作簿，放在循环里只会不断覆盖文件。
  • write(data, sheet) 可以调用多次，同一张 WriteSheet 的第一页写完后，后面的页只追加数据行，表头不会重复。
  • finish() 必须执行且只执行一次，放在 finally 里。它内部会 flush 临时文件并结束工作簿，不调用的话文件不完整甚至打不开。
  • 顺序是 finish() 在前、关流在后。如果自己 new 了 FileOutputStream 交给 EasyExcel 使用，就不要再在 finish() 之前抢先 close()，否则抛 IOException: Stream closed；autoCloseStream 默认 true，EasyExcel 会负责关流。更稳妥的是直接用 EasyExcel.write(File, ...) 让它自己管流。
  • Web 下载不要手动关 response.getOutputStream()，doWrite 结束后 EasyExcel 已经处理完毕；确实需要自己控制时用 autoCloseStream(Boolean.FALSE)。

写 Excel 的常见坑

  • needHead(false) 时列顺序仍由注解决定：不写表头，列的先后依然由 index、order、字段声明顺序决定。
  • 区分 WriteSheet 与 WriteTable：同一张 sheet 内需要多段彼此独立的表格（各带各的表头）时才用 WriteTable；页面分页追加数据只需复用同一个 WriteSheet。
  • 样式不要逐单元格设置：用 HorizontalCellStyleStrategy、LongestMatchColumnWidthStyleStrategy 或自定义 WriteHandler，否则 POI 样式对象数量暴涨，内存和文件体积都会失控。
  • 长数字被写成科学计数法或丢精度：订单号、身份证号这类值用 String 承接，不要用 Double。
  • 公式单元格：写出公式直接赋字符串 "=SUM(A1:A10)" 即可，但计算值是 Excel 打开时才生成的，代码里读不到。

追加写入已有文件

EasyExcel 不提供“打开已有 xlsx 继续追加”的 API，但可以用模板方式实现：先读出原文件已有的行数，把它作为新数据的起始行，同时关闭表头写出。

public static void append(File file, Class<?> clazz, List<?> data) {
    // 1. 数出原文件的数据行数（不含表头）
    List<?> exists = EasyExcel.read(file, clazz, null).sheet().doReadSync();
    // 2. 把原文件当模板，新数据写在已有内容后面，且不再重复写表头
    ExcelWriter excelWriter = EasyExcel.write(file)
            .withTemplate(file)
            .build();
    try {
        WriteSheet writeSheet = EasyExcel.writerSheet()
                .needHead(Boolean.FALSE)
                .relativeHeadRowIndex(exists.size())
                .build();
        excelWriter.write(data, writeSheet);
    } finally {
        excelWriter.finish();
    }
}

追加写入要先全量读一遍原文件来判断位置，开销不小；导出量很大时，更推荐“分批导出到多个文件”，而不是不断往同一个文件里追加。

与原生 POI 的取舍

一句话总结：只是导入导出业务数据，用 EasyExcel；需要图表、透视表、复杂样式或直接操作底层对象，用 POI。两者并不冲突，EasyExcel 的 WriteHandler、Converter 都能拿到 POI 的 Sheet、Cell、Workbook，可以在需要的地方“下沉”到 POI。

常见坑与最佳实践

  1. 版本别混用：EasyExcel 1.x 的 Sheet、BaseRowModel、EasyExcelFactory.readBySax、ExcelWriter.write1 在 3.x 已全部移除，依赖统一用 3.x，不要照着老博客抄代码。
  2. POI 版本冲突：EasyExcel 3.3.x 依赖 POI 5.2.x，项目里若另有旧版 poi-ooxml（如 3.17、4.1.2），运行时会报 NoSuchMethodError，用 mvn dependency:tree 排掉旧版本。
  3. 监听器、转换器不要交给 Spring 单例管理：它们要么有状态，要么每次读写都需要新建，用构造方法注入依赖即可。
  4. 导出接口要兜住异常：写出过程中抛异常会留下半截文件或半截响应。要么让异常冒泡（Web 场景按 downloadFailedUsingJson 那样重置 response 返回 JSON），要么开启 writeExcelOnException(true) 尽量把已写数据落盘。
  5. 临时文件与磁盘：inMemory(false)（默认）会在系统临时目录写文件，容器里要确认 /tmp 空间充足；inMemory(true) 只是把压力转回堆内存，大导出不要开。
  6. 线程安全：ExcelWriter 不是线程安全的，一个导出任务一个 writer，不要放进线程池共享。
  7. 列宽自适应要谨慎：自动列宽策略需要缓存每列最宽的字符串，超大文件反而吃内存，固定列宽 @ColumnWidth 更稳。

     *
     * @since 2.1.1
     */
    @GetMapping("downloadFailedUsingJson")
    public void downloadFailedUsingJson(HttpServletResponse response) throws IOException {
        // 这里注意 有同学反应使用swagger 会导致各种问题，请直接用浏览器或者用postman
        try {
            response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
            response.setCharacterEncoding("utf-8");
            // 这里URLEncoder.encode可以防止中文乱码 当然和easyexcel没有关系
            String fileName = URLEncoder.encode("测试", "UTF-8").replaceAll("\\+", "%20");
            response.setHeader("Content-disposition", "attachment;filename*=utf-8''" + fileName + ".xlsx");
            // 这里需要设置不关闭流
            EasyExcel.write(response.getOutputStream(), DownloadData.class).autoCloseStream(Boolean.FALSE).sheet("模板")
                .doWrite(data());
        } catch (Exception e) {
            // 重置response
            response.reset();
            response.setContentType("application/json");
            response.setCharacterEncoding("utf-8");
            Map<String, String> map = MapUtils.newHashMap();
            map.put("status", "failure");
            map.put("message", "下载文件失败" + e.getMessage());
            response.getWriter().println(new ObjectMapper().writeValueAsString(map));
        }
    }

     * <p>
     * 1. 创建excel对应的实体对象 参照{@link UploadData}

        }
        return list;
    }

UploadDataListener

import java.util.List;

import com.alibaba.excel.context.AnalysisContext;
import com.alibaba.excel.read.listener.ReadListener;
import com.alibaba.excel.util.ListUtils;
import com.alibaba.fastjson.JSON;

import lombok.extern.slf4j.Slf4j;

/**
 * 模板的读取类
 *
 */
// 有个很重要的点 DemoDataListener 不能被spring管理，要每次读取excel都要new,然后里面用到spring可以构造方法传进去
@Slf4j
public class UploadDataListener implements ReadListener<UploadData> {
    /**
     * 每隔5条存储数据库，实际使用中可以100条，然后清理list ，方便内存回收
     */
    private static final int BATCH_COUNT = 5;
    private List<UploadData> cachedDataList = ListUtils.newArrayListWithExpectedSize(BATCH_COUNT);
    /**
     * 假设这个是一个DAO，当然有业务逻辑这个也可以是一个service。当然如果不用存储这个对象没用。
     */
    private UploadDAO uploadDAO;

    public UploadDataListener() {
        // 这里是demo，所以随便new一个。实际使用如果到了spring,请使用下面的有参构造函数
        uploadDAO = new UploadDAO();
    }

    /**
     * 如果使用了spring,请使用这个构造方法。每次创建Listener的时候需要把spring管理的类传进来
     *
     * @param uploadDAO
     */
    public UploadDataListener(UploadDAO uploadDAO) {
        this.uploadDAO = uploadDAO;
    }

    /**
     * 这个每一条数据解析都会来调用
     *
     * @param data    one row value. Is is same as {@link AnalysisContext#readRowHolder()}
     * @param context
     */
    @Override
    public void invoke(UploadData data, AnalysisContext context) {
        log.info("解析到一条数据:{}", JSON.toJSONString(data));
        cachedDataList.add(data);
        // 达到BATCH_COUNT了，需要去存储一次数据库，防止数据几万条数据在内存，容易OOM
        if (cachedDataList.size() >= BATCH_COUNT) {
            saveData();
            // 存储完成清理 list
            cachedDataList = ListUtils.newArrayListWithExpectedSize(BATCH_COUNT);
        }
    }

    /**
     * 所有数据解析完成了 都会来调用
     *
     * @param context
     */
    @Override
    public void doAfterAllAnalysed(AnalysisContext context) {
        // 这里也要保存数据，确保最后遗留的数据也存储到数据库
        saveData();
        log.info("所有数据解析完成！");
    }

    /**
     * 加上存储数据库
     */
    private void saveData() {
        log.info("{}条数据，开始存储数据库！", cachedDataList.size());
        uploadDAO.save(cachedDataList);
        log.info("存储数据库成功！");
    }
}

ExcelUtil

import com.alibaba.excel.EasyExcel;
import com.alibaba.excel.ExcelWriter;
import com.alibaba.excel.write.metadata.WriteSheet;
import com.alibaba.excel.write.metadata.style.WriteCellStyle;
import com.alibaba.excel.write.metadata.style.WriteFont;
import com.alibaba.excel.write.style.HorizontalCellStyleStrategy;
import lombok.extern.slf4j.Slf4j;
import org.springframework.util.CollectionUtils;
import org.springframework.util.StringUtils;

import java.io.*;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

@Slf4j
public class ExcelUtil {

    private ExcelUtil() {
    }

    /* ------------------------------ 读 ------------------------------ */

    /**
     * 读第一张 sheet 的全部数据，一次性返回
     * 注意：数据全部堆在内存里，只适合小文件；大文件请用分批入库的 ReadListener
     */
    public static List<DemoData> readAll(File file) {
        return EasyExcel.read(file, DemoData.class, null).sheet().doReadSync();
    }

    /**
     * 读指定 sheet，并指定表头占几行
     *
     * @param sheetNo       工作表下标，从 0 开始
     * @param headRowNumber 表头行数，默认 1；有标题行/多级表头时必须显式指定
     */
    public static List<DemoData> readSheet(File file, int sheetNo, int headRowNumber) {
        return EasyExcel.read(file, DemoData.class, null)
                .sheet(sheetNo)
                .headRowNumber(headRowNumber)
                .doReadSync();
    }

    /**
     * 不建模，按行列下标读取；适合表头不固定、只需要搬运数据的场景
     */
    public static List<Map<Integer, String>> readRaw(InputStream inputStream) {
        return EasyExcel.read(inputStream).sheet().doReadSync();
    }

    /* ------------------------------ 写 ------------------------------ */

    /**
     * 写单张 sheet，数据量不大时可用
     */
    public static void writeSingleSheet(File file, List<?> data, Class<?> clazz, String sheetName) {
        EasyExcel.write(file, clazz)
                .sheet(sheetName)
                .doWrite(data);
    }

    /**
     * 写多张 sheet：不同数据写进同一个工作簿的不同工作表
     */
    public static <T> void writeMultiSheet(File file, List<SheetData<T>> sheetDataList) {
        ExcelWriter excelWriter = EasyExcel.write(file).build();
        try {
            for (SheetData<T> sheetData : sheetDataList) {
                WriteSheet writeSheet = EasyExcel.writerSheet(sheetData.getSheetName())
                        .head(sheetData.getClazz())
                        .build();
                excelWriter.write(sheetData.getData(), writeSheet);
            }
        } finally {
            // finish() 会自动关闭底层输出流，不要在此之前手动关闭
            excelWriter.finish();
        }
    }

    /** 一张 sheet 的数据与类型 */
    public static class SheetData<T> {
        private final String sheetName;
        private final Class<T> clazz;
        private final List<T> data;

        public SheetData(String sheetName, Class<T> clazz, List<T> data) {
            this.sheetName = sheetName;
            this.clazz = clazz;
            this.data = data;
        }

        public String getSheetName() {
            return sheetName;
        }

        public Class<T> getClazz() {
            return clazz;
        }

        public List<T> getData() {
            return data;
        }
    }

    /**
     * 带样式的写：表头灰底加粗、内容自动列宽
     */
    public static void writeWithStyle(File file, List<?> data, Class<?> clazz, String sheetName) {
        WriteCellStyle headStyle = new WriteCellStyle();
        WriteFont headFont = new WriteFont();
        headFont.setBold(true);
        headFont.setFontHeightInPoints((short) 12);
        headStyle.setWriteFont(headFont);

        WriteCellStyle contentStyle = new WriteCellStyle();

        EasyExcel.write(file, clazz)
                .registerWriteHandler(new HorizontalCellStyleStrategy(headStyle, contentStyle))
                .registerWriteHandler(new LongestMatchColumnWidthStyleStrategy())
                .sheet(sheetName)
                .doWrite(data);
    }

    /**
     * 分页写同一张 sheet：一个 ExcelWriter 反复 write，表头只写一次
     *
     * @param pageSize 每页条数，建议 1000～5000
     */
    public static void writeByPage(File file, PageQuery<?> pageQuery, Class<?> clazz,
                                   String sheetName, int pageSize) {
        ExcelWriter excelWriter = EasyExcel.write(file, clazz).build();
        try {
            WriteSheet writeSheet = EasyExcel.writerSheet(sheetName).build();
            int pageNo = 0;
            while (true) {
                List<?> page = pageQuery.query(pageNo++, pageSize);
                if (page == null || page.isEmpty()) {
                    break;
                }
                excelWriter.write(page, writeSheet);
            }
        } finally {
            excelWriter.finish();
        }
    }

    /**
     * 分页查询回调，避免 ExcelUtil 依赖具体的 DAO 实现
     */
    @FunctionalInterface
    public interface PageQuery<T> {
        List<T> query(int pageNo, int pageSize);
    }
}
