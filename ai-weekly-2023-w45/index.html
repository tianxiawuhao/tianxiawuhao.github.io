AI 周报 · 2023.11.06 – 11.12

Posted on 2023-11-12，3 min read

OpenAI 首届开发者大会是本周 AI 新闻主线,GPT-4 Turbo、DALL-E 3 API 等相继发布,ChatGPT 周活跃用户达 1 亿;与此同时,AI 机器人的拐点论与 AI 是否削弱个人技能的讨论也在科技媒体升温。

模型与产品

  • 11-06 · OpenAI 发布 GPT-4 Turbo 及微调计划：OpenAI 在其首届开发者大会上推出 GPT-4 Turbo,同时公布针对 GPT-4 的微调计划,向开发者进一步开放模型定制能力,被视为其开发者生态纵深布局的信号。 来源
  • 11-06 · OpenAI 披露 ChatGPT 周活跃用户达 1 亿：OpenAI 在开发者大会周披露,ChatGPT 周活跃用户数已达 1 亿;配合多项平台化发布,通用助手正在从单一产品转向可被第三方扩展的生态。 来源

开发者工具

  • 11-06 · OpenAI 推出 DALL-E 3 API 与新语音模型：OpenAI 发布 DALL-E 3 图像生成 API,并推出新的文本转语音模型,将多模态生成能力以接口形式开放给第三方开发者调用。 来源
  • 11-10 · Superpowered 转型为机器人语音 API 平台：获 YC 支持的效率类应用 Superpowered 宣布转型,将自身重新定位为面向机器人与其它产品的语音 API 平台,押注对话式语音交互的开发需求。 来源

人文与社会

  • 11-10 · 观点称 AI 机器人的 GPT 时刻临近：TechCrunch 刊登署名观点文章,认为 AI 机器人领域正逼近属于它的 GPT 时刻,机器人技术有望迎来类似大语言模型的关键拐点。 来源
  • 11-10 · 观点:AI 或让人在擅长之事上变差：另一篇观点文章提醒,AI 并不会自动放大个人优势,反而可能让人在自己原本擅长的事情上表现更差,引发对过度依赖与技能退化的讨论。 来源

人文视角 · 一点思考

一周内,一家公司的开发者大会几乎撑起整周 AI 新闻,足见行业叙事的高度集中,也意味着巨头发布节奏正在定义所有人的注意力。ChatGPT 周活破亿与 API、商店化路线,让通用助手朝可被第三方定义能力的平台演进,普通人的工作与创造方式将被重新塑造。恰在此时,关于 AI 会让人在擅长之事上变差的提醒值得玩味:自动化带来便利,也可能钝化技能、滋生依赖。窗口期的真正考验,或许不是模型还能做什么,而是人类能否保有判断与主动。
