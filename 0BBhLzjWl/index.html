数据结构常见的八大排序算法

Posted on 2021-04-25，22 min read

八大排序、三大查找是《数据结构》当中非常基础的知识点，这里为了复习顺带总结一下常见的八种排序算法。评价一个排序算法，通常看四个指标：时间复杂度（最好 / 平均 / 最坏）、空间复杂度（是否原地）、稳定性（相等元素的相对次序是否改变），以及适用场景（数据规模、初始有序程度、是数组还是链表）。

直接插入排序

算法思想：

直接插入排序的核心思想就是：将数组中的所有元素依次跟前面已经排好的元素相比较，如果选择的元素比已排序的元素小，则交换，直到全部元素都比较过。

因此，从上面的描述中我们可以发现，直接插入排序可以用两个循环完成：

  1. 第一层循环：遍历待比较的所有数组元素
  2. 第二层循环：将本轮选择的元素(selected)与已经排好序的元素(ordered)相比较。

如果 selected < ordered，就把 selected 向前挪一位，直到找到不大于它的元素为止。代码中用「先保存待插入元素、再把较大的元素整体后移、最后落位」代替反复交换，可以减少赋值次数。

复杂度与特点：最好情况是序列已经有序，内层循环每次只比较一次就退出，时间复杂度 \(O(n)\)；最坏情况是序列完全逆序，比较和移动次数约为 \(n^2/2\)，时间复杂度 \(O(n^2)\)；平均同样为 \(O(n^2)\)。辅助空间 \(O(1)\)，是原地排序；只有当 \(arr[j] > temp\) 时才后移，相等元素不会被跨越，因此是稳定排序。它适合数据量较小或序列基本有序的场景，很多标准库的排序在区间足够小时也会切换成插入排序。

 * 直接插入排序的核心思想就是：将数组中的所有元素依次跟前面已经排好的元素相比较，如果选择的元素比已排序的元素小，则交换，直到全部元素都比较过。
 * 因此，从上面的描述中我们可以发现，直接插入排序可以用两个循环完成：
 * 第一层循环：遍历待比较的所有数组元素
 * 第二层循环：将本轮选择的元素(selected)与已经排好序的元素(ordered)相比较。
 * 如果：selected < ordered，那么将二者交换
 */
public class DirectInsertionSort {
    public static void main(String[] args) {
        int[] arr = {12, 32, 22, 7, 48};
        insertSort(arr);
    }

    private static void insertSort(int[] arr) {
       for (int i = 1; i < arr.length; i++) {
           int temp = arr[i];
           int j;
           for (j = i - 1; j >= 0; j--) {
               if (temp < arr[j]) {
                   arr[j + 1] = arr[j];
               } else {
                   break;
               }
           }
           arr[j + 1] = temp;
       }

        System.out.println(Arrays.toString(arr));
    }
}

希尔排序

算法思想：

希尔排序（缩小增量排序）的算法思想：将待排序数组按照步长 gap 分组，把下标相差 gap 的元素看作同一组，对每组先用直接插入排序排好；然后不断缩小 gap（常见做法是折半），当 gap = 1 时再做一次完整的直接插入排序，排序完成。

gap 较大时元素可以一次跨越多步移动，序列的「逆序度」迅速下降；等到 gap = 1 时序列已经接近有序，插入排序接近 \(O(n)\)。这就是希尔排序比直接插入排序快的原因。

同样的：从上面的描述中我们可以发现：希尔排序的总体实现应该由三个循环完成：

  1. 第一层循环：将gap依次折半，对序列进行分组，直到gap=1
  2. 第二、三层循环：也即直接插入排序所需要的两次循环。具体描述见上。

代码实现

package sort;

import java.util.Arrays;

/**
 * @author wuhao
 * @desc 希尔排序（缩小增量排序）
 * @date 2020-12-02 15:20:43
 * 希尔排序的算法思想：将待排序数组按照步长 gap 分组，对每组使用直接插入排序；
 * 每趟把 gap 折半，直到 gap = 1 时再做一次完整的直接插入排序。
 * gap > 1 时元素可以按大步长移动，序列的"逆序度"快速下降，
 * 最后一趟 gap = 1 时序列已接近有序，插入排序接近 O(n)。
 */
public class HillSort {
    public static void main(String[] args) {
        int[] arr = {12, 32, 22, 7, 48, 3, 5, 6, 8, 24};
        shellSort(arr);
        System.out.println(Arrays.toString(arr));
    }

    private static void shellSort(int[] arr) {
        // gap 依次折半：n/2, n/4, ... , 1
        for (int gap = arr.length / 2; gap > 0; gap /= 2) {
            // 对每个分组做直接插入排序：组内相邻元素下标相差 gap
            for (int i = gap; i < arr.length; i++) {
                int temp = arr[i];
                int j = i - gap;
                while (j >= 0 && arr[j] > temp) {
                    arr[j + gap] = arr[j];
                    j -= gap;
                }
                arr[j + gap] = temp;
            }
        }
    }
}

复杂度与特点：无论初始序列如何，比较次数都固定为 \(n(n-1)/2\)，所以最好、最坏、平均时间复杂度都是 \(O(n^2)\)；但每趟最多只交换一次，交换次数上界为 \(n-1\)，因此当「交换」的代价远大于「比较」时比冒泡排序划算。辅助空间 \(O(1)\)，是原地排序。它是不稳定的：例如 \([5, 5, 2]\)，第一趟把最小的 2 与第一个 5 交换，两个 5 的相对次序就被破坏了。

简单选择排序

算法思想

简单选择排序的基本思想：比较+交换。

  1. 从待排序序列中，找到关键字最小的元素；
  2. 如果最小元素不是待排序序列的第一个元素，将其和第一个元素互换；
  3. 从余下的 N - 1 个元素中，找出关键字最小的元素，重复(1)、(2)步，直到排序结束。

因此我们可以发现，简单选择排序也是通过两层循环实现。

第一层循环：依次遍历序列当中的每一个元素

第二层循环：将遍历得到的当前元素依次与余下的元素进行比较，符合最小元素的条件，则交换。

代码实现

package sort;

import java.util.Arrays;

/**
 * @author wuhao
 * @desc 简单选择排序
 * @date 2020-12-02 16:21:47
 * 简单选择排序的基本思想：比较+交换。
 * 从待排序序列中，找到关键字最小的元素；
 * 如果最小元素不是待排序序列的第一个元素，将其和第一个元素互换；
 * 从余下的 N - 1 个元素中，找出关键字最小的元素，重复(1)、(2)步，直到排序结束。
 * 因此我们可以发现，简单选择排序也是通过两层循环实现。
 * 第一层循环：依次遍历序列当中的每一个元素
 * 第二层循环：将遍历得到的当前元素依次与余下的元素进行比较，符合最小元素的条件，则交换。
 */
public class SimpleSelectionSort {
    public static void main(String[] args) {
        int[] arr = {12, 32, 22, 7, 48, 3, 5, 6, 8, 24};
        selectionSort(arr);
    }

    private static void selectionSort(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            int k = i;
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[k]) {
                    k = j;
                }
            }
            if (k != i) {
                int temp = arr[i];
                arr[i] = arr[k];
                arr[k] = temp;
            }


        }
        System.out.println(Arrays.toString(arr));
    }
}

复杂度与特点：建堆的时间复杂度是 \(O(n)\)（不是 \(O(n\log n)\)，因为越靠下的结点下沉层数越少），之后每趟取出堆顶并恢复堆性质需要 \(O(\log n)\)，共 \(n-1\) 趟，所以最好、最坏、平均时间复杂度都是 \(O(n\log n)\)。辅助空间 \(O(1)\)，是原地排序。堆排序不稳定：堆顶与堆尾交换会把相等元素甩到很远的位置。它适合「既要原地、又要求最坏情况有保障」的场景，也常用于求前 K 大 / 前 K 小元素和优先队列。

堆排序

堆的概念

堆：本质是一种用数组存储的完全二叉树。它的关键性质是父结点与孩子结点之间的大小关系：大顶堆中任意结点的值都不小于其左右孩子的值，小顶堆中任意结点的值都不大于其左右孩子的值。注意方向是「父结点大于 / 小于孩子」，而不是「叶子小于父结点」；堆只约束父子关系，对左右孩子之间的大小不做任何要求。

用数组存储完全二叉树时，下标之间有固定关系（以下标 0 为根）：结点 i 的左孩子是 \(2i+1\)、右孩子是 \(2i+2\)，父结点是 \((i-1)/2\)；最后一个非叶子结点的下标是 \(n/2-1\)。把结点「下沉」时，只需和较大的那个孩子比较即可。

利用堆排序，就是基于大顶堆或者小顶堆的一种排序方法。下面，我们通过大顶堆来实现。

基本思想：

堆排序可以按照以下步骤来完成：

  1. 构建初始堆，将待排序列构成一个大顶堆(或者小顶堆)，升序大顶堆，降序小顶堆；
  2. 将堆顶元素与堆尾元素交换，并断开(从待排序列中移除)堆尾元素。
  3. 重新构建堆。
  4. 重复2~3，直到待排序列中只剩下一个元素(堆顶元素)。

代码实现：

package sort;

import java.util.Arrays;

/**
 * @author wuhao
 * @desc 堆排序（升序用大顶堆）
 * @date 2020-12-04 09:13:58
 * 1. 建堆：从最后一个非叶子结点 n/2 - 1 开始，自下而上依次下沉，时间复杂度 O(n)；
 * 2. 排序：把堆顶（当前最大值）与堆尾交换，堆的有效长度减一，再让堆顶下沉恢复堆性质，重复 n-1 次。
 * 下标关系（0 基）：结点 i 的左孩子 2i+1，右孩子 2i+2，父结点 (i-1)/2。
 */
public class HeapSort {
    public static void main(String[] args) {
        int[] arr = {11, 44, 23, 67, 88, 65, 34, 48, 9, 12};
        heapSort(arr);
        System.out.println(Arrays.toString(arr));
    }

    private static void heapSort(int[] a) {
        int n = a.length;
        // 建堆：从最后一个非叶子结点开始，自下而上依次下沉
        for (int i = n / 2 - 1; i >= 0; i--) {
            siftDown(a, i, n);
        }
        // 排序：堆顶与堆尾交换，有效长度减一，再只对堆顶做一次下沉
        for (int i = n - 1; i > 0; i--) {
            int temp = a[0];
            a[0] = a[i];
            a[i] = temp;
            siftDown(a, 0, i);
        }
    }

    /**
     * 下沉：把 a[parent] 调整到合适位置，length 是当前堆的有效长度
     */
    private static void siftDown(int[] a, int parent, int length) {
        int temp = a[parent];          // 先保存待调整的结点
        int child = 2 * parent + 1;    // 左孩子
        while (child < length) {
            // 右孩子存在且比左孩子大，就选右孩子
            if (child + 1 < length && a[child] < a[child + 1]) {
                child++;
            }
            // 父结点已经不小于较大的孩子，堆性质满足，直接结束
            if (temp >= a[child]) {
                break;
            }
            a[parent] = a[child];      // 孩子上移
            parent = child;            // 继续向下检查被破坏的子树
            child = 2 * parent + 1;
        }
        a[parent] = temp;              // 放到最终位置
    }
}

冒泡排序

基本思想

冒泡排序的思路比较简单：反复比较相邻的两个元素，若前者大于后者就交换，每一趟结束后当前未排序部分的最大值会「冒」到末尾。

  1. 从序列头部开始，依次比较相邻的两个元素，保证右边的元素不小于左边的元素；一趟结束后，序列最后一个元素一定是当前未排序部分的最大值。
  2. 对剩下的 n-1 个元素重复步骤 1，直到所有元素有序。
  3. 长度为 n 的序列最多需要 n-1 趟。如果某一趟没有发生任何交换，说明序列已经有序，可以提前结束——这正是冒泡排序最好情况为 \(O(n)\) 的原因。

代码实现

package sort;

import java.util.Arrays;

/**
 * @author wuhao
 * @desc 冒泡排序（相邻比较 + 提前退出优化）
 * @date 2020-12-02 16:34:57
 * 冒泡排序思路：每一趟从左到右依次比较相邻的两个元素，逆序就交换，
 * 一趟结束后当前未排序部分的最大值会"冒"到末尾；
 * 如果某一趟没有发生任何交换，说明序列已经有序，可以直接退出，此时最好情况为 O(n)。
 */
public class BubbleSort {
    public static void main(String[] args) {
        int[] arr = {12, 32, 22, 7, 48};
        bubbleSort(arr);
        System.out.println(Arrays.toString(arr));
    }

    private static void bubbleSort(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) {      // 最多 n-1 趟
            boolean swapped = false;
            // 每趟只比较到 n-1-i，后面 i 个元素已经有序
            for (int j = 0; j < arr.length - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {              // 相邻比较，逆序则交换
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true;
                }
            }
            if (!swapped) {                             // 本趟无交换，已经有序
                break;
            }
        }
    }
}

复杂度与特点：平均和最好情况下，每次划分都能把区间大致均分，递归深度 \(\log n\)，时间复杂度 \(O(n\log n)\)；最坏情况（例如对有序序列固定取首元素作枢轴）退化为 \(O(n^2)\)。辅助空间来自递归栈，平均 \(O(\log n)\)、最坏 \(O(n)\)。它是原地排序，但不稳定：划分时的远距离交换会改变相等元素的相对次序。由于常数因子小、缓存友好，它通常是实际最快的比较排序，也是 Java 中 Arrays.sort(int[]) 的基础。

快速排序

算法思想：

快速排序的基本思想：挖坑填数 + 分治法。

  1. 从当前区间中选择一个基准数（pivot），这里取区间第一个数；
  2. j 从右往左找比基准小的数，把它填到左边的坑里；i 从左往右找比基准大的数，把它填到右边的坑里；
  3. 当 i == j 时把基准数填回该位置，此时基准左侧都不大于它、右侧都不小于它；
  4. 对左右两个子区间重复以上过程，直到子区间只剩一个元素（递归出口）。

用伪代码描述如下（下标从 0 开始，区间记作 [left, right]）：

1. i = left; j = right; 把基准数挖出，a[i] 成为第一个坑；

2. j 由后向前找比基准小的数，找到后把它填入 a[i]，a[j] 成为新坑；

3. i 由前向后找比基准大的数，找到后把它填入 a[j]，a[i] 成为新坑；

4. 重复 2、3 两步，直到 i == j，把基准数填入 a[i]，返回 i 作为划分点。

枢轴选择与最坏情况：固定取区间首元素作枢轴时，如果序列本身已经有序或完全逆序，每次划分只能分出一个元素，递归深度退化为 n，时间复杂度退化为 \(O(n^2)\)。常见改进有三数取中（取首、中、尾三个数的中位数作枢轴）、随机选取枢轴，以及小区间切换插入排序。另外，递归实现的最坏栈深度是 \(O(n)\)，可以改用显式栈的非递归写法，或者先递归较短的一侧、另一侧循环处理，把栈深度控制在 \(O(\log n)\)。

代码实现：

package sort;

import java.util.Arrays;
import java.util.Stack;

/**
 * @author wuhao
 * @desc 快速排序（挖坑填数 + 分治）
 * @date 2020-12-02 17:08:57
 * 快速排序的基本思想：挖坑填数 + 分治。
 * 1. 从序列当中选择一个基准数(pivot)，这里取区间第一个数；
 * 2. j 从右往左找比基准小的数填左坑，i 从左往右找比基准大的数填右坑；
 * 3. i == j 时把基准填回该位置，此时左侧都不大于基准，右侧都不小于基准；
 * 4. 对左右两个子区间重复以上过程，直到子区间只剩一个元素。
 */
public class QuickSort {
    public static void main(String[] args) {
        int[] arr = {12, 32, 22, 7, 48, 3, 35, 6, 8, 42};
        int[] copy = arr.clone();

        quickSort(arr, 0, arr.length - 1);
        System.out.println("递归：" + Arrays.toString(arr));

        quickSortByStack(copy, 0, copy.length - 1);
        System.out.println("非递归：" + Arrays.toString(copy));
    }

    /** 递归实现 */
    private static void quickSort(int[] arr, int left, int right) {
        if (left >= right) {                 // 区间为空或只有一个元素
            return;
        }
        int pivot = partition(arr, left, right);
        quickSort(arr, left, pivot - 1);
        quickSort(arr, pivot + 1, right);
    }

    /** 一趟划分：挖坑填数，返回基准最终所在的下标 */
    private static int partition(int[] arr, int left, int right) {
        int base = arr[left];                // 挖出基准，a[left] 成为第一个坑
        int i = left, j = right;
        while (i < j) {
            // 先从右往左找比 base 小的数
            while (i < j && arr[j] >= base) {
                j--;
            }
            if (i < j) {
                arr[i] = arr[j];             // 填左坑，a[j] 成为新坑
            }
            // 再从左往右找比 base 大的数
            while (i < j && arr[i] <= base) {
                i++;
            }
            if (i < j) {
                arr[j] = arr[i];             // 填右坑，a[i] 成为新坑
            }
        }
        arr[i] = base;                       // i == j，基准填回最后一个坑
        return i;
    }

    /** 非递归实现：用栈保存待处理区间，避免递归过深时栈溢出 */
    private static void quickSortByStack(int[] arr, int left, int right) {
        Stack<Integer> stack = new Stack<>();
        stack.push(left);
        stack.push(right);
        while (!stack.isEmpty()) {
            int r = stack.pop();
            int l = stack.pop();
            if (l >= r) {
                continue;
            }
            int pivot = partition(arr, l, r);
            stack.push(l);
            stack.push(pivot - 1);
            stack.push(pivot + 1);
            stack.push(r);
        }
    }
}

复杂度与特点：递归深度为 \(\log n\)，每层合并的总代价是 \(O(n)\)，所以最好、最坏、平均时间复杂度都是 \(O(n\log n)\)，性能非常稳定。辅助数组需要 \(O(n)\) 空间，属于非原地排序；但合并时「小于号优先取左段」，相等元素不会跨越，因此它是稳定的。归并排序不需要随机访问，很适合链表排序，也是外部排序（大文件多路归并）的基础。

归并排序

算法思想：

归并排序是建立在归并操作上的一种有效的排序算法，它是分治法（Divide and Conquer）的典型应用。它的基本操作是：把待排序列不断折半拆分，直到每个子序列只有一个元素（单个元素天然有序），再把这些有序子序列两两合并，最终得到完全有序的序列。

  1. 分解：把当前区间折半拆成左右两段，递归处理；
  2. 合并：把两个相邻且各自有序的子序列合并成一个有序序列。

因此，归并排序实际上就是两个操作：拆分 + 合并。

如何合并？设 L[first...mid] 为第一段、L[mid+1...last] 为第二段，且两段都已有序，现在要把它们合并成 L[first...last] 且仍然有序。

  1. 用两个指针分别指向两段的开头，依次比较，把较小的元素放入临时数组 temp[]；
  2. 当某一段的元素全部取完后，把另一段剩下的元素依次复制到 temp[]；
  3. 最后把 temp[] 中的元素复制回 L[first...last]，此时该区间有序。

如何分解？这里采用递归的方法：把待排序列分成 A、B 两组，再分别对 A、B 重复分组，直到每组只剩一个元素，此时认为组内所有元素有序，分解结束。

代码实现

package sort;

import java.util.Arrays;

/**
 * @author wuhao
 * @desc 归并排序
 * @date 2020-12-03 09:35:00
 * 归并排序是建立在归并操作上的一种有效的排序算法，该算法是采用0的一个典型的应用。它的基本操作是：将已有的子序列合并，达到完全有序的序列；即先使每个子序列有序，再使子序列段间有序。
 * 归并排序其实要做两件事：
 * 分解----将序列每次折半拆分
 * 合并----将划分后的序列段两两排序合并
 * 因此，归并排序实际上就是两个操作，拆分+合并
 * 如何合并？
 * L[first...mid]为第一段，L[mid+1...last]为第二段，并且两端已经有序，现在我们要将两端合成达到L[first...last]并且也有序。
 * 首先依次从第一段与第二段中取出元素比较，将较小的元素赋值给temp[]
 * 重复执行上一步，当某一段赋值结束，则将另一段剩下的元素赋值给temp[]
 * 此时将temp[]中的元素复制给L[]，则得到的L[first...last]有序
 * 如何分解？
 * 在这里，我们采用递归的方法，首先将待排序列分成A,B两组；然后重复对A、B序列
 * 分组；直到分组后组内只有一个元素，此时我们认为组内所有元素有序，则分组结束。
 */
public class MergeSort {
    public static void main(String[] args) {
        int[] arr = {11, 44, 23, 67, 88, 65, 34, 48, 9, 12};
        int[] tmp = new int[arr.length];    //新建一个临时数组存放
        mergeSort(arr, 0, arr.length - 1, tmp);
        System.out.println(Arrays.toString(arr));
    }

    private static void mergeSort(int[] arr, int low, int high, int[] tmp) {
        if (low < high) {
            int mid = (low + high) / 2;
            mergeSort(arr, low, mid, tmp);
            mergeSort(arr, mid + 1, high, tmp);
            merge(arr, low, mid, high, tmp);
        }
    }

    private static void merge(int[] arr, int low, int mid, int high, int[] tmp) {
        int i = 0;
        int j = low, k = mid + 1;
        while (j <= mid && k <= high) {
            if (arr[j] < arr[k]) {
                tmp[i++] = arr[j++];
            } else {
                tmp[i++] = arr[k++];
            }
        }
        while (j <= mid) {
            tmp[i++] = arr[j++];
        }
        while (k <= high) {
            tmp[i++] = arr[k++];
        }
        for (int l = 0; l < i; l++) {
            arr[low+l] = tmp[l];
        }

    }
}

复杂度与特点：每一趟分配与收集都要处理全部 n 个元素并遍历 k 个桶，共 d 趟（d 为最大值的位数），所以时间复杂度为 \(O(d(n+k))\)；当 d 为常数、k 也不大时接近线性 \(O(n)\)，这也是它快的原因。辅助空间为桶和临时数组，\(O(n+k)\)，属于非原地排序。基数排序稳定（前提是每一位的收集都保持稳定），但它只在关键字能按位拆分时可用。

基数排序

算法思想

基数排序通过序列中各个元素的值，对 N 个元素进行若干趟「分配」与「收集」来实现排序。

  1. 分配：取出 L[i] 中的元素，确定它当前位（第一趟是个位）上的数字，按该数字把它放入序号相同的桶中；
  2. 收集：所有元素都分配完后，按桶的序号从小到大依次把元素收集起来，形成新的待排序列 L[]；
  3. 对新形成的序列 L[] 重复「分配 + 收集」，依次处理十位、百位……直到最高位处理完毕，排序结束。

基数排序必须稳定：每一位的收集顺序都依赖上一趟的相对次序，只有稳定地收集，高位排好的顺序才不会被破坏。以非负整数的 LSD（最低位优先）为例，先按个位分桶收集，再按十位、百位依次进行，若干趟之后整个序列有序。

适用条件：基数排序只适合关键字可以「按位拆分」、且每一位取值范围有限的数据，最典型的是非负整数，也可以是定长字符串或日期。它不进行比较，因此不受比较排序 \(O(n\log n)\) 下界的限制；但如果数据值域跨度极大（例如只有两个数却相差 \(10^9\)），位数 d 很大，反而比快速排序慢。对负数需要先统一加上偏移量，或者单独处理符号位。

代码实现

package sort;

import java.util.Arrays;

/**
 * @author wuhao
 * @desc 基数排序
 * @date 2020-12-03 09:58:32
 * 基数排序：通过序列中各个元素的值，对排序的N个元素进行若干趟的“分配”与“收集”来实现排序。
 * 分配：我们将L[i]中的元素取出，首先确定其个位上的数字，根据该数字分配到与之序号相同的桶中
 * 收集：当序列中所有的元素都分配到对应的桶中，再按照顺序依次将桶中的元素收集形成新的一个待排序列L[ ]
 * 对新形成的序列L[]重复执行分配和收集元素中的十位、百位...直到分配完该序列中的最高位，则排序结束
 * 根据上述“基数排序”的展示，我们可以清楚的看到整个实现的过程
 */
public class BaseSort {
    public static void main(String[] args) {
        int[] arr = {63, 157, 189, 51, 101, 47, 141, 121, 157, 156,
                194, 117, 98, 139, 67, 133, 181, 12, 28, 0, 109};

        radixSort(arr);
        System.out.println(Arrays.toString(arr));
    }

    private static void radixSort(int[] arr) {
        //待排序列最大值
        int max = arr[0];
        int exp;//指数
        //计算最大值
        for (int anArr : arr) {
            if (anArr > max) {
                max = anArr;
            }
        }
        //从个位开始，对数组进行排序
        for (exp = 1; max / exp > 0; exp *= 10) {
            //存储待排元素的临时数组
            int[] temp = new int[arr.length];
            //分桶个数
            int[] buckets = new int[10];

            //将数据出现的次数存储在buckets中
            for (int value : arr) {
                //(value / exp) % 10 :value的最底位(个位)
                buckets[(value / exp) % 10]++;
            }

            //更改buckets[i]，
            for (int i = 1; i < 10; i++) {
                buckets[i] += buckets[i - 1];
            }

            //将数据存储到临时数组temp中
            for (int i = arr.length - 1; i >= 0; i--) {
                temp[buckets[(arr[i] / exp) % 10] - 1] = arr[i];
                buckets[(arr[i] / exp) % 10]--;
            }

            //将有序元素temp赋给arr
            System.arraycopy(temp, 0, arr, 0, arr.length);
        }

    }
}

后记

写完之后运行了一下时间比较，从结果上来看，堆排序、归并排序、基数排序都很快，与上面的复杂度分析一致。对于快速排序递归深度过深的问题，可以考虑把它改写成非递归（用显式栈保存待处理区间）的形式，本文的示例代码已经给出了两种写法，实测输出一致。

实际选型时的建议：

  • 数据量很小（几十个元素以内）或序列基本有序：直接用插入排序，常数小、实现简单。
  • 要求稳定、且可以接受 \(O(n)\) 的额外空间：选归并排序；对链表排序时它几乎是首选。
  • 要求原地、且最坏情况也要有保障：选堆排序；只要求平均最快、不介意最坏 \(O(n^2)\)：选快速排序。
  • 关键字是小范围整数：计数排序最快；位数不多的非负整数：基数排序。
  • 工程中一般不自己手写排序：Java 的 Arrays.sort(int[]) 使用双轴快速排序，Arrays.sort(Object[]) 与 Collections.sort 使用 TimSort（归并 + 插入，稳定排序）。
