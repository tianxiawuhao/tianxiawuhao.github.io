AI教程 使用DPO微调大语言模型

10.1 DPO理论介绍以及DPO存在的问题

Posted on 2025-05-04，6 min read

提示

  • DPO: Direct Preference Optimization
  • 直接偏好优化：你的大语言模型实际上是一个奖励模型

10.1.1 偏好数据集

DPO 需要偏好数据集来微调 LLM。偏好数据集的格式如下：

{
    "prompt": "这部电影怎么样?",
    "chosen": "这部电影很好看.",
    "rejected": "这部电影不好看."
}

数据集构建的方法：

  • 针对同一个prompt，通过调整温度，让LLM输出不同的回答。然后让数据标注工程师来标注对不同回答的偏好。
  • 在使用ChatGPT时，你可能注意到，偶尔会被要求在两个相似的答案中选择一个来继续对话。这个偏好会被记录下来，并用于在未来的偏好调整中改进模型。
  • 手工标注
  • 合成数据：通过写提示词来让LLM生成偏好数据集（需要人工审核）。
  • 使用网上的开源数据集

数据集容易存在的问题：

  1. 正负例区分不明显
{
    "prompt": "这部电影怎么样?",
    "chosen": "这部电影很好看。",
    "rejected": "这部电影挺好看。"
}

人类都无法识别哪个应该是正例，哪个应该是负例。

  1. 数据集中存在偏好循环
{
    "prompt": "这部电影怎么样?",
    "chosen": "这部电影很好看。",
    "rejected": "这部电影很差。"
},
{
    "prompt": "这部电影怎么样?",
    "chosen": "这部电影很差。",
    "rejected": "这部电影很好看。"
}

当模型看到以上数据时，就不知道人类的偏好是什么了。无法学到任何东西。因为第一个人标注的数据的偏好是 $A > B$，第二个人标注的数据的偏好是 $B > A$，那么模型看到的偏好是 $A > B > A$。这就是偏好循环。

10.1.2 DPO目标函数

这里我们思考一下，给定提示词 $x$ 的情况下，模型输出补全 $y$ 的概率是多少呢？如下所示：

$$ \begin{aligned} \pi_{\theta}(y|x) &= P_{\mathrm{LLM}{\theta}}(y_0|x)P{\mathrm{LLM}{\theta}}(y_1|x,y_0)\dots P{\mathrm{LLM}{\theta}}(y_t|x,y{< t})\ &= \prod_{t = 0}^{|y|}P_{\mathrm{LLM}{\theta}}(y_t|x,y{< t}) \end{aligned} \tag{10.2} $$

然后根据 $\log$ 的性质也就是 $\log \frac{A}{B} = \log A - \log B$。可以推导出目标函数最内部的表达式的另一种形式。

$$ \begin{aligned} &\log \frac{\pi_{\theta}(y_w|x)}{\pi_{\theta}(y_l|x)} -\log \frac{\pi_{\mathrm{ref}}(y_w|x)}{\pi_{\mathrm{ref}}(y_l|x)}\ &= \log \pi_{\theta}(y_w|x) - \log \pi_{\theta}(y_l|x) - \log \pi_{\mathrm{ref}}(y_w|x) + \log \pi_{\mathrm{ref}}(y_l|x)\ &= \log \pi_{\theta}(y_w|x) - \log \pi_{\mathrm{ref}}(y_w|x) - (\log \pi_{\theta}(y_l|x) - \log \pi_{\mathrm{ref}}(y_l|x)) \end{aligned} \tag{10.3} $$

通过观察目标函数，我们知道在最开始训练时：$\pi_{\theta} = \pi_{\mathrm{ref}}$，所以 $\log \frac{\pi_{\theta}(y_w|x)}{\pi_{\mathrm{ref}}(y_w|x)} - \log \frac{\pi_{\theta}(y_l|x)}{\pi_{\mathrm{ref}}(y_l|x)} = 0$。但由于外层有 $\sigma$ 函数，所以不影响反向传播更新网络（$\sigma(0) = 0.5$）。

通过观察目标函数，我们可以知道随着训练的进行，$\frac{\pi_{\theta}(y_w|x)}{\pi_{\theta}(y_l|x)}$ 会越来越大。因为 $\frac{\pi_{\theta}(y_w|x)}{\pi_{\mathrm{ref}}(y_w|x)}$ 是一个常数（作为正则化项存在）。

DPO存在的问题

  1. $\frac{\pi_{\theta}(y_w|x)}{\pi_{\theta}(y_l|x)}$ 的分子和分母可能同时增大或者减小。例如分母增大了1.5倍，分子增大了3倍。那么就导致了LLM输出人类偏好的回答的概率和输出人类讨厌的回答的概率都增加了。
  2. $\frac{\pi_{\theta}(y_w|x)}{\pi_{\theta}(y_l|x)}$ 随着训练，分子越来越大，分母越来越小，结果导致了 $\pi_{\theta}(y_w|x)$ 趋近于1，$\pi_{\theta}(y_l|x)$ 趋近于0，正则化项 $\frac{\pi_{\theta}(y_w|x)}{\pi_{\mathrm{ref}}(y_w|x)}$ 没有起到作用，最终LLM彻底失去了探索能力。也就是出现了“过拟合”的问题。DPO容易过拟合，泛化能力不足。所以DPO的训练轮数不能太多。
  3. 数据集中存在的偏好循环会导致LLM学不到东西。例如数据集中存在 $A > B$ 和 $B > C$，那么模型可以学习到人类的偏好是 $A > B > C$。如果这是还有一条数据中 $C > A$，那么模型就懵了，不知道人类的偏好是什么了。因为模型看到的是 $A > B > C > A$。也就是偏好循环。

尽管存在这些缺点，DPO仍然是一种非常有效的工具；许多最成功和性能最好的开源LLM都是使用DPO进行指令微调的。

危险

个人认为DPO不算是强化学习，因为DPO需要训练数据集。而真正的强化学习的训练数据是由策略模型自己采样得来的。
