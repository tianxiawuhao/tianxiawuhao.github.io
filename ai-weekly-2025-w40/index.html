AI 周报 · 2025.09.29 – 10.05

Posted on 2025-10-05，3 min read

本周 AI 焦点在大模型与应用：Anthropic 发布最强编程模型 Claude Sonnet 4.5；OpenAI 推出智能体购物系统进军电商；DeepSeek 以稀疏注意力模型将 API 成本减半，端侧 AI 亦有新进展。

模型与产品

  • 09-29 · Anthropic 发布 Claude Sonnet 4.5 编程模型：Anthropic 推出新一代 Claude Sonnet 4.5，官方称其为迄今最强的编程模型，面向复杂编码任务与开发者，编程助手与代码智能赛道的竞争随之升温。 来源
  • 09-29 · OpenAI 推出智能体购物系统：OpenAI 上线智能体式购物系统，把 AI 引入选购环节，被视为向 Google、Amazon 主导的电商与搜索场景发起的正面竞争。 来源

开发者工具

  • 09-29 · DeepSeek 发布稀疏注意力模型降低 API 成本：DeepSeek 发布采用稀疏注意力机制的新模型，宣称可使 API 调用成本降低一半，推理开销与开发者调用成本成为厂商新一轮比拼重点。 来源
  • 10-03 · 开发者借 iOS 26 调用苹果端侧 AI 模型：报道梳理开发者如何在 iOS 26 中调用苹果设备端 AI 模型，端侧推理逐步落地，应用对云端的依赖有望进一步降低。 来源

融资与产业

  • 10-03 · OpenAI 以收购式招聘加码个性化 AI：通过最新一次收购式招聘，OpenAI 加码面向普通用户的个性化消费级 AI，显示其在模型能力之外开始押注差异化的个人产品体验。 来源
  • 10-03 · Naveen Rao 新 AI 硬件公司传获 a16z 支持：据知情人士消息，Naveen Rao 新创立的 AI 硬件公司正寻求融资，目标估值达 50 亿美元，据称获得 a16z 支持。 来源

人文视角 · 一点思考

厂商竞争正从榜单蔓延到价格与场景：Claude 号称编程最强，OpenAI 把智能体放进购物流程，DeepSeek 把 API 价格再砍一半。效率提升的另一面，是用户把比价、下单这类决策逐步交给算法，透明与纠错机制值得追问。当推理成本被不断压低，行业盈利模式仍未明朗。端侧模型同期推进，提示 AI 将更分散地嵌入日常设备，责任与治理或许需要一套新坐标系。
