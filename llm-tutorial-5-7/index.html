5.7 广义优势估计

Posted on 2025-04-21，7 min read

提示

广义优势估计：Generalized Advantage Estimation，GAE

上面的1步TD误差表示为：$\delta_t = R_t + \gamma V_{\omega}(S_{t+1}) - V_{\omega}(S_t)$。在很多强化学习文献中，这个叫做优势A（Advantage）。

也就是1步TD目标 $R_t + \gamma V_{\omega}(S_{t+1})$ 相对于基线 $V_{\omega}(S_t)$ 的优势是多少。

我们在上一节的Actor-Critic中使用1步TD误差来作为优势。而现在常用的一种方法是针对多步TD误差计算指数加权平均的方式来估算优势，也就是广义优势估计。

首先，$t$ 时刻的1步TD误差是：

$$\delta_t = R_t + \gamma V(S_{t+1}) - V(S_t) \quad (5.34)$$

其中 $V$ 是价值函数神经网络 $V_{\omega}$。那么我们计算一下多步TD误差：

$$\begin{array}{rl} & {A_t^{(1)} = \delta_t}\\ & {A_t^{(2)} = \delta_t + \gamma \delta_{t+1}}\\ & {A_t^{(3)} = \delta_t + \gamma \delta_{t+1} + \gamma^2 \delta_{t+2} = -V(s_t) + R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \gamma^3 V(s_{t+3})}\\ & {\qquad \vdots}\\ & {A_t^{(k)} = \sum_{l = 0}^{k - 1}\gamma^{l}\delta_{t + l}} \end{array}$$

$$\begin{array}{r l} & {A_t^{\mathrm{GAE}} = (1 - \lambda)\Big(A_t^{(1)} + \lambda A_t^{(2)} + \lambda^{2}A_t^{(3)} + \dots \Big)}\\ & {\qquad = (1 - \lambda)(\delta_t + \lambda (\delta_t + \gamma \delta_{t + 1}) + \lambda^{2}(\delta_t + \gamma \delta_{t + 1} + \gamma^{2}\delta_{t + 2}) + \dots)}\\ & {\qquad = (1 - \lambda)(\delta_t(1 + \lambda +\lambda^{2} + \dots) + \gamma \delta_{t + 1}(\lambda +\lambda^{2} + \lambda^{3} + \dots) + \gamma^{2}\delta_{t + 2}(\lambda^{2} + \lambda^{3} + \lambda^{4} + \dots) + \dots)}\\ & {\qquad = (1 - \lambda)\Bigg(\delta_t\frac{1}{1 - \lambda} +\gamma \delta_{t + 1}\frac{\lambda}{1 - \lambda} +\gamma^{2}\delta_{t + 2}\frac{\lambda^{2}}{1 - \lambda} +\dots \Bigg)}\\ & {\qquad = \sum_{l = 0}^{\infty}(\gamma \lambda)^{l}\delta_{t + l}} \end{array} \quad (5.36)$$

其中，$\lambda \in [0,1]$ 是在GAE中额外引入的一个超参数。当 $\lambda = 0$ 时，$A_t^{\mathrm{GAE}} = \delta_t = R_t + \gamma V(s_{t + 1}) - V(s_t)$，也就是t时刻的步TD误差；当 $\lambda = 1$ 时，$A_t^{\mathrm{GAE}} = \sum_{l = 0}^{\infty}\gamma^{l}\delta_{t + l} = \sum_{l = 0}^{\infty}\gamma^{l}R_{t + l} - V(s_t) = G_t - V(S_t)$，也就是基线版本的REINFORCE改进算法。使用 $G_t$，方差大偏差小，使用 $R_t + \gamma V(s_{t + 1})$，偏差大方差小。所以 $\lambda$ 的大小控制的是“偏差-方差权衡”。

有上面的式子，我们还可以推导出一个递推公式

$$A_t^{\mathrm{GAE}} = \delta_t + \gamma \lambda A_{t + 1}^{\mathrm{GAE}} \quad (5.37)$$

下面是计算GAE的过程，给定 $\gamma$ 和 $\lambda$ 以及每个时间步的 $\delta_t$ 之后，我们可以根据公式直接进行优势估计。先前向（forward）计算每一个时刻的1步TD误差，然后再逆向（backward）计算每一个时刻的GAE。

首先，我们有 $n$ 个1步TD误差。

$$\mathrm{TD}_{\delta} = [\delta_t,\delta_{t + 1},\dots ,\delta_{t + n}] \quad (5.38)$$

先把数组逆序

$$\mathrm{TD}_{\delta} = [\delta_{t + n},\delta_{t + n - 1},\dots ,\delta_{t}] \quad (5.39)$$

然后遍历逆序数组，有如下结果：

$$\begin{array}{r l} & {A_{t + n}^{\mathrm{GAE}} = \delta_{t + n}}\\ & {A_{t + n - 1}^{\mathrm{GAE}} = \delta_{t + n - 1} + \gamma \lambda A_{t + n}^{\mathrm{GAE}}}\\ & {A_{t + n - 2}^{\mathrm{GAE}} = \delta_{t + n - 2} + \gamma \lambda A_{t + n - 1}^{\mathrm{GAE}}}\\ & {\qquad \vdots}\\ & {A_{t}^{\mathrm{GAE}} = \delta_{t} + \gamma \lambda A_{t + 1}^{\mathrm{GAE}}} \end{array} \quad (5.40)$$

这样每一个时间步的广义优势估计就计算出来了。

GAE目标

GAE Target = $A_t^{\mathrm{GAE}} + V(S_t)$

定理5.6—GAE的Actor-Critic策略梯度定理

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}A_t^{\mathrm{GAE}}\nabla_{\theta}\log \pi_{\theta}(a_t|s_t)\right] \quad (5.41)$$

提示

为了使符号更清晰，将动作 $A_t$ 改为 $a_t$，将状态 $S_t$ 改为 $s_t$。$A_t^{\mathrm{GAE}}$ 中的 $A$ 表示“Advantage”（优势）。
