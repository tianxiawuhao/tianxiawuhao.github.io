5.4 Actor-Critic（演员-评论家架构）

Posted on undefined，undefined min read

如果在上节介绍的带基线的REINFORCE中使用价值函数作为基线，那么就可以将其视为基于价值且基于策略的方法。本节将进一步改进带基线的REINFORCE，推导一个叫作Actor-Critic的算法。Actor-Critic也是基于价值且基于策略的方法。

5.4.1 Actor-Critic的数学推导

首先从复习带基线的REINFORCE开始。带基线的REINFORCE的目标函数的梯度的数学式如下所示。

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}(G_t - b(S_t))\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \quad (5.27)$$

上式中的 $G_t$ 表示回报，$b(S_t)$ 表示基线。可以使用任何函数作为基线。这里我们使用基于神经网络建模的价值函数作为基线。因此，我们要用到以下这些新的记号。

  • $\omega$：表示价值函数的神经网络的所有权重参数。
  • $V_{\omega}(S_t)$：将价值函数模型化的神经网络。

此时目标函数的梯度的数学式如下式所示

定理5.4—Actor-Critic架构的REINFORCE策略梯度定理

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}(G_t - V_{\omega}(S_t))\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \quad (5.28)$$

上式中存在一个问题，即只要没抵达目标，就无法确定回报 $G_t$ 的值。也就是说，在抵达目标之前，无法更新策略和价值函数。如果这是基于蒙特卡洛方法的算法，那么二者无法更新就是它的缺点。

蒙特卡洛采样

我们之前使用的是蒙特卡洛采样，也就是采样出一条完整的轨迹。然后更新策略神经网络 $\pi_{\theta}$。

消除这个缺点的方法是时序-差分方法（TD方法，Time Difference Method）。使用TD方法训练价值函数时，使用1个时间步（或 $n$ 个时间步）后的结果就能进行更新，如图所示。

如图所示，在训练价值函数 $V_{\omega}(S_t)$ 时，蒙特卡洛方法使用的是回报 $G_t$，而TD方法使用的是 $R_t + \gamma V_{\omega}(S_{t+1})$。

下面将基于蒙特卡洛（MC）方法的公式切换为TD方法，其中，代替 $G_t$ 的是 $R_t + \gamma V_{\omega}(S_{t+1})$。此时得到的式子如下所示。

定理5.5—1步TD误差的Actor-Critic策略梯度定理

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{T\sim \pi_{\theta}}\left[\sum_{t = 0}^{T}(R_t + \gamma V_{\omega}(S_{t+1}) - V_{\omega}(S_t))\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \quad (5.29)$$

t时刻的单步TD误差经常表示为 $\delta_t = R_t + \gamma V_{\omega}(S_{t+1}) - V_{\omega}(S_t)$

也就是在蒙特卡洛方法中，我们的训练目标是：通过训练使得 $V_{\omega}(S_t)$ 越来越接近 $G_t$。也就是使二者的均方误差损失越小越好，$(V_{\omega}(S_t) - G_t)^2 \rightarrow 0$。但是用 $G_t$ 作为 $V_{\omega}(S_t)$ 的预测目标有个问题，就是 $G_t$ 中包含的噪声很多，或者说 $G_t$ 是无偏估计，但是方差很大。相当于一名篮球运动员传了一次球这个动作的好坏，由比赛最终的输赢结果来评判。有一定的道理，但传球之后发生的事情太多了，传球那个动作的好坏的信号淹没在了噪声里面。后面的未来奖励受太多随机因素影响，所以 $G_t$ 波动很大。所以蒙特卡洛方法训练价值网络是一种偏差小但是方差很大的方法。

而在TD方法中，我们的训练目标是：通过训练使得 $V_{\omega}(S_t)$ 越来越接近 $R_t + \gamma V_{\omega}(S_{t+1})$。也就是使二者的均方误差损失越小越好，$(V_{\omega}(S_t) - (R_t + \gamma V_{\omega}(S_{t+1})))^2 \rightarrow 0$。这里替换的逻辑是：$G_t = R_t + \gamma G_{t+1}$，而 $V(S_{t+1}) = \mathbb{E}[G_{t+1}] \approx G_{t+1}$。如果 $V_{\omega}$ 是一个理想的真实的价值函数，那么根据贝尔曼期望方程 $V(S_t) = \mathbb{E}[G_t] = \mathbb{E}[R_t + \gamma V(S_{t+1})]$，使用 $R_t + \gamma V(S_{t+1})$ 替换掉 $G_t$ 是无偏估计的。可惜这里我们使用 $V_{\omega}$ 这个神经网络来拟合 $V$ 价值函数。所以势必会引入偏差。为什么TD方法会有偏差？因为预测目标TD Target：$R_t + \gamma V_{\omega}(S_{t+1})$ 本身就包含了一个 $V_{\omega}(S_{t+1})$ 预测值。如果 $V_{\omega}(S_{t+1})$ 没有学准，那么Target本身就是错误的。这就是偏差的来源。为什么TD方法的方差小？因为TD目标只包含：一个 $R_t$ 和神经网络的预测值 $V_{\omega}(S_{t+1})$，而神经网络的输出平滑，所以预测目标波动很小。所以方差很小。所以TD方法训练价值网络是一种偏差大但是方差小的方法，价值网络的学习速度（收敛速度）很快。

TD通常是低方差、高偏差，而MC通常是高方差、低偏差。

我们可以看到，我们的训练目标其实是单步TD误差趋近于0。这是因为，当目标函数到达极大值点时，对 $\theta$ 求得的梯度一定为0，所以单步TD误差也肯定为0。

概念

  • 单步TD误差（TD Error）：$R_t + \gamma V_{\omega}(S_{t+1}) - V_{\omega}(S_t)$
  • 单步TD目标（TD Target）：$R_t + \gamma V_{\omega}(S_{t+1})$

基于上面的公式的算法就是Actor-Critic。策略 $\pi_{\theta}$ 和价值函数 $V_{\omega}$ 是神经网络，我们要同时训练这两个神经网络。具体来说，对于策略 $\pi_{\theta}$ 要基于上面的公式进行训练；而对于价值函数 $V_{\omega}$，则通过TD方法，以接近 $R_t + \gamma V_{\omega}(S_{t+1})$ 为目标训练 $V_{\omega}(S_t)$ 这个神经网络。

提示

Actor-Critic中的Actor是演员（采取动作的人）的意思，也就是采取动作的人，相当于策略 $\pi_{\theta}$。而Critic是评论家的意思，相当于价值函数 $V_{\omega}$。因此，Actor-Critic的意思是“使用 $V_{\omega}$，来评论基于策略 $\pi_{\theta}$ 采取的动作的好坏”。

为什么可以用 $R_t + \gamma V_{\omega}(S_{t+1})$ 替换掉 $G_t$？

首先我们知道 $G_t = R_t + \gamma G_{t+1}$ 以及 $V_{\omega}(S_{t+1}) = \mathbb{E}[G_{t+1}]$。所以 $G_{t+1} \approx V_{\omega}(S_{t+1})$。

5.4.2 Actor-Critic的代码实现

下面实现Actor-Critic。策略和价值函数这两个神经网络的代码如下所示。

策略网络和价值网络

class PolicyNet(nn.Module):
    def __init__(self, action_size):
        super().__init__()
        self.l1 = nn.Linear(4, 128)
        self.l2 = nn.Linear(128, action_size)

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = F.softmax(self.l2(x), dim=1)
        return x

class ValueNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.l1 = nn.Linear(4, 128)
        self.l2 = nn.Linear(128, 1)

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = self.l2(x)
        return x

上面的代码将策略的网络实现了为PolicyNet类，将价值函数的网络实现为了ValueNet类。策略的最终输出是Softmax函数的输出，所以输出的是概率。接下来是Agent类的代码。

class Agent:
    def __init__(self):
        self.gamma = 0.98 # 折扣因子
        self.lr_pi = 0.0002 # 策略网络的学习率 α_actor
        self.lr_v = 0.0005 # 价值网络的学习率 α_critic
        self.action_size = 2
        # 初始化策略网络（演员网络）π_θ
        self.pi = PolicyNet(self.action_size)
        # 初始化价值函数网络（评论家网络）V_ω
        self.v = ValueNet()

        self.optimizer_pi = optim.Adam(self.pi.parameters(), lr=self.lr_pi)
        self.optimizer_v = optim.Adam(self.v.parameters(), lr=self.lr_v)

    def get_action(self, state):
        probs = self.pi(torch.tensor(state).unsqueeze(0)).squeeze(0)
        m = Categorical(probs)
        action = m.sample().item()
        return action, probs

    def update(
        self,
        state, # S_t
        action_prob, # π_θ(A_t|S_t)
        reward, # R_t
        next_state, # S_{t+1}
        done
    ):
        state = torch.tensor(state).unsqueeze(0) # S_t
        next_state = torch.tensor(next_state).unsqueeze(0) # S_{t+1}

        # ① self.v的损失：均方差
        # TD目标 = R_t + γV_ω(S_{t+1})
        target = reward + self.gamma * self.v(next_state) * (1 - done)
        v = self.v(state) # V_ω(S_t)
        loss_fn = nn.MSELoss() # (R_t + γV_ω(S_{t+1}) - V_ω(S_t))² → 0
        loss_v = loss_fn(v, target.detach()) # target要从计算图中剥离出去

        # ② self.pi的损失
        delta = target - v # δ = R_t + γV_ω(S_{t+1}) - V_ω(S_t)
        # -(R_t + γV_ω(S_{t+1}) - V_ω(S_t))logπ_θ(A_t|S_t)
        loss_pi = -torch.log(action_prob) * delta.detach().item()

        self.optimizer_v.zero_grad()
        self.optimizer_pi.zero_grad()
        loss_v.backward() # ∇_ω(R_t + γV_ω(S_{t+1}) - V_ω(S_t))²
        loss_pi.backward() # -(R_t + γV_ω(S_{t+1}) - V_ω(S_t))∇_θlogπ_θ(A_t|S_t)
        self.optimizer_v.step()
        self.optimizer_pi.step()

get_action方法可以基于策略取出动作。需要注意的是，由于输入到神经网络中的数据将作为小批量进行处理，因此在处理其中一个数据（状态）时需要小批量的轴。另外，get_action方法返回了两个值，即选择的动作及其概率。选择动作的概率将在稍后的损失函数计算中使用。

update方法可以训练价值函数和策略。在代码①处为价值函数（self.v）计算损失。为此要计算TD目标（target），求出当前状态下其与价值函数（v）的均方差。然后，在代码②处为策略（self.pi）计算损失。需要将其乘以-1的值作为损失。剩下的就是一直以来的神经网络的训练代码。

训练循环 Python

env = gym.make("CartPole-v0")
agent = Agent()
return_list = []
episode_list = []

for episode in range(2000):
    state = env.reset()
    done = False
    total_reward = 0

    while not done:
        action, probs = agent.get_action(state)
        next_state, reward, done, info = env.step(action)
        # 执行完一个动作，立即更新π和V,这两个网络
        agent.update(state, probs[action], reward, next_state, done)

        state = next_state
        total_reward += reward

    return_list.append(total_reward)
    episode_list.append(episode)
    if episode % 100 == 0:
        print("回合: { }, 总奖励: { }, 1f} ".format(episode, total_reward))

plot_loss(episode_list, return_list, "actor-critic-pg-loss.pdf")
test_agent(agent, env)
