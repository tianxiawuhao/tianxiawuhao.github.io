1. 机器学习总览

机器学习研究"如何让计算机从数据中自动获取规律"，核心是把经验（数据）转化为可泛化的决策能力。

1.1 四大范式

范式训练数据目标代表任务典型算法
监督学习 Supervised有标注 \((x, y)\)学映射 \(f: x \to y\)分类、回归线性模型、SVM、树模型
无监督学习 Unsupervised仅 \(x\)发现内在结构聚类、降维、密度估计K-means、PCA、GMM
半监督学习 Semi-supervised少量标注 + 大量无标注用无标注数据增强性能文本分类、医学影像FixMatch、伪标签
强化学习 Reinforcement与环境交互的奖励信号学最优策略 \(\pi^*\)控制、博弈、对齐Q-learning、PPO、GRPO

两个横切视角：

  • 自监督学习（Self-supervised）：从数据自身构造监督信号（掩码预测、对比学习），是预训练时代的主力范式，可视为"无监督目标 + 有监督形式"。
  • 按输出空间：离散 → 分类；连续 → 回归；结构化（序列、图、集合）→ 序列标注、图学习、检测与分割。

1.2 学习理论的三个基本概念

  • 经验风险最小化（ERM）：
\[\hat{\theta} = \arg\min_\theta \frac{1}{N}\sum_{i=1}^{N} \mathcal{L}\big(f_\theta(x_i), y_i\big) + \lambda\,\Omega(\theta)\]

第一项是拟合数据的能力，\(\Omega(\theta)\) 是正则项（L1/L2、树复杂度、Dropout），\(\lambda\) 控制强度。

  • 泛化：模型在未见数据上的表现。测试误差可分解为
\[\mathbb{E}[\text{Err}] = \text{Bias}^2 + \text{Variance} + \text{Noise}\]
  • 欠拟合：偏差主导 —— 模型容量不足，训练误差就很高；<ul><li><strong>过拟合</strong>：方差主导 —— 训练误差低但测试误差高；</li><li><strong>应对</strong>：增加数据、数据增强、正则化、早停、集成、降低模型容量。</li></ul>
  • 没有免费午餐定理（No Free Lunch）：不存在对所有问题都最优的算法，模型选择必须结合数据分布与任务先验。

1.3 数据准备与特征工程

  • 数据质量优先于模型复杂度：清洗（缺失值、异常值）、去重、标注一致性校验。
  • 特征工程：数值标准化/归一化、类别编码（One-Hot、Target Encoding、Embedding）、分箱、交叉特征、时间特征（滑窗、周期编码）。
  • 数据泄漏（Data Leakage）：最隐蔽的致命错误 —— 归一化统计量、目标编码、特征选择都必须在训练折内拟合；时间序列严禁用未来信息。
  • 数据不平衡：重采样（SMOTE、欠采样）、类别权重、Focal Loss、阈值调优。
  • 数据划分与分布漂移：训练/验证/测试保持同分布；上线后监控 PSI、KS、特征覆盖率。

2. 监督学习

利用已标注数据学习 \(f_\theta\)，用于对新数据预测。

2.1 线性与广义线性模型

  • 线性回归：\(\hat{y} = w^\top x + b\)；最小二乘有闭式解 \(w^* = (X^\top X)^{-1}X^\top y\)，加入 \(\lambda I\) 得到岭回归（Ridge，L2）以保证可逆并抑制共线性。
  • 逻辑回归：二分类，把线性输出压到概率空间
\[p(y=1\mid x) = \sigma(w^\top x + b), \qquad \sigma(z) = \frac{1}{1+e^{-z}}\]

损失为交叉熵 \(\mathcal{L} = -\big[y\log\hat{p} + (1-y)\log(1-\hat{p})\big]\)，无闭式解，用梯度下降/牛顿法求解。扩展到多类即 Softmax 回归。

  • 判别式 vs 生成式：逻辑回归直接建模 \(p(y\mid x)\)；朴素贝叶斯建模 \(p(x\mid y)p(y)\)，二者在特定假设下等价（高斯判别分析 GDA）。
  • 正则化族：Lasso（L1，产生稀疏解、可做特征选择）、Ridge（L2，压缩系数）、ElasticNet（两者混合）。

2.2 支持向量机 SVM

  • 最大间隔超平面：
\[\min_{w,b}\ \frac{1}{2}\|w\|^2 \quad \text{s.t.}\quad y_i(w^\top x_i + b) \ge 1\]
  • 软间隔：引入松弛变量 \(\xi_i\) 与惩罚系数 \(C\)，允许少量越界样本；\(C\) 越大越不容忍错误（更易过拟合）。
  • 核技巧：用核函数 \(K(x_i,x_j)=\phi(x_i)^\top\phi(x_j)\) 隐式升维，处理非线性边界。常用线性核、多项式核、RBF（高斯）核、Sigmoid 核。
  • 适用与局限：中小规模、高维稀疏（文本）、边界清晰场景表现好；训练复杂度 \(O(N^2)\sim O(N^3)\)，大规模数据不如线性模型与树模型。

2.3 决策树

  • 递归选择最优特征与切分点，把特征空间划分为若干矩形区域。
  • 划分准则：ID3 用信息增益，C4.5 用信息增益率（支持连续值与缺失值），CART 用基尼指数且只做二叉划分。
\[\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2, \qquad \text{Gain}(D,A) = H(D) - \sum_{v}\frac{|D_v|}{|D|}H(D_v)\]
  • 剪枝：预剪枝（限制深度/叶样本数/最小增益）与后剪枝（代价复杂度剪枝 CCP）。
  • 特点：可解释性强、无需归一化、支持混合类型特征；单棵树方差大、易过拟合。

2.4 集成学习

策略机制代表主要降低
Bagging并行训练 + 自助采样 + 投票/平均随机森林、ExtraTrees方差
Boosting串行训练、逐步纠正残差AdaBoost、GBDT、XGBoost偏差
Stacking用元学习器组合基模型输出各类堆叠方案两者
  • 随机森林：对样本做 Bootstrap 抽样，且每次分裂只在随机特征子集上选最优，降低树间相关性；对噪声鲁棒、几乎不需调参，是表格数据的强基线。
  • 梯度提升树 GBDT：串行拟合前一轮的负梯度（回归问题即残差）
\[F_m(x) = F_{m-1}(x) + \nu\, h_m(x), \qquad h_m \approx -\frac{\partial \mathcal{L}}{\partial F}\]

\(\nu\) 为学习率（收缩系数），越小越稳但需要更多轮；配合行/列子采样可进一步抗过拟合。

  • 三大工程实现对比：

| 维度 | XGBoost | LightGBM | CatBoost |

| --- | --- | --- | --- |

| 分裂策略 | 预排序 + 近似分位 | 直方图 + Leaf-wise（带深度限制） | 对称/遗忘树 + 有序提升 |

| 速度 | 中 | 快（大数据集尤佳） | 中 |

| 类别特征 | 需手动编码 | 原生支持 | 原生支持（目标统计，抗泄漏） |

| 强项 | 精度与生态成熟 | 大规模、低内存 | 类别特征多、小数据抗过拟合 |

| 主要风险 | 内存占用高 | 叶生长过深易过拟合 | 训练相对慢 |

  • 2025 现状：结构化/表格数据上 GBDT 仍是默认最强基线，通常优于同量级深度模型；实践中常与神经网络融合或作为特征工程后的最终模型。

2.5 朴素贝叶斯

  • 假设特征在给定类别下条件独立：
\[p(y\mid x) \propto p(y)\prod_{j=1}^{d} p(x_j \mid y)\]
  • 变体：高斯（连续特征）、多项式（词频）、伯努利（词是否出现）。
  • 优点：训练与预测极快、小样本可用、天然支持增量更新；缺点：独立性假设常不成立，概率估计有偏（但分类决策往往仍可用）。
  • 典型场景：文本分类、垃圾邮件过滤、情感初筛、新闻主题归类。

2.6 K 近邻 KNN

  • 惰性学习：不显式训练，预测时找最近的 \(k\) 个样本投票（分类）或平均（回归）。
  • 距离度量：欧氏、曼哈顿、余弦、马氏；\(k\) 小方差大、\(k\) 大方差小但偏差大。
  • 加速结构：KD 树、球树、HNSW/IVF 等近似最近邻（ANN）索引。
  • 缺点：预测需遍历数据、对维度灾难与特征尺度敏感（必须先归一化）。

2.7 其他常考模型

  • 感知器与线性判别：线性可分性、感知器收敛定理。
  • 因子分解机 FM / 场感知 FM（FFM）：处理高维稀疏特征交叉，推荐系统经典。
  • 广义加性模型 GAM：\(g(\mathbb{E}[y]) = \sum_j f_j(x_j)\)，兼顾非线性与可解释性（如 Explainable Boosting Machine）。
  • 异常检测：Isolation Forest（孤立森林）、One-Class SVM、LOF、自编码器重构误差。

2.8 模型评估与选择

任务指标说明
分类准确率、精确率 \(P\)、召回率 \(R\)、\(F_1=\frac{2PR}{P+R}\)类别不平衡时准确率会失真
分类（排序）ROC-AUC、PR-AUC、KSPR-AUC 在极不平衡时更可靠
概率校准Brier Score、ECE、可靠性曲线判断"预测概率是否可信"
回归MSE、RMSE、MAE、\(R^2\)、MAPERMSE 放大异常值影响，MAE 更鲁棒
排序/推荐NDCG、MAP、Recall@K、AUC关注头部位置质量
  • 评估协议：留出法、\(k\) 折交叉验证、分层抽样、分组交叉验证（避免同组泄漏）、时间序列滚动验证。

  • 统计显著性：交叉验证的均值差异需配合 t 检验/Wilcoxon 检验，避免"随机种子噪声"当作提升。
  • 调参：网格/随机搜索、贝叶斯优化（TPE、Optuna）、Hyperband/ASHA 早停式搜索、多目标（精度 vs 延迟）。

3. 无监督学习

处理未标注数据，发现数据内在结构：聚类、降维、密度估计、异常检测。

3.1 聚类

  • K-means：最小化簇内平方误差
\[J = \sum_{k=1}^{K}\sum_{x \in C_k} \|x - \mu_k\|^2\]

交替执行"分配—更新"直到收敛。需预设 \(K\)（肘部法、轮廓系数、Gap Statistic），对初值敏感（用 K-means++ 初始化）、对尺度敏感。变体：Mini-Batch K-means（大数据）、球形 K-means（文本）。

  • 层次聚类：自底向上合并（AGNES）或自顶向下分裂（DIANA），用单链/全链/平均链/Ward 准则度量簇间距离，输出树状图；无需预设 \(K\)，复杂度 \(O(N^2)\) 以上。

  • DBSCAN：基于密度，核心点需在 \(\varepsilon\) 邻域内包含至少 MinPts 个样本；能发现任意形状簇并识别噪声，无需预设 \(K\)，但参数敏感、高维退化。改进：OPTICS、HDBSCAN。
  • 高斯混合模型 GMM：假设数据由 \(K\) 个高斯分布混合生成，用 EM 算法迭代估计
\[p(x) = \sum_{k=1}^{K}\pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)\]

E 步算后验责任 \(\gamma_{ik}\)，M 步加权重估参数；输出软分配，是 K-means 的概率化推广（协方差取各向同性且趋零时退化为 K-means）。

  • 谱聚类：在相似度图的拉普拉斯矩阵特征空间上做 K-means，擅长非凸簇。
  • 聚类评估：外部指标（ARI、NMI、纯度）与内部指标（轮廓系数、DB 指数、CH 指数）。

3.2 降维

  • 主成分分析 PCA：寻找方差最大的正交方向，等价于协方差矩阵的特征分解
\[\max_{w,\,\|w\|=1} w^\top \Sigma w \quad\Longrightarrow\quad \Sigma w = \lambda w\]

取前 \(k\) 个特征向量投影。变体：核 PCA（非线性）、增量 PCA、随机化 SVD（大规模）。注意：必须先中心化，且对量纲敏感。

  • 线性判别分析 LDA：有监督降维，最大化类间散度与类内散度之比 \(J(w)=\frac{w^\top S_B w}{w^\top S_W w}\)。
  • t-SNE：高维用高斯、低维用 \(t\) 分布（重尾）度量相似度，最小化 KL 散度。仅适合可视化（通常 2D），不保留全局结构，perplexity 影响显著，不能直接用于新样本。
  • UMAP：基于黎曼几何与拓扑数据分析，速度更快、更好保留全局结构，可用于下游任务。
  • 自编码器 AE：用编码器-解码器重构误差学习低维瓶颈表示，实现非线性降维；变体 VAE、去噪 AE、稀疏 AE。
  • 矩阵分解类：截断 SVD、NMF（非负、可解释的部分-整体分解）、字典学习。

3.3 密度估计与关联规则

  • 参数化方法：高斯分布、混合模型、最大似然估计。
  • 非参数方法：核密度估计（KDE）、直方图、\(k\) 近邻密度估计。
  • 异常检测视角：低密度区域即异常；常用 Isolation Forest、LOF、COPOD。
  • 关联规则挖掘：Apriori、FP-Growth；度量支持度（Support）、置信度（Confidence）、提升度（Lift）；经典应用是购物篮分析。

3.4 自监督表示学习

不依赖人工标注，从数据自身构造监督信号，学到的表示可迁移到下游任务。

  • 对比学习：拉近正样本对、推远负样本对，常用 InfoNCE 损失
\[\mathcal{L} = -\log \frac{\exp\big(\text{sim}(z_i, z_i^+) / \tau\big)}{\sum_{j} \exp\big(\text{sim}(z_i, z_j) / \tau\big)}\]
  • 代表：SimCLR（大 batch + 强增强）、MoCo（动量编码器 + 队列，解耦 batch 大小）、BYOL / SimSiam（无负样本，靠预测器与非对称结构防塌缩）、SwAV（聚类分配）。<ul><li>关键要素：数据增强策略、温度系数 \(\tau\)、负样本数量与质量、大批量训练。</li></ul>
  • 掩码建模：遮住部分输入并重建。<ul><li><strong>MAE</strong>：只编码 25% 可见 patch，训练效率高，ViT-Huge 在 ImageNet-1K 上纯自监督达 87.8% Top-1；</li><li><strong>BEiT / SimMIM</strong>：预测离散 token 或原始像素；</li><li><strong>BERT</strong>：NLP 侧的掩码语言建模（MLM）。</li></ul>
  • 自蒸馏：DINO / DINOv2（1.42 亿张图像上预训练，学生-教师自蒸馏 + 多裁剪，特征无需微调即可用于分割与深度估计）、iBOT。
  • 2025 趋势：自监督预训练已是视觉与多模态的默认起点；对比学习重心从"图像-图像"转向"图像-文本"（CLIP 系）与多模态对齐。

4. 半监督学习

结合少量标注与大量无标注数据，缓解标注成本。

  • 一致性正则：同一样本施加不同扰动，要求预测一致。代表：\(\Pi\)-Model、Mean Teacher、UDA、FixMatch（弱增强生成伪标签 + 强增强约束一致性）。
  • 伪标签 / 自训练：用模型给无标注数据打标签，筛选高置信样本加入训练；本质是熵最小化。风险是确认偏误（错误标签自我强化）。
  • 基于图的方法：样本为节点、相似度为边，标注通过图结构传播（Label Propagation / Label Spreading）：
\[\mathcal{L} = \sum_{i,j} W_{ij}\big\|f_i - f_j\big\|^2 + \mu\sum_{i \in L}\big\|f_i - y_i\big\|^2\]
  • 基于生成模型：用 GAN/VAE/扩散模型生成或重构样本扩充数据；或让判别器兼作分类器（Semi-Supervised GAN、BadGAN）。
  • 熵最小化与低密度分离：鼓励决策边界穿过低密度区域（Semi-supervised SVM / TSVM）。
  • 2025 趋势：LLM 弱监督正在替代经典半监督算法 —— 用大模型自动标注/生成训练数据往往更省事且效果更好；半监督经典方法主要用于视觉小样本、医疗影像等低资源领域。

5. 强化学习

通过智能体（Agent）与环境的交互学习最优策略，形式化为马尔可夫决策过程（MDP）：\(\langle \mathcal{S}, \mathcal{A}, P, R, \gamma \rangle\)。

5.1 核心概念

  • Agent（智能体）：学习与决策的主体，如游戏角色、机器人、LLM 本身。
  • Environment（环境）：智能体所处世界，如棋盘、3D 城市、用户。
  • State（状态）\(s\)：环境在某一时刻的完整描述，如棋盘布局。<ul><li>状态转移函数：\(s_{t+1} = f(s_t, a_t)\)，描述动作如何改变状态；</li><li><strong>马尔可夫性</strong>：\(P(s_{t+1}\mid s_t, a_t) = P(s_{t+1}\mid s_1,a_1,\dots,s_t,a_t)\)，即"无记忆性"；</li><li>部分可观测时用观测 \(o_t\) 建模为 <strong>POMDP</strong>。</li></ul>
  • Action（动作）\(a\)：可执行操作集合。<ul><li><strong>离散</strong>动作空间（棋子移动方向）便于穷举；<strong>连续</strong>动作空间（方向盘角度）需要策略网络直接输出。</li></ul>
  • Reward（奖励）\(r\)：<ul><li>即时奖励 \(R_{t+1}\)：单步反馈信号；</li><li>累积回报 \(G_t = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1}\)，\(\gamma \in [0,1)\) 为折扣因子；</li><li><strong>稀疏奖励</strong>问题：长期任务中有效反馈极少（如航天器对接），需奖励塑形、内在激励、课程学习。</li></ul>
  • Policy（策略）\(\pi\)：\(\pi(a\mid s)\) 表示在状态 \(s\) 下选择动作 \(a\) 的概率。<ul><li>确定性策略 \(a = \mu_\theta(s)\)：高效、无探索，适合连续控制（DDPG、TD3）；</li><li>随机性策略 \(\pi_\theta(a\mid s)\)：具备探索能力，适合离散动作与探索-利用平衡。</li></ul>
  • Value Function（价值函数）：
\[V_\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s], \qquad Q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]\]
\[A_\pi(s,a) = Q_\pi(s,a) - V_\pi(s) \quad (\text{优势函数})\]
  • 贝尔曼方程：价值函数的递归关系，是动态规划与 TD 学习的理论基础。
\[V_\pi(s) = \sum_a \pi(a\mid s)\Big[R(s,a) + \gamma \sum_{s'} P(s'\mid s,a)\, V_\pi(s')\Big]\]
\[Q_\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'\mid s,a)\sum_{a'}\pi(a'\mid s')\, Q_\pi(s',a')\]

最优价值满足贝尔曼最优方程 \(V^*(s) = \max_a\big[R(s,a) + \gamma\sum_{s'}P(s'\mid s,a)V^*(s')\big]\)。

  • 蒙特卡洛树搜索 MCTS：结合随机采样与树搜索，四步循环 —— 选择（按 UCB 下行）→ 扩展（新增子节点）→ 模拟（随机 rollout 估回报）→ 回溯（更新路径统计量）。不依赖马尔可夫性，适合围棋等复杂/部分可观测环境（AlphaGo/AlphaZero 用 MCTS + 策略价值网络）。

5.3 价值学习（Value-Based）

通过估计价值函数间接推导策略（隐式策略：选最大价值动作），一般基于 TD 算法。

  • Q-learning：Off-policy，用贪婪目标更新，直接逼近 \(Q^*\)：
\[Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]\]
  • SARSA：On-policy，用当前策略实际采取的下一步动作更新：
\[Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma Q(s',a') - Q(s,a)\big]\]

更保守、更稳，但收敛到的是当前策略的价值。

  • DQN：Q-learning 的深度版本，用神经网络近似 \(Q\)，两大稳定机制：<ul><li><strong>经验回放</strong>：缓存 \((s,a,r,s')\) 随机采样 mini-batch，打破时序相关性、提高利用率。改进 <strong>PER</strong> 按 TD 误差加权采样 \(P(i) \propto |\delta_i|^\alpha\) 并用重要性采样纠偏。</li><li><strong>目标网络</strong>：参数定期从主网络复制、期间冻结，目标值</li></ul>
\[y = r + \gamma \max_{a'} Q_{\text{target}}(s', a')\]

避免"追逐移动目标"导致震荡。

  • DQN 改进族：<ul><li><strong>Double DQN</strong>（解决 Q 值<strong>高估</strong>，分离动作选择与价值评估）：</li></ul>
\[y = r + \gamma\, Q_{\text{target}}\big(s', \arg\max_{a'} Q_{\text{main}}(s', a')\big)\]
  • Dueling DQN（分解状态价值与动作优势）：
\[Q(s,a) = V(s) + \Big(A(s,a) - \tfrac{1}{|\mathcal{A}|}\sum_{a'} A(s,a')\Big)\]
  • 多步学习：\(y = \sum_{k=0}^{n-1}\gamma^k r_{t+k} + \gamma^n \max_{a'}Q(s_{t+n},a')\)，加速奖励传播。<ul><li><strong>分布式 DQN</strong>（C51 / QR-DQN / IQN）：建模回报<strong>分布</strong>而非期望，增强不确定性表达。</li><li><strong>Noisy Net</strong>：在网络参数上加噪，替代 \(\varepsilon\)-greedy 实现状态相关的探索。</li><li><strong>Rainbow</strong>：整合上述改进，是离散动作 DQN 系列的集大成者。</li></ul>

5.4 策略学习（Policy-Based）

直接参数化策略并优化期望回报 \(J(\theta) = \mathbb{E}_{\tau\sim\pi_\theta}[G(\tau)]\)，由策略梯度定理：

\[\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\big[\nabla_\theta \log \pi_\theta(a_t\mid s_t)\cdot \hat{A}_t\big]\]

\(\hat{A}_t\) 为优势估计，用于降低方差；通常引入 Critic 辅助（Actor-Critic 框架）。

  • REINFORCE：以整条轨迹的回报 \(G_t\) 为权重的蒙特卡洛策略梯度，无偏但方差极大。
  • A3C：多线程智能体并行探索、异步更新全局参数，用优势函数减方差。
  • A2C：A3C 的同步版本，集中式批量更新，实现更简单、GPU 利用率更高。
  • PPO：当前最通用基线，用重要性采样比加裁剪限制更新幅度：
\[r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)}, \qquad \mathcal{L}^{\text{CLIP}} = \mathbb{E}\Big[\min\big(r_t\hat{A}_t,\ \text{clip}(r_t, 1-\epsilon, 1+\epsilon)\hat{A}_t\big)\Big]\]

常配 GAE 优势估计、价值损失与熵正则。

  • 连续控制三件套：<ul><li><strong>DDPG</strong>：确定性策略 + Q-learning（off-policy），加噪声探索；</li><li><strong>TD3</strong>：双 Critic 抑制高估 + 延迟策略更新 + 目标动作平滑；</li><li><strong>SAC</strong>：最大熵 RL，目标含熵项 \(\mathbb{E}\big[\sum_t \gamma^t\big(r_t + \alpha\mathcal{H}(\pi(\cdot\mid s_t))\big)\big]\)，样本效率与稳定性俱佳。</li></ul>
  • 信赖域方法：TRPO（KL 约束）、自然策略梯度（Fisher 信息矩阵）；PPO 是其"廉价近似"。

5.5 离线强化学习（Offline RL）与前沿方向

  • 离线 RL / Batch RL：只能从固定数据集学习，禁止在线交互（医疗、金融、推荐）。核心难题是分布外（OOD）动作的外推误差。<ul><li>代表算法：BCQ、<strong>CQL</strong>（保守 Q 学习，压低 OOD 动作价值）、<strong>IQL</strong>（隐式 Q 学习，避免查询 OOD 动作）、TD3+BC、<strong>Decision Transformer</strong>（把 RL 变成序列建模）。</li></ul>
  • 基于模型的 RL：Dreamer 系列（在潜空间中"想象" rollout）、MuZero（学隐式动力学 + MCTS），样本效率远高于 model-free。
  • 多智能体 RL（MARL）：MADDPG、QMIX、MAPPO；难点在非平稳性与信用分配。
  • 探索机制：内在奖励（ICM、RND）、计数法、熵正则、汤普森采样。
  • 模仿学习：行为克隆（BC）、逆强化学习（IRL）、GAIL。
  • RL + 大模型：见 §7.5.3，RLHF/DPO/GRPO 已成为 LLM 对齐与推理能力提升的标准工具。

5.6 典型应用

  • 游戏与博弈：Atari（DQN）、围棋（AlphaGo/AlphaZero）、星际争霸（AlphaStar）、Dota（OpenAI Five）。
  • 机器人：抓取、 locomotion、灵巧操作；仿真到现实（Sim2Real）迁移。
  • 推荐与广告：把用户反馈作为奖励，做长期价值优化（与 bandit 问题衔接）。
  • 系统优化：数据中心制冷（DeepMind）、芯片布局、编译器优化、网络调度。
  • 大模型对齐与推理：见 §7.5.3、§7.6。

6. 深度学习基础与主流网络

6.1 神经网络基础

  • 感知器：\(y = \text{sign}(w^\top x + b)\)，只能解决线性可分问题（XOR 不可解）。

  • 多层感知器 MLP 与万能逼近定理：含单隐层、足够多神经元的前馈网络可以任意精度逼近紧集上的连续函数。
  • 激活函数：Sigmoid（易梯度消失）、Tanh、ReLU（缓解梯度消失、计算廉价）、LeakyReLU、GELU/SiLU（Transformer 与主流 CNN 常用）、Swish。
  • 反向传播：链式法则逐层回传梯度
\[\frac{\partial \mathcal{L}}{\partial W^{(l)}} = \delta^{(l)}\big(a^{(l-1)}\big)^\top, \qquad \delta^{(l)} = \big(W^{(l+1)\top}\delta^{(l+1)}\big) \odot \phi'\big(z^{(l)}\big)\]

  • 训练技巧：<ul><li>权重初始化：Xavier/Glorot（tanh）、He（ReLU）；</li><li>归一化：BatchNorm、<strong>LayerNorm</strong>（Transformer 必备）、RMSNorm、GroupNorm；</li><li>正则化：Dropout、权重衰减、Label Smoothing、数据增强、早停；</li><li><strong>残差连接</strong>（ResNet）解决深层网络的退化问题；</li><li>优化器：SGD+Momentum、Adam、<strong>AdamW</strong>（解耦权重衰减）、LAMB（超大 batch）、Lion；</li><li>学习率调度：Warmup + Cosine/Linear Decay、OneCycle、ReduceLROnPlateau。</li></ul>
  • 其他经典网络：Hopfield 网络（联想记忆）、自组织映射 SOM（拓扑保持的无监督聚类）、学习矢量量化 LVQ。

6.2 卷积神经网络 CNN

  • 核心组件：<ul><li><strong>卷积层</strong>：卷积核滑动提取局部特征，具备<strong>局部连接、权值共享、平移等变性</strong>；</li><li><strong>池化层</strong>：下采样降低分辨率与计算量，扩大感受野；</li><li><strong>全连接层</strong>：整合特征输出预测。</li></ul>

  • 感受野：多层小卷积核（如 3×3）堆叠可在同等参数下获得更大感受野与更强非线性。
  • 经典架构演进：LeNet → AlexNet → VGG → ResNet（残差连接，深度突破百层）→ Inception → DenseNet → EfficientNet（复合缩放）→ ConvNeXt（CNN 的现代化改造）→ ViT/Swin（Transformer 进入视觉）。

  • 主要任务：图像分类、目标检测（§9.2）、语义/实例分割、关键点、超分辨率。
  • 现代化训练配方：强数据增强（Mixup/CutMix/RandAugment）、标签平滑、EMA、长训练周期 + 大 batch。

6.3 循环神经网络与序列建模

  • 基本结构：\(h_t = \phi(W_h h_{t-1} + W_x x_t + b)\)，输出 \(y_t = g(W_o h_t)\)；参数在时间上共享。

  • 问题：长序列上梯度消失/爆炸（可用梯度裁剪缓解），难以捕捉长距离依赖。
  • 门控变体：<ul><li><strong>LSTM</strong>：遗忘门 \(f_t\)、输入门 \(i_t\)、输出门 \(o_t\) 与细胞状态 \(C_t\) 控制信息流：</li></ul>
\[f_t = \sigma(W_f[h_{t-1},x_t]), \quad i_t = \sigma(W_i[h_{t-1},x_t]), \quad C_t = f_t \odot C_{t-1} + i_t \odot \tanh(W_C[h_{t-1},x_t])\]

  • GRU：合并为更新门与重置门，参数更少、训练更快。

  • 双向与堆叠：BiRNN 同时利用前后文；深层堆叠提升表达力。
  • 历史地位与现状：曾是 NLP/语音主力（seq2seq + 注意力）；Transformer 出现后逐步边缘化。但 RNN 思想以新形式回归 —— 线性注意力、SSM/Mamba 本质是"可并行训练的递归"，在长序列推理时具备 \(O(1)\) 记忆与 \(O(N)\) 计算优势。

6.4 生成模型

  • 自编码器 AE / 变分自编码器 VAE：VAE 学潜变量分布，优化证据下界
\[\mathcal{L}_{\text{ELBO}} = \mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big] - D_{\text{KL}}\big(q_\phi(z\mid x)\,\|\,p(z)\big)\]

生成平滑但偏模糊。

  • 生成对抗网络 GAN：生成器 \(G\) 与判别器 \(D\) 对抗训练
\[\min_G \max_D\ \mathbb{E}_{x\sim p_{\text{data}}}\big[\log D(x)\big] + \mathbb{E}_{z\sim p_z}\big[\log\big(1 - D(G(z))\big)\big]\]

代表作：DCGAN、StyleGAN（高质量人脸）、CycleGAN（无配对图像翻译）、Pix2Pix。难点：训练不稳定、模式坍塌；技巧：WGAN-GP、谱归一化、TTUR。

  • 扩散模型 Diffusion：前向逐步加噪，反向学习去噪 \(\epsilon_\theta\)，目标极简
\[\mathcal{L} = \mathbb{E}_{t,x_0,\epsilon}\big\|\epsilon - \epsilon_\theta(x_t, t)\big\|^2\]

代表：DDPM、DDIM（加速采样）、Latent Diffusion / Stable Diffusion（潜空间扩散）、DiT（Transformer 骨干）。优点：训练稳定、质量与多样性俱佳；缺点：采样步数多、推理慢。

  • 流匹配 Flow Matching / 整流模型：直接回归从噪声到数据的速度场 \(v_\theta(x_t,t)\)，绕开扩散的随机微分方程框架，训练更直接、采样步数更少。SD3、Flux 等采用该范式，是 2024–2025 生成模型主流路线之一。
  • 归一化流 Normalizing Flow：可逆变换精确计算似然，适合密度估计与异常检测。
  • 自回归生成：逐 token/像素建模 \(p(x)=\prod_t p(x_t\mid x_{<t})\)，GPT 系列与 PixelCNN 属于此类。

6.5 注意力机制

  • 通用注意力（跨序列）：查询 \(Q\) 与键 \(K\) 做相似度打分、Softmax 归一化后加权求和值 \(V\)：
\[\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V\]

其中 \(1/\sqrt{d_k}\) 用于稳定梯度。作用是为解码器动态提供源序列上下文，缓解固定长度向量瓶颈，擅长机器翻译、文本生成等跨序列任务。

  • 自注意力（同序列内部）：<ul><li>每个词经 \(W_Q, W_K, W_V\) 线性变换得到 \(q, k, v\)；</li></ul>

  • 以某词为中心，用它的 \(q\) 与所有词的 \(k\) 做点积，Softmax 得到权重，再对所有 \(v\) 加权求和作为该词的输出；<ul><li>直观记忆：<strong>Query 是"我想找什么"，Key 是"我有什么标签"，Value 是"我实际提供的内容"</strong>；</li><li>复杂度 \(O(N^2 d)\)，长序列是瓶颈 → 稀疏注意力、线性注意力、FlashAttention（IO 感知的精确加速）、滑窗/分块注意力。</li></ul>

  • 多头注意力：把表示切分为 \(h\) 个子空间并行做注意力再拼接：
\[\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O\]

  • 掩码注意力：解码器用因果掩码（只可见左侧），保证自回归生成不"偷看"未来。
  • 位置编码：正弦位置编码、可学习位置嵌入、RoPE（旋转位置编码，主流 LLM 标配）、ALiBi、相对位置编码；配合长度外推技术（NTK 插值、YaRN）扩展上下文窗口。

6.6 图神经网络（GNN）

处理图结构数据（分子、社交网络、知识图谱、推荐）。

  • 消息传递范式：\(h_v^{(l+1)} = \phi\big(h_v^{(l)}, \square_{u\in\mathcal{N}(v)} \psi(h_u^{(l)}, h_v^{(l)})\big)\)，即"聚合邻居 + 更新自身"。
  • 代表模型：GCN（谱域简化）、GraphSAGE（采样聚合，支持归纳）、GAT（注意力加权邻居）、GIN（表达力上界）、MPNN。
  • 任务：节点分类、链接预测、图分类、图生成。
  • 难点：过平滑（层数加深导致表示趋同）、过挤压（长距离信息瓶颈）、可扩展性（邻居爆炸，用 GraphSAINT/Cluster-GCN 采样）。
  • 与 LLM 结合：GraphRAG（§7.7）、分子性质预测、知识图谱补全。

6.7 深度强化学习

  • 用神经网络表示策略 \(\pi_\theta(a\mid s)\) 或价值 \(Q_\theta(s,a)\)。
  • 代表：DQN（Atari）、AlphaGo/AlphaZero（MCTS + 自我对弈）、PPO（机器人控制、LLM 对齐）、SAC（连续控制）。
  • 要点：样本效率低（并行环境、经验回放、基于模型方法缓解）、奖励设计困难、训练不稳定（目标网络、双 Q、梯度裁剪缓解）。

6.8 分布式训练与加速

  • 并行策略：数据并行（DDP）、张量并行（TP）、流水线并行（PP）、序列并行、专家并行（MoE），组合为 3D/4D 并行。
  • 显存优化：ZeRO-1/2/3、梯度检查点（Activation Checkpointing）、混合精度（FP16/BF16/FP8）、FlashAttention、CPU Offload、QLoRA。
  • 训练稳定性：梯度裁剪、loss scale、BF16 优先、日志与断点续训、数据配比监控。
  • 通信优化：NVLink/InfiniBand、梯度压缩、重叠计算与通信。

7. 大语言模型（LLM）

7.1 核心任务

  • 文本生成：对话、代码生成、故事/文案创作、摘要。
  • 语义理解：文本分类、情感分析、信息抽取、问答。
  • 知识推理：逻辑推理、数学计算、多步任务规划、工具调用（Agent）。
  • 多模态：图文问答、文档解析、语音/视频理解（GPT-4o、Qwen3-Omni 等全模态模型）。

7.2 Transformer 总体结构

整体数据流：输入序列 → 编码器（理解）→ 中间表示 → 解码器（生成）→ 输出序列。

  • 输入部分：<ul><li><strong>输入嵌入</strong>：把 token 映射为固定维度向量，捕捉语义；</li><li><strong>位置编码</strong>：Transformer 本身无序列感知能力，需显式注入位置信息（正弦编码或 RoPE）。</li></ul>
  • 编码器：由 \(N\) 个相同层堆叠，每层含
  • 多头自注意力：捕捉序列内元素关系，双向可见；
  • 前馈网络 FFN：对每个位置独立做线性变换 + 激活（通常是两层 MLP，中间维度约 4 倍）。

每个子模块后接残差连接 + LayerNorm 以稳定训练。

  • 解码器：由 \(N\) 个相同层堆叠，每层含三个子模块
  • 掩码多头自注意力：只能看到左侧已生成的 token；
  • 交叉注意力：\(Q\) 来自解码器、\(K/V\) 来自编码器输出，用于对齐输入与输出；
  • 前馈网络 FFN。
  • 输出部分：线性层把隐藏状态映射到词表维度，Softmax 得到下一个 token 的概率分布。

  • 复杂度与现代优化：自注意力 \(O(N^2)\) → FlashAttention 1/2/3（分块 + IO 感知，精确且显著提速省显存）、GQA/MQA（分组/多查询注意力，压缩 KV Cache）、KV Cache 量化、MoE 稀疏激活。

7.3 三种架构范式

范式注意力典型任务代表模型
Encoder-only完全双向理解型：分类、NER、语义匹配、检索BERT、RoBERTa、ERNIE、DeBERTa
Decoder-only因果掩码（只看左侧）生成型：续写、对话、代码GPT-2/3/4/4o、LLaMA、Qwen、DeepSeek、Mistral
Encoder-Decoder编码器双向 + 解码器交叉注意力序列到序列：翻译、摘要T5、BART、Pegasus、mT5

  • BERT 系预训练目标：MLM（随机掩码 token 预测）+ NSP（RoBERTa 证明 NSP 有害并弃用）。
  • Decoder-only 为何胜出：训练目标统一（下一 token 预测）、易于扩展、零样本/少样本泛化强、天然支持统一的多任务与多模态接口。
  • 架构前沿（2025）：<ul><li><strong>MoE</strong>：每个 token 只激活部分专家（如 DeepSeek-V3/R1 总参数 671B、每 token 激活约 37B），容量与算力解耦；难点在负载均衡与通信开销。</li></ul>

  • 状态空间模型 SSM / Mamba：以选择性扫描实现线性复杂度与 \(O(1)\) 推理记忆，长序列高效。<ul><li><strong>混合架构</strong>：注意力层与 Mamba/SSM 层交错 + MoE —— 代表 <strong>Jamba</strong>（注意力:Mamba = 1:7，每两个块插入 MoE）、<strong>RWKV-7 / RWKV-X</strong>（线性复杂度、支持长度外推）、Zamba、Hymba。2025 年共识是"纯注意力"与"纯 SSM"各有短板，混合是工程最优解。</li><li><strong>线性注意力与高效注意力</strong>：RetNet、GLA、Lightning Attention，追求训练可并行、推理递归。</li><li><strong>多模态架构</strong>：统一 token 化 + 跨模态对齐，视觉编码器（ViT/SigLIP）+ 投影层 + LLM 解码器是主流范式。</li></ul>

7.4 Tokenizer 分词器

把自然语言通过"词典"映射为整数 ID（数字就是单词在词典中的页码）。

方法原理优点缺点
BPE从字符出发，反复合并最高频相邻符号对简单高效、平衡词表与长度纯频率驱动、语义弱；对形态丰富语言不友好
WordPiece合并能最大化语言模型概率的子词对（似然驱动）语义关联更强、缓解 OOV需预设词表大小；训练需迭代优化概率，复杂度高
SentencePiece把文本视为 Unicode 字节/字符序列，直接在原始文本上划分子词，无需语言相关预处理多语言友好（中日等无空格语言）、端到端训练长词易被过度切分、token 数变多；对特殊符号敏感
Unigram LM从大词表出发，按语言模型概率剪枝出最优子词集合相同词表规模下编码效率通常最优、词表可动态调整训练计算成本高、实现与调参复杂
  • 补充：Byte-level BPE（GPT-2 起采用，彻底消除 OOV）；tiktoken（OpenAI 的高性能 BPE 实现）；WordPiece 与 BPE 的关键差异在于合并判据是"似然增益"而非"频率"。
  • 工程要点：词表大小（常用 32K–256K）、特殊 token 设计（BOS/EOS/PAD、对话角色、工具调用）、多语言与代码的 token 效率（中文压缩率直接影响成本与有效上下文长度）。

7.5 训练与微调全流程

典型流水线：预训练 → 监督微调 → 偏好对齐（可选）→ 蒸馏/量化部署。

7.5.1 预训练（Pretrain）

  • 目标：让参数中"充满知识的墨水"。首先要学的不是交流，而是下一 token 预测（词语接龙）：输入"秦始皇"，能接龙"是中国的第一位皇帝"。
  • 数据：Wiki、书籍、网页、代码、论文等大规模高质量语料；关键在于清洗、去重（MinHash/LSH）、质量过滤、配比与课程。
  • 特性：过程"无监督"（无需人工标注），模型自行从文本中总结规律。
  • 算力与规模：Scaling Law 指导参数量、数据量与算力的最优配比（Chinchilla 最优化：数据量约为参数量的 20 倍）。
  • 现代目标变体：因果语言建模（CLM）、前缀语言建模、填空式（FIM，代码补全）、多 token 预测（MTP，DeepSeek-V3 用于提升推理与训练效率）。

7.5.2 监督微调 SFT

  • 预训练后的模型只会"接龙"，SFT 施加对话模板（多轮 问题→回答 结构）做指令微调。
  • 损失为 token 级交叉熵（通常只对回答部分计算）：
\[\mathcal{L}_{\text{SFT}} = -\sum_{t \in \text{answer}} \log \pi_\theta(y_t \mid x, y_{<t})\]
  • 数据质量远比数量重要（LIMA 的"少而精"结论）：指令多样性、难度分布、拒绝采样筛选、多轮比例。
  • 相关技术：指令微调、多任务混合、模板一致性、序列打包（packing）、loss masking。

7.5.3 偏好对齐：RLHF / DPO / GRPO

RLHF：基于人类反馈的强化学习

让模型知道"什么回答好、什么差"。

  • 三阶段：SFT → 训练奖励模型 RM（Bradley-Terry 偏好建模）→ 用 PPO 优化策略并加 KL 约束：
\[\max_\pi\ \mathbb{E}_{x\sim D,\, y\sim \pi}\big[r_\phi(x,y)\big] - \beta\, D_{\text{KL}}\big(\pi(\cdot\mid x)\,\|\,\pi_{\text{ref}}(\cdot\mid x)\big)\]
  • 代价：需同时驻留策略、参考、奖励、价值四个模型，显存与工程复杂度高；人类反馈昂贵且有偏差。

DPO：直接偏好优化

  • 通过推导 PPO 奖励模型的显式解，把在线 RL 换成离线偏好数据上的分类式损失，参考模型输出可预先缓存；只需策略与参考两个模型，显存与稳定性显著优于 PPO。
  • 损失形式（\(y_w\) 偏好回答，\(y_l\) 被拒回答）：
\[\mathcal{L}_{\text{DPO}} = -\log \sigma\Big(\beta \log\frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \beta \log\frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\Big)\]
  • 变体：IPO、KTO（只需二元反馈）、ORPO/SimPO（免参考模型）、cDPO、RLAIF（用 AI 反馈替代人工）。

GRPO：组相对策略优化

  • PPO 的简化版：去掉价值网络，用同一问题下一组回答的组内奖励归一化作为优势估计
\[\hat{A}_i = \frac{r_i - \text{mean}(\{r_j\}_{j=1}^{G})}{\text{std}(\{r_j\}_{j=1}^{G})}\]
  • 只需策略与参考两个模型；与可验证奖励（RLVR：数学答案匹配、代码单测、格式约束） 结合时，无需人工推理轨迹即可激发出长链思维（CoT）、自我验证、反思与"顿悟时刻（Aha Moment）"。
  • 改进变体：<ul><li><strong>DAPO</strong>：非对称裁剪（Clip-Higher，防熵崩溃）+ 动态采样（过滤全对/全错批次）+ token 级损失（缓解长序列梯度稀释）；</li><li><strong>Dr.GRPO</strong>：移除长度与标准差归一化，消除"偏好长回答"和"难度偏置"；</li><li><strong>RLOO</strong>：留一均值作基线，无偏且更简单，可视为 GRPO 前身；</li><li><strong>GSPO</strong>：序列级重要性比率，进一步稳定长序列训练。</li></ul>

趋势判断：偏好对齐更多提升"礼貌"（有用性、安全性、风格）而非"智力"；推理能力提升主要来自 RLVR + 可验证奖励。偏好对齐本身有利有弊 —— 样本成本高、反馈偏差、多样性损失。

7.5.4 知识蒸馏 KD

  • 思想：学生模型面向教师模型学习；教师是充分训练的大模型。
  • 硬标签 vs 软标签：SFT 拟合 one-hot 硬标签；KD 用教师 softmax 分布作软标签并以 KL 损失对齐（\(T\) 为温度）：
\[\mathcal{L}_{\text{KD}} = \text{KL}\big(p_{\text{teacher}}(\cdot\mid x, T)\,\|\,p_{\text{student}}(\cdot\mid x, T)\big)\]

直观理解：SFT 学"老师的答案"，KD 学"老师大脑里神经元的激活状态"（如 1+1=2 时某神经元输出 100、另一个 -99）。

  • 目的：让小模型体积更小、效果更好，降低部署成本。
  • 白盒 / 黑盒：<ul><li><strong>白盒蒸馏</strong>：可访问教师内部结构（logits、中间层、注意力），如 DistilBERT、MiniLLM；</li><li><strong>黑盒蒸馏</strong>：只能学教师输出数据，即"用大模型生成数据做 SFT"（闭源模型只能如此），是大模型时代最普遍的做法，与 SFT 流程完全一致，差别只在数据来源。</li></ul>

7.5.5 LoRA 与参数高效微调 PEFT

LoRA：低秩适配

  • 冻结预训练权重 \(W_0\)，只学低秩增量：
\[h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} B A x, \qquad B \in \mathbb{R}^{d\times r},\ A \in \mathbb{R}^{r\times k},\ r \ll \min(d,k)\]
  • 可训练参数常降至原模型的 0.01%–1%；推理时可合并回 \(W_0 + BA\)，不增加延迟。

PEFT 全景（2025）：

类别方法说明
低秩重参数化LoRA、QLoRA（4-bit NF4 + 双量化 + 分页优化器）、AdaLoRA（自适应秩）、DoRA（权重分解为幅度与方向）、LoRA+、rsLoRA、LoHa/LoKr主流首选，工程最成熟
加性适配器Adapter、AdapterFusion、Compacter引入额外模块，推理有延迟
软提示Prompt Tuning、P-Tuning v2、Prefix Tuning不改权重，占用上下文长度
选择性微调BitFit（只调 bias）、LayerNorm 微调极轻量，效果有限
其他IA³、SSF、VeRA、MoRA特定场景补充
  • 选择建议：资源受限优先 LoRA/QLoRA；追求极致质量用全参 SFT 或 DoRA；多任务/多租户用 LoRA 热插拔；长上下文微调注意位置编码与长度分布。

工具链依赖关系：

transformers（Hugging Face 基础库：模型 / 分词器 / Trainer）
   ├── PEFT（LoRA/QLoRA 等适配器，量化依赖 bitsandbytes）
   │      └── QLoRA = 4-bit 量化基座 + LoRA
   └── TRL（RLHF 训练库：SFTTrainer / PPO / DPO / GRPO，可结合 PEFT 的 LoRA）
          └── 可对接 Unsloth 加速与省显存

7.6 推理模型与测试时计算

  • 范式转变：DeepSeek-R1 证明"冷启动 SFT + 大规模 RL（GRPO + 可验证奖励）"可从基座中"涌现"出推理能力。
  • R1 的四阶段流程：
  • 冷启动 SFT：少量高质量长 CoT 示例建立推理格式；
  • 推理专项 RL：规则奖励（答案正确性、格式、语言一致性）驱动 GRPO；
  • 拒绝采样 + SFT：从阶段 2 采样最优轨迹并混合通用数据重训，恢复通用能力；
  • 全场景 RL：在阶段 3 检查点上再跑一轮 GRPO，并引入偏好奖励（有用性、安全性）。
  • 经验结论：作者在 Qwen-1.5B 上较快复现了 Zero 过程的数学推理，但一个共识是 —— 参数太小的模型仅靠冷启动 SFT + GRPO 几乎无法获得可用推理效果（通常需要 >3B 量级基座）。
  • 测试时计算扩展：把算力花在推理而非训练 —— 长链思维、自洽性投票、Best-of-N、过程奖励模型（PRM）、树搜索（MCTS/Beam）。代表系统：OpenAI o 系列、DeepSeek-R1、Claude Extended Thinking、Gemini Thinking。
  • 蒸馏路线：面向强模型输出数据做蒸馏，是"最快、最稳、最经济"的推理模型获取方式，但上限受教师限制。
  • 2025 趋势：推理与通用能力统一到同一模型（混合思考模式，按需切换思考长度）；RL 从文本扩展到全模态。

7.7 检索增强生成 RAG

  • 动机：缓解幻觉、领域知识缺失、知识过时，且无需重训模型。
  • 基础流程：文档切分（Chunking）→ 向量化（Embedding）→ 向量检索（Top-k）→ 重排（Rerank）→ 拼接上下文生成。
  • 范式演进：
  • Naive RAG：检索-生成直连；
  • Advanced RAG：检索前（查询改写、HyDE、多查询）+ 检索后（重排、压缩、上下文裁剪）；
  • Modular RAG：模块化编排检索、路由、记忆、工具；
  • GraphRAG：以知识图谱承载实体关系，支持多跳推理与全局摘要，工作流为"图索引 → 图引导检索 → 图增强生成"，代表实现 Microsoft GraphRAG、LightRAG、KAG；
  • Agentic RAG：LLM 自主决定何时检索、检索什么、是否多轮检索，并结合工具调用。
  • 工程要点：分块策略与重叠、混合检索（BM25 + 稠密向量）、元数据过滤、查询改写与多跳、重排模型、上下文长度与成本权衡、引用溯源与忠实性评估（RAGAS 等）。
  • 挑战：多跳错误累积、图构建与维护成本、检索与生成的联合优化、评测标准不统一。

7.8 数据工程、幻觉与评估

  • 数据工程：语料清洗与去重、质量分类器、领域配比、合成数据（Self-Instruct、Evol-Instruct）、数据溯源与版权合规。
  • 幻觉（Hallucination）缓解：RAG 与引用、工具与代码执行校验、自洽性投票、过程监督、拒答机制、温度与解码策略调整。
  • 能力评估：MMLU/MMLU-Pro（知识）、GPQA（专家问答）、GSM8K/MATH/AIME（数学）、HumanEval/MBPP/SWE-bench（代码）、IFEval（指令遵循）、LMSYS Chatbot Arena（人类偏好 Elo）。
  • 对齐与安全：红队测试、越狱防御、有害内容过滤、引用溯源、RLHF/RLAIF 安全对齐、Constitutional AI；重点风险包括幻觉、偏见、隐私泄漏、提示注入（尤其 Agent 场景）。
  • 部署优化：量化（INT8/INT4、GPTQ、AWQ、GGUF）、蒸馏、剪枝、投机解码、连续批处理、PagedAttention（vLLM）、KV Cache 复用、MoE 专家并行；推理引擎：vLLM、TensorRT-LLM、SGLang、llama.cpp、Ollama。

7.9 Agent 与工具使用

  • 核心循环：规划（Plan）→ 调用工具（Act）→ 观察结果（Observe）→ 反思修正（Reflect）。
  • 关键能力：函数调用（Function Calling）、结构化输出、多步规划、记忆（短期上下文 + 长期向量库）、自我验证。
  • 协议与生态（2024–2025）：MCP（Model Context Protocol） 统一模型与外部工具/数据源的接入方式；A2A 等智能体互操作协议；LangGraph、AutoGen、CrewAI 等编排框架。
  • 评测：AgentBench、SWE-bench、WebArena、τ-bench（工具使用与多轮任务）。
  • 风险：错误累积、工具滥用、提示注入导致越权操作、成本失控；工程上需要沙箱、权限最小化、人工确认关键动作。

8. 语音合成（TTS）

8.1 核心任务

  • 前端处理：文本正则化（TN，数字/符号/缩写展开）、分词与注音、韵律预测（停顿、重音、语调）。
  • 声学建模：文本 → 声学特征（梅尔频谱等）。
  • 波形合成：声学特征 → 语音波形（声码器 Vocoder）。

8.2 技术特点

  • 声学模型：自注意力 + 时长预测器（Duration Predictor） 是主流（FastSpeech 系、VITS 系）；
  • 声码器：逆自回归（Parallel WaveNet）、GAN（HiFi-GAN、BigVGAN）生成高质量音频；
  • 端到端：文本直接映射波形（VITS、Tacotron 2 + Vocoder 联合优化），减少级联误差。

8.3 现代范式与代表模型（2023–2025）

范式代表模型特点
零样本语音克隆VALL-E / VALL-E 2、CosyVoice / CosyVoice 2、F5-TTS、Fish-Speech、IndexTTS、XTTS-v2仅需 3–10 秒参考音频即可克隆音色，支持跨语言音色迁移与情感控制（instruct 模式）
自回归 codec 语言模型VALL-E、CosyVoice、Spark-TTS把音频离散化为 codec token，用 LLM 式自回归生成，天然统一 TTS 与语音理解

  • 关键技术词：神经音频编解码（SoundStream、EnCodec）、RVQ/FSQ 残差矢量量化、无文本对齐（免 G2P 的字符级合成）、声音转换与情感解耦、韵律可控性（语速/停顿/情感标签）。
  • 落地要点：克隆音色的合规与授权（声纹属敏感生物特征）、多说话人零样本稳定性、长文本拼接自然度、中英混读与数字读法。

9. 计算机视觉：OCR 与目标检测

原稿把"目标检测"挂在 OCR 之下，这里拆为独立小节：OCR 是上层任务，目标检测（含文本检测）是其技术基础。

9.1 OCR（光学字符识别）

核心任务

  1. 文本检测：定位图像中的文字区域（任意形状、密集、多方向）；
  2. 文本识别：把文字区域转为可编辑文本；
  3. 结构化解析：表格、公式、版式、手写体的结构化还原（文档理解）。

技术特性

  • 文本检测：基于 CNN 的特征金字塔网络（FPN） 是主流（DBNet、PSENet、FCENet）；
  • 文本识别：CNN + RNN + CTC/Attention 混合架构（CRNN、ASTER），或纯 Transformer/CTC；
  • 端到端系统：检测与识别联合训练（PGNet、ABCNet），减少级联误差；
  • 大模型时代的新范式：多模态大模型直接做端到端文档 OCR 与理解，典型流水线为 版面检测（DocLayout-YOLO）→ 分块轻量 LLM 识别 → 跨块逻辑关系预测；代表模型有 Donut、Nougat（公式/论文）、GOT-OCR2.0、Qwen-VL 系、InternVL、dots.ocr。传统 OCR 仍在小语种、低算力、高吞吐场景具备成本优势。

应用场景

  • 票据处理：银行支票、发票自动识别与审核；
  • 工业质检：产品标签信息提取与合规校验；
  • 古籍数字化：复杂版式文献识别与检索；
  • 办公自动化：合同比对、表格抽取、证件识别。

9.2 目标检测方法

（1）传统方法

  • 区域选择（穷举策略：滑动窗口 + 多尺度 + 多长宽比遍历，时间复杂度极高）；
  • 特征提取（SIFT、HOG 等；形态多样性、光照变化、背景多样性导致手工特征鲁棒性差）；
  • 分类器分类（SVM、AdaBoost 等）；代表：Haar + AdaBoost（人脸）、HOG + SVM（行人）、DPM。

（2）候选区域 + 深度学习分类（两阶段）

  • R-CNN：① 输入测试图像；② 用选择性搜索（Selective Search）自底向上提取约 2000 个候选区域 Region Proposal；③ 把大小不一的候选区域缩放（warp）到统一尺寸（227×227）送入 CNN，取 fc7 层输出作为特征；④ 用每个候选区域的特征训练 SVM 分类器（另用回归器微调框）。

  • SPP-net：空间金字塔池化，共享卷积计算，不再逐个 warp。
  • Fast R-CNN：Selective Search + CNN + ROI Pooling，分类与框回归统一到一个网络，端到端训练。

  • Faster R-CNN：用 RPN（区域提议网络） 替代 Selective Search，实现真正端到端，是两阶段方法的经典基线。
  • R-FCN：位置敏感得分图，提升精度与速度；后续演进 Mask R-CNN（加分割分支）、Cascade R-CNN（级联阈值提纯）。

（3）基于深度学习的回归方法（单阶段）

  • YOLO：① 输入图像划分为 \(S\times S\) 网格（原版 7×7）；② 每个网格预测 \(B\) 个边界框（含目标置信度与各类别概率）；③ 得到 \(S\times S\times B\) 个候选窗口后，按阈值滤除低置信度框，再用 NMS（非极大值抑制） 去除冗余窗口。<ul><li>版本演进：YOLOv3（FPN 多尺度）→ YOLOv5/v8（工程化与生态）→ YOLOv9/v10 → <strong>YOLO11</strong>（2024）→ <strong>YOLO26</strong>（2025-09，主打关键架构改进与端到端推理）。</li></ul>
  • SSD：多尺度特征图预测 + 默认框（anchor），速度与精度平衡。
  • DenseBox / CornerNet / CenterNet：无锚框（anchor-free）路线，减少超参。
  • FCOS、ATSS：anchor-free 单阶段的重要改进。

（4）基于 Transformer 的检测器

  • DETR：把检测视为集合预测，Transformer 编解码 + 二分图匹配（匈牙利算法）去掉 NMS；缺点是收敛慢。
  • Deformable DETR：可变形注意力，显著加速收敛。
  • DINO：当前 DETR 系精度标杆（对比去噪训练 + 混合查询选择）。
  • RT-DETR / RT-DETRv2：实时检测 Transformer，直接输出最终检测结果、无需 NMS 后处理，在实时场景对标 YOLO。
  • 2025 现状：实时场景以 YOLO11/YOLO26 与 RT-DETR 系为两大主力；精度优先用 DINO 系与 Co-DETR；开放词汇检测（Grounding DINO、YOLO-World）与"检测 + 分割 + 描述"统一的多模态模型成为新范式。

9.3 图像分割

  • 语义分割：逐像素分类。FCN → U-Net（医学）→ DeepLab（空洞卷积 + ASPP）→ SegFormer/Mask2Former。
  • 实例分割：Mask R-CNN、YOLACT、SOLO。
  • 全景分割：统一"可数物体 + 背景区域"。
  • 通用/可提示分割：SAM / SAM 2（提示驱动，零样本迁移到任意图像与视频），是 2023–2025 的重要范式转变。

9.4 关键配套技术

  • NMS 与变体：Soft-NMS、DIoU-NMS；端到端模型逐步去 NMS。
  • 损失函数：IoU/GIoU/DIoU/CIoU、Focal Loss（解决正负样本失衡）、Varifocal Loss。
  • 训练技巧：Mosaic/MixUp 增强、多尺度训练、EMA、标签分配（SimOTA、Task-Aligned Assigner）。
  • 评价指标：mAP@[.5:.95]、AP50、FPS/延迟、参数量与 FLOPs。

10. 多模态与生成式视觉

  • 图文对齐：CLIP（对比学习对齐图像与文本，支撑零样本分类与检索）、ALIGN、SigLIP；BLIP/BLIP-2（理解 + 生成）。
  • 视觉指令微调：LLaVA、Qwen-VL、InternVL、Idefics —— 用"图像 + 指令 → 文本"数据把视觉编码器接入 LLM。
  • 统一生成：Stable Diffusion 3 / Flux（MMDiT + 流匹配）、DALL·E 3、Imagen。
  • 视频生成：Sora（时空 patch + DiT）、可灵、Veo；难点在时序一致性、物理合理性与长时长。
  • 图像编辑与可控生成：ControlNet、IP-Adapter、InstructPix2Pix、修复/扩图（Inpainting/Outpainting）。
  • 3D 与场景：NeRF、3D Gaussian Splatting、多视图重建；与扩散模型结合做文本到 3D。
  • 评测：FID、CLIPScore、GenEval、VBench（视频）等。
