王树森深度强化学习笔记4：Actor-Critic Method（AC Method）

Posted on 2023-12-25，6 min read

Actor-Critic（简称 AC）把策略学习（Policy-Based Learning）和价值学习（Value-Based Learning）结合起来：用一个神经网络决定动作，用另一个神经网络给动作打分，两者互相依赖、同时训练。

Actor 是策略网络，用来控制 Agent 运动，可以看做「运动员」；Critic 是价值网络，用来给动作打分，可以看做「裁判」。运动员依据裁判的评分改进动作，裁判则根据环境返回的奖励修正自己的判断。

一、价值网络和策略网络（Value Network and Policy Network）

先回顾状态价值函数 \(V_\pi(s)\)：它是对动作价值函数 \(Q_\pi(s,a)\) 关于动作的加权平均，权重由策略 \(\pi(a\mid s)\) 给出。动作离散时，\(V_\pi(s)=\sum_{a\in\mathcal{A}}\pi(a\mid s)\,Q_\pi(s,a)\)；动作连续时，\(V_\pi(s)=\int_{\mathcal{A}}\pi(a\mid s)\,Q_\pi(s,a)\,\mathrm{d}a\)。

固定状态 \(s\) 时，\(V_\pi(s)\) 越大说明策略 \(\pi\) 越好；固定策略 \(\pi\) 时，\(V_\pi(s)\) 越大说明状态 \(s\) 越有利。AC 方法用两个神经网络分别近似策略 \(\pi\) 与动作价值 \(Q_\pi\)，从而在没有环境模型的情况下也能估计并改进策略。

1）策略网络（Policy Network）（Actor）

用策略网络 \(\pi(a\mid s;\theta)\) 近似策略函数 \(\pi(a\mid s)\)，\(\theta\) 是一个可训练的神经网络参数。

以超级玛丽为例，该网络只有一个输入：状态 \(s\)，也就是游戏的一帧画面。网络内部依次做两件事：

  • 用卷积层把一帧画面变成特征向量；
  • 用全连接层把特征向量变成与动作空间（Action Space）中元素个数相同的向量，再经 Softmax 激活函数归一化，得到各动作概率之和为 1 的策略分布 \(\pi(a\mid s;\theta)\)。

动作离散时，网络输出的每个分量就是「在该状态下选择某个动作」的概率，例如向左、向右、向上、跳跃各占多少；动作连续时，网络通常输出高斯分布的均值与标准差，再从该分布中采样。要注意策略网络只负责产生动作，它自己并不知道动作是好是坏——判断好坏是 Critic 的工作。

2）价值网络（Value Network）（Critic）

用价值网络 \(q(s,a;w)\) 近似动作价值函数 \(Q_\pi(s,a)\)，\(w\) 是一个可训练的神经网络参数。

还是以超级玛丽为例，该网络有两个输入：状态 \(s\) 和动作 \(a\)。状态 \(s\) 是一帧画面，动作 \(a\) 是策略网络刚刚做出的选择（离散动作可用独热编码 One-Hot Encoding 表示）。两个输入的处理方式不同：

  • 状态 \(s\)：用卷积层提取特征，得到状态特征向量；
  • 动作 \(a\)：用全连接层提取特征，得到动作特征向量。

把两个特征向量拼接成一个更高维的向量，再经一个全连接层输出一个实数 \(q(s,a;w)\)，它就是 Critic 对「在状态 \(s\) 下执行动作 \(a\)」这一选择的打分。

需要区分的是：这里的 \(q(s,a;w)\) 评估的是当前策略 \(\pi\) 的动作价值 \(Q_\pi\)，而不是最优动作价值 \(Q^\star\)。后者是 DQN 的学习目标，两者的差别见笔记2：价值学习。

3）两个网络的关系与参数共享

把两个网络接在一起，就得到状态价值函数的一个参数化近似：

\[ V_\pi(s)\;\approx\;V(s;\theta,w)=\sum_{a}\pi(a\mid s;\theta)\,q(s,a;w). \]

也就是说，Actor 给出「每个动作有多大概率被选中」，Critic 给出「每个动作值多少分」，两者的加权和就是对当前状态的价值估计。

价值网络和策略网络中的参数是可以共享的（例如共用同一个卷积主干，最后再分出两个头），也可以各自独立；共享时两个网络的梯度会叠加在一起。无论是否共享，同时训练价值网络和策略网络，就是 Actor-Critic Method（AC Method）。

二、训练神经网络（Train the Neural Network）

两个网络的参数 \(\theta\) 与 \(w\)，更新目标并不一样：

  • 更新 \(\theta\) 是为了让状态价值 \(V(s;\theta,w)\) 变大。\(V(s;\theta,w)\) 是对策略和状态的评价：固定状态 \(s\) 时它越大说明策略越好，固定策略 \(\pi\) 时它越大说明状态 \(s\) 越有利。让 \(\theta\) 沿着 \(V\) 的梯度方向上升，就是让 Actor 变强。
  • 更新 \(w\) 是为了让 Critic 的打分更精准，从而更好地估计未来奖励的总和。Critic 相当于裁判，一开始并没有打分能力，初始阶段的打分都是瞎猜的；它靠环境给的奖励 \(r\) 不断修正 \(w\)，打分才会越来越准。

一次完整的更新包含五个步骤：

  1. 观测当前状态 \(s_t\)，用策略网络采样动作 \(a_t\sim\pi(\cdot\mid s_t;\theta_t)\) 并执行；
  2. 环境返回奖励 \(r_t\) 和新状态 \(s_{t+1}\)；
  3. 用策略网络在 \(s_{t+1}\) 处再采样一个动作 \(\tilde a_{t+1}\sim\pi(\cdot\mid s_{t+1};\theta_t)\)，它只用于构造 TD 目标，Agent 不会真正执行它；
  4. 用 TD 算法更新价值网络：\(w_t\to w_{t+1}\)；
  5. 用策略梯度（带 baseline）更新策略网络：\(\theta_t\to\theta_{t+1}\)。

注意第 3、4、5 步用到的都是更新前的参数 \(w_t,\theta_t\)；\(\theta\) 与 \(w\) 可以在同一次迭代里一起更新。

1）使用时序差分算法更新价值网络q（Update Value Network q Using TD）

用 TD 算法更新价值网络 \(q\) 时，先获取 Actor 在 \(t\) 时刻与 \(t+1\) 时刻的状态 \(s_t,s_{t+1}\)、动作 \(a_t\) 以及采样动作 \(\tilde a_{t+1}\)，此时 Critic 的参数为 \(w_t\)。TD 目标（TD target）为

\[ y_t=r_t+\gamma\,q(s_{t+1},\tilde a_{t+1};w_t), \]

它用「立即奖励 + 折扣后的下一步打分」来近似 \(t\) 时刻的真实回报。把 \(q(s_t,a_t;w)\) 与 \(y_t\) 的差距写成损失函数（通常取平方误差的一半）：

\[ L(w)=\tfrac12\big[q(s_t,a_t;w)-y_t\big]^2,\qquad \frac{\partial L(w)}{\partial w}=\big(q(s_t,a_t;w)-y_t\big)\frac{\partial q(s_t,a_t;w)}{\partial w}. \]

再做一步梯度下降，就得到新的参数 \(w_{t+1}\)：

\[ w_{t+1}=w_t-\alpha\,\delta_t\,\frac{\partial q(s_t,a_t;w_t)}{\partial w},\qquad \delta_t=q(s_t,a_t;w_t)-y_t. \]

其中 \(\alpha\) 是学习率，\(\delta_t\) 称为时序差分误差（TD error）：\(\delta_t>0\) 表示 Critic 的打分高于 TD 目标（高估了），\(\delta_t<0\) 表示低估了。不同教材对 \(\delta_t\) 的符号约定可能相反，本文统一采用上式。

\(\tilde a_{t+1}\) 只是为了凑出 TD 目标而采样的一次动作，环境不会真的执行它。这也是 AC 与蒙特卡洛方法的重要差别：TD 只需要一步转移就能更新，不必等回合结束，代价是自举（bootstrap）带来了偏差——MC 与 TD 的偏差-方差权衡见笔记5。

2）使用策略梯度更新策略网络π（Update Policy Network π Using Policy Gradient）

策略网络的目标是让 \(V(s;\theta,w)\) 变大，因此需要 \(V\) 关于 \(\theta\) 的梯度。由策略梯度定理：

\[ \frac{\partial V(s;\theta)}{\partial\theta}=\mathbb{E}_{A\sim\pi(\cdot\mid s;\theta)}\left[\frac{\partial\ln\pi(A\mid s;\theta)}{\partial\theta}\,Q_\pi(s,A)\right]. \]

等式右边是关于动作 \(A\) 的期望，而 \(Q_\pi\) 是未知的——这正好可以用 Critic 的打分 \(q(s_t,a_t;w)\) 来代替。按策略 \(\pi\) 随机抽取一个动作 \(a_t\)，单个 \(g(a_t,\theta)\) 就是整体期望的无偏估计，这里用的是蒙特卡洛近似：

\[ g(a_t,\theta_t)=\frac{\partial\ln\pi(a_t\mid s_t;\theta_t)}{\partial\theta}\,q(s_t,a_t;w_t). \]

然后对该样本做一次随机梯度上升（Stochastic Gradient Ascent，SGA）来更新 \(\theta\)，得到 \(\theta_{t+1}\)：

\[ \theta_{t+1}=\theta_t+\beta\,q(s_t,a_t;w_t)\,\frac{\partial\ln\pi(a_t\mid s_t;\theta_t)}{\partial\theta}, \]

其中 \(\beta\) 是策略网络的学习率。直观理解：如果 Critic 给 \(a_t\) 的打分 \(q_t>0\)，就提高在 \(s_t\) 下选择 \(a_t\) 的概率；如果打分为负，就降低这个概率。

与 REINFORCE 一类纯策略梯度方法相比，AC 的梯度权重来自 Critic 的打分而不是一整条回合的真实回报，因此每走一步就能更新一次；代价是 Critic 的估计带有偏差，策略梯度也随之有偏。这一点在笔记3：策略学习中已经讨论过。

3）带 baseline 的策略梯度：优势函数与 A2C

直接用 \(q_t\) 当权重有一个问题：它的尺度依赖环境与回合长度，方差较大。可以在权重里减去一个只与状态有关的量 \(b(s)\)（称为 baseline），它不会改变梯度的期望：

\[ \mathbb{E}_{A\sim\pi}\left[\frac{\partial\ln\pi(A\mid s;\theta)}{\partial\theta}\,b(s)\right]=b(s)\sum_{a}\frac{\partial\pi(a\mid s;\theta)}{\partial\theta}=b(s)\frac{\partial}{\partial\theta}\left(\sum_{a}\pi(a\mid s;\theta)\right)=0, \]

因为策略分布的概率之和恒为 1，它对 \(\theta\) 的导数恒为 0。最好的 baseline 就是状态价值函数本身，即 \(b(s)=V_\pi(s)\)——问题在于它同样未知，而 Critic 恰好能给出它的估计。减掉 baseline 之后，权重剩下的部分正是优势函数（Advantage Function）：

\[ A_\pi(s,a)=Q_\pi(s,a)-V_\pi(s), \]

它衡量「在状态 \(s\) 下选择动作 \(a\)，比按当前策略随机选动作平均好多少」。Critic 还能免费给出优势的估计——TD 误差 \(\delta_t\) 就是优势的一个单步估计：

\[ A_\pi(s_t,a_t)\;\approx\;\delta_t=q(s_t,a_t;w_t)-\big(r_t+\gamma\,q(s_{t+1},\tilde a_{t+1};w_t)\big). \]

于是策略网络的更新变成

\[ \theta_{t+1}=\theta_t+\beta\,\delta_t\,\frac{\partial\ln\pi(a_t\mid s_t;\theta_t)}{\partial\theta}, \]

这就是基线策略梯度（Policy Gradient with Baseline），文献里也常称为 A2C（Advantage Actor-Critic）：Actor 用优势 \(\delta_t\) 加权，Critic 用 TD 误差更新，两个网络共用同一个误差信号，实现上非常紧凑。相比直接用 \(q_t\)，\(\delta_t\) 的数值范围小得多，方差更低、收敛更快也更稳。

使用 baseline 有一条硬性约束：baseline 不能是 \(a_t\) 的函数，即不能与 \(a_t\) 存在映射关系。否则上式中的期望不再为 0，梯度就会产生偏差。换句话说，任何接近 \(q_t\)、但不由 \(a_t\) 决定的数，都可以拿来当 baseline。

实践中还会把 \(\delta_t\) 推广为多步回报或 GAE（Generalized Advantage Estimation），进一步平衡偏差与方差；A3C 则用多个并行的 Agent 异步收集数据，把这一思路推向工程实现。

4）算法总结（Summary of Algorithm）

把上面的流程整理成一张表，四个环节依次执行、循环往复：

环节做什么用到的信号
Actor 决策观测状态 \(s_t\)，按 \(\pi(\cdot\mid s_t;\theta_t)\) 采样动作 \(a_t\) 并执行\(\theta_t\)
环境反馈获得奖励 \(r_t\) 与新状态 \(s_{t+1}\)，并采样 \(\tilde a_{t+1}\)（不执行）\(r_t,\ s_{t+1}\)
Critic 更新用 TD 目标 \(y_t=r_t+\gamma\,q(s_{t+1},\tilde a_{t+1};w_t)\) 算出 \(\delta_t\)，梯度下降更新 \(w\)\(y_t,\ q(s_t,a_t;w_t)\)
Actor 更新用带 baseline 的策略梯度 \(\theta_{t+1}=\theta_t+\beta\,\delta_t\,\nabla_\theta\ln\pi(a_t\mid s_t;\theta_t)\) 更新 \(\theta\)\(\delta_t\)

AC 是 on-policy 算法：与环境交互、用来采样动作的策略，正是当前正在训练的策略 \(\pi(\cdot\mid\cdot;\theta_t)\)。因此每一步收集到的 \((s_t,a_t,r_t,s_{t+1})\) 只能用来更新这一步的参数，不能像 DQN 那样存进经验回放反复使用。on-policy 与 off-policy 的区别见笔记5与笔记2。

三、总结（Summary）

  • 两个网络、两个角色：Actor 是策略网络 \(\pi(a\mid s;\theta)\)，负责决策；Critic 是价值网络 \(q(s,a;w)\)，负责打分。同时训练两者就是 Actor-Critic 方法。
  • Critic 用 TD 学习：以 \(y_t=r_t+\gamma\,q(s_{t+1},\tilde a_{t+1};w_t)\) 为目标做梯度下降，误差为 \(\delta_t=q(s_t,a_t;w_t)-y_t\)。它只需一步转移、可以边交互边更新，代价是自举带来的偏差。
  • Actor 用带 baseline 的策略梯度学习：权重从 \(q_t\) 换成 \(\delta_t\) 之后，等价于用优势函数 \(A_\pi(s,a)=Q_\pi(s,a)-V_\pi(s)\) 加权，这就是 A2C；baseline 必须与 \(a_t\) 无关，梯度才无偏。
  • baseline 的作用：不改变梯度的期望（因而不引入偏差），却能显著降低方差，让算法收敛更快、更稳定。
  • on-policy：数据由当前策略产生、用完即弃，这与 DQN 的 off-policy 经验回放形成对比。AC 的优点是单步更新、方差较小；主要代价是 Critic 的偏差会传导给 Actor，且对学习率等超参数比较敏感。
