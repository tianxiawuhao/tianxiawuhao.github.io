强化学习

5.9 总结

Posted on 2025-04-19，2 min read

在本章中，我们学习了基于策略的方法——策略梯度法。具体来说，我们学习了几种策略梯度法的算法。它们的统一的数学式如下所示。

$$\nabla_{\theta}J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[\sum_{t = 0}^{T}\Phi_t\nabla_{\theta}\log \pi_{\theta}(A_t|S_t)\right] \quad (5.74)$$

  1. $\Phi_t = G(\tau)$（最简单的策略梯度法）
  2. $\Phi_t = G_t$（REINFORCE）
  3. $\Phi_t = G_t - b(S_t)$（带基线的REINFORCE）
  4. $\Phi_t = R_t + \gamma V(S_{t+1}) - V(S_t)$（Actor-Critic）
  5. $\Phi_t = A_t^{\mathrm{GAE}}$（广义优势估计）

上面几种方法的权重 $\Phi_t$ 各不相同。最简单的策略梯度法在所有时刻的权重都是 $G(\tau)$。对它进行改进，将时刻t的收益 $G_t$ 作为权重进行评估的是REINFORCE。另外，通过加入“基线”这一方法，减小了方差的方法是带基线的REINFORCE。Actor-Critic 是一种除了策略之外，对价值函数也用神经网络建模的方法。期待 $(1) \rightarrow (2) \rightarrow (3) \rightarrow (4) \rightarrow (5)$ 这样的编号一直延续下去，从而有更高级的方法出现，产生更好的结果。

优势函数

$\Phi_t$ 也叫做优势函数（Advantage Function），优势函数经常在文献中表示为 $A(s,a)$，也就是在状态 $s$ 采取动作 $a$ 时，策略的优势是多少。强化学习中的很多花活儿都是针对如何改进 $\Phi_t$ 而来的。比如GRPO算法使用的组相对优势。
