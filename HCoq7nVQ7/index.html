一、优势函数（Advantage Function）

接下来是最优动作价值函数和最优状态价值函数：

在此基础上引入一个新概念：最优优势函数（optimal advantage function）。它由最优动作价值函数与最优状态价值函数确定，以最优状态价值函数 \(V^*(s)\) 作为基线，衡量动作 \(a\) 相对基线好多少：

\[ A^*(s,a) = Q^*(s,a) - V^*(s) \]

动作越好，优势越大；当动作 \(a\) 恰好是最优动作时，它的价值就等于基线，优势为 0。因此最优优势函数满足：

\[ \max_{a} A^*(s,a) = 0 \]

二、Dueling Network

Dueling Network 的核心思路是：不直接让网络输出 Q 值，而是让网络分别输出「状态本身有多好」和「每个动作相对这个状态好多少」，再把两者合成 Q 值。它的结构与 DQN 相似，但输出分支被拆成了两支，下面这张图先给出整体结构。

再用一个神经网络来近似最优状态价值函数 \(V^*(s;\boldsymbol{w}^V)\)：

可以看到，这两个神经网络结构相似，都是先用卷积层对输入提取特征；因此在真正实现时，可以让它们共享主干网络的参数。

有了这两个近似，就可以合成 Q 值的近似：

\[ Q(s,a;\boldsymbol{w}) = V^*(s;\boldsymbol{w}^V) + A^*(s,a;\boldsymbol{w}^A) - \max_{a'} A^*(s,a';\boldsymbol{w}^A) \]

这里的 \(Q(s,a;\boldsymbol{w})\) 即 Dueling Network 的输出，\(\boldsymbol{w}\) 表示合并后的参数 \((\boldsymbol{w}^A,\boldsymbol{w}^V)\)；减去 \(\max\) 项是为了让 \(V\) 与 \(A\) 的分解唯一，下一节会详细说明。

Dueling Network 与 DQN 结构相似，但前者把 Q 值分解为状态价值与优势之和，网络结构更好，实际效果也更优。

值得一提的是，训练 Dueling Network 时可以采用 PER、DDQN、Multi-Step TD target 等进阶方法。

三、解决不唯一性（Overcome Non-identifiability）

如果不加最大化项，可能出现 V 与 A 都训练不好的情况。举个例子：记 \(V' = V^* + 10\)、\(A' = A^* - 10\)，两者相加并不影响 Q，即 \(Q' = V' + A' = Q^*\)；但实际上 \(V^*\) 与 \(A^*\) 都发生了大幅偏移，导致它们对应的神经网络都难以训练好。

而加入最大化项后，可以很好地保持 V 与 A 对应神经网络的平衡。

下面这张图把「不加 \(\max\)」与「加入 \(\max\)」两种情形放在一起对比：左侧的 V 与 A 可以同时任意偏移而 Q 不变，网络难以收敛到唯一解；右侧用 \(\max_a A^*(s,a) = 0\) 把基线钉死，V 与 A 就与 Q 一一对应了。

四、总结（Summary）

要点：应把 Dueling Network 当作一个整体来训练，而不是分别单独训练其中的神经网络。
