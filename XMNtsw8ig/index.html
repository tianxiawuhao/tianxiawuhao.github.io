linux安装node

Posted on 2022-06-14，2 min read

Node.js 官方为 Linux 提供的是编译好的 tar.xz 二进制包，解压即用，不需要自己编译。下面以 LTS 版本的 16.13.0（对应 node-v16.13.0-linux-x64.tar.xz）为例，把它安装到 /usr/local/node，并通过软链接让 node、npm 等命令在任意目录下都能直接使用。

整体流程如下：下载压缩包 → 移动到指定目录 → 解压 → 建立软链接 → 按需安装 yarn 与 cnpm。

1、下载

wget https://nodejs.org/dist/v16.13.0/node-v16.13.0-linux-x64.tar.xz

2、移动到指定目录

# /usr/local/node 若不存在需先创建
mkdir -p /usr/local/node

mv node-v16.13.0-linux-x64.tar.xz  /usr/local/node

3、解压

cd /usr/local/node

# xz -d 把 .tar.xz 还原成 .tar，再用 tar 解开
xz -d node-v16.13.0-linux-x64.tar.xz
tar -xvf node-v16.13.0-linux-x64.tar

解压后会得到 /usr/local/node/node-v16.13.0-linux-x64 目录，测试直接用绝对路径运行看看：

/usr/local/node/node-v16.13.0-linux-x64/bin/node -v
# v16.13.0

/usr/local/node/node-v16.13.0-linux-x64/bin/npm -v
# 8.1.0

4、设置软链接，相当于windows设置环境变量

上面的命令必须写全路径才能执行，很不方便。/usr/bin 本来就在系统的 PATH 中，所以只要把可执行文件软链接过去，敲 node、npm 就能直接调用——作用上等同于在 Windows 里把安装目录的 bin 加入 PATH 环境变量。

ln -s /usr/local/node/node-v16.13.0-linux-x64/bin/node   /usr/bin/node
ln -s /usr/local/node/node-v16.13.0-linux-x64/bin/npm   /usr/bin/npm

5、安装yarn,并设置 yarn 的软链接

# -g 表示全局安装，会装到 node 目录的 bin/lib 下
npm install yarn -g

ln -s /usr/local/node/node-v16.13.0-linux-x64/bin/yarn   /usr/bin/yarn

测试下：

yarn -v
# 1.22.17

6、安装cnpm

npm 官方源在国内下载较慢，可以再装一个 cnpm（淘宝镜像客户端）备用。原淘宝镜像域名 registry.npm.taobao.org 已于 2024 年停止服务、HTTPS 证书过期，现已迁移到 registry.npmmirror.com，安装时请使用新地址。

npm install -g cnpm --registry=https://registry.npmmirror.com

# 路径以 npm prefix -g 的输出为准，将其下的 bin/cnpm 链接到 /usr/bin
ln -s /usr/local/node/node-v16.13.0-linux-x64/bin/cnpm  /usr/bin/cnpm
