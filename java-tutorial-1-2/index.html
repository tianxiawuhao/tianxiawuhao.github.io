变量、数据类型与运算符

Posted on 2026-09-19，6 min read

上一章已经跑起了第一个 Java 程序，但里面的数据都是写死的。真实程序要处理的是各种各样的数据：年龄、价格、状态标记、一个开关是开还是关。这些数据在 Java 里怎么表示、能表示多大的范围、不同类型的值能不能混着算，就是本章要解决的问题。读完这一章，你应该能看懂任何一段基础 Java 代码里的变量声明和表达式，也能自己判断一段运算会不会溢出、会不会被截断。本章适合已经会写 HelloWorld、准备打牢语法地基的读者。

一、基本数据类型：4 类 8 种

Java 是强类型语言，每个变量在声明时就必须确定类型，之后只能存这个类型的值。基本数据类型共 4 类 8 种，它们的本质区别是占多少字节、能表示多大范围。

1.1 四种字面量表示的整数

整数常量默认是 int，但可以用不同进制书写。Java 7 之前只有八进制和十六进制两种写法；Java 7 起补上了二进制字面量，还允许用下划线分组，可读性好了很多。

public class LiteralDemo {
    public static void main(String[] args) {
        int dec = 100;              // 十进制，默认形式
        int bin = 0b0110_0100;      // 二进制，0b 前缀（Java 7+），下划线只是分隔符
        int oct = 0144;             // 八进制，0 前缀：1*64 + 4*8 + 4 = 100
        int hex = 0x64;             // 十六进制，0x 前缀，大小写均可
        long big = 10_000_000_000L; // 超过 int 范围必须加 L

        System.out.println(dec + " " + bin + " " + oct + " " + hex); // 100 100 100 100
        System.out.println(big);                                     // 10000000000

        float f = 3.14F;   // 小数字面量默认 double，float 必须加 F
        double d = 3.14;   // 默认类型，不加后缀
        char c = 'A';      // 字符用单引号，只能是单个字符
        boolean ok = true; // 只有 true / false 两个取值
        System.out.println(f + " " + d + " " + c + " " + ok);
    }
}

有两个容易出错的地方需要提前记住。第一，八进制前缀的 0 不能省，0144 是 100，144 就是 144，两者相差 44。第二，八进制和十六进制字面量本身只是“怎么写”，写成 -0xF2 只是对 242 取负，值是 -242，并不是“十六进制不能表示负数”——负数与否取决于有没有负号，跟进制无关。

1.2 字面量的类型归属

整数默认 int、小数默认 double、长整型加 L、单精度浮点加 F，这四条规则决定了绝大多数“类型不兼容”编译错误。图 1 中每种类型的取值范围都值得记住，其中 int 约为 ±21 亿，日常排错时最常撞到它。

二、类型转换：自动提升与强制转换

不同类型的值放在一起运算时，Java 会先做类型转换。方向只有一个：范围小的转成范围大的，这样不会丢数据，编译器自动完成，称为自动类型提升。反过来则必须由程序员显式写出强制转换，并承担精度损失。

public class ConvertDemo {
    public static void main(String[] args) {
        // 自动提升：小 -> 大
        int i = 100;
        long l = i;          // int -> long
        double d = l;        // long -> double
        System.out.println(l + " " + d);

        // 特殊规则：byte、short、char 在运算中先各自提升为 int
        char ch = 'a';
        int sum = ch + 1;    // 'a' 的码值是 97，结果是 98
        System.out.println(sum);

        // 强制转换：大 -> 小，可能丢精度
        double pi = 3.99;
        int n = (int) pi;    // 直接截断小数部分，不四舍五入
        System.out.println(n);              // 3

        // 溢出与截断：130 超出 byte 范围，保留低 8 位
        byte b = (byte) 130;
        System.out.println(b);              // -126
    }
}

2.1 为什么 b = b1 + b2 编译不过

下面这段代码经常让初学者困惑：

byte b1 = 3;
byte b2 = 4;
// byte b3 = b1 + b2;   // 编译错误：possible lossy conversion from int to byte
byte b4 = 3 + 4;        // 编译通过
byte b5 = (byte) (b1 + b2); // 正确写法

原因在于：3 + 4 是编译期常量表达式，编译器先算出 7，确认它落在 byte 范围内，于是放行。而 b1 + b2 里的 b1、b2 是变量，Java 规定 byte、short、char 参与运算时一律先提升为 int，结果类型就是 int。把一个 int 塞回 byte 必须显式转换，这也解释了为什么两个 char 相加得到的是 int 而不是 char。

另外，boolean 不参与任何数值转换，它既不能转成 int，也不能接收 int 的赋值，这一点和 C 语言不同。

三、运算符：五类用法与一个陷阱

3.1 算术运算符与整数除法

System.out.println(5 / 3);    // 1     两个整数相除，结果仍是整数，直接截断
System.out.println(5 % 3);    // 2     取余，常用于判断能否整除
System.out.println(5 / 3.0);  // 1.6666666666666667
System.out.println(10 + 'a'); // 107   char 按码值参与运算
System.out.println("n=" + 1 + 2); // n=12  一旦左边出现字符串，+ 变成拼接
System.out.println(1 + 2 + "n");  // 3n   左边先按算术算完再拼接

++ 和 -- 单独成句时前置后置没有区别；一旦参与其它运算，前置是先自增再取值，后置是先取值再自增：

int a = 10;
int b = a++;  // b 拿到 10，然后 a 变成 11
int c = ++a;  // a 先变成 12，c 拿到 12
System.out.println(a + "," + b + "," + c); // 12,10,12

3.2 赋值、关系、逻辑与三元运算符

扩展赋值运算符 +=、-= 等自带一次强制转换，这是它和“写全”的差别：

short s = 10;
// s = s + 20;      // 编译错误：s + 20 是 int
s += 20;            // 编译通过，等价于 s = (short) (s + 20)
System.out.println(s); // 30

int x = 3, y = 4;
System.out.println((x > y) && (x++ > 0)); // false；&& 短路，右边不执行
System.out.println("x=" + x);             // x=3，没有被自增
System.out.println((x > y) & (y++ > 0));  // false；& 不短路，右边照常执行
System.out.println("y=" + y);             // y=5

int max = (x > y) ? x : y; // 三元运算符：条件为真取前者，否则取后者
System.out.println(max);   // 4

这里的关键区别是：&& 和 || 具有短路效果，左边一旦能决定结果，右边就不执行；而 & 和 | 两侧都会执行。把带副作用的表达式放在右侧时，这个差异会直接改变程序行为，所以日常判断条件应优先用 &&、||。另外关系运算符的结果一定是 boolean，不要把 == 写成 =——后者是赋值，还可能反过来导致“条件永远是 true”的隐蔽 bug。

3.3 位运算与移位：直接操作二进制

位运算符把整数当成一串二进制位逐位操作，只适用于整数类型（&、|、^ 也可以作用于 boolean，即上面说的不短路版本）。Java 的整数用补码表示，最高位是符号位：0 为正，1 为负。

System.out.println(5 & 3);    // 1    按位与：都为 1 才为 1，可用来取某几位
System.out.println(5 | 3);    // 7    按位或：有一个 1 就为 1，可用来置位
System.out.println(5 ^ 3);    // 6    按位异或：相同为 0，不同为 1
System.out.println(~5);       // -6   按位取反，含符号位

System.out.println(5 << 2);   // 20   左移：低位补 0，相当于 ×2²
System.out.println(5 >> 2);   // 1    有符号右移：高位补符号位
System.out.println(-5 >> 2);  // -2   负数右移，高位补 1
System.out.println(-5 >>> 2); // 1073741822  无符号右移：高位一律补 0

图 3 用 8 位示意了三种移位的补位差异。同样一份二进制 11111011（-5 的低 8 位补码），有符号右移补 1，无符号右移补 0，结果一个是 -2，一个变成 1073741822。这说明 >>> 对负数来说不是“除以 2 的幂”，用之前要想清楚。

还有两条容易忽略的规则。其一，移位运算符只取右侧操作数的低位：对 int 只用低 5 位（相当于对 32 取模），对 long 只用低 6 位，所以 1 << 33 的结果是 2 而不是 0。其二，byte、short、char 参与移位前会先提升为 int，因此对小类型做 >>> 之后往往需要强制转换回原类型。位运算在权限标志、哈希计算、加密算法里很常见，后两者恰好是 Java 数据结构与算法部分反复用到的工具。

3.4 优先级

不必背完整表格，记住几条够用：一元运算符（!、~、++、--）最高；其次是算术；移位低于算术、高于关系；关系高于按位；&& 高于 ||；赋值最低。真正稳妥的做法是给不确定的地方加括号，可读性也比考记忆强。

四、小结

本章把数据类型和运算符这两块地基铺平了。4 类 8 种基本类型决定了一个变量能装多大范围的值；整数字面量有四种进制写法，默认 int，小数字面量默认 double。运算时小范围类型自动提升为大范围类型，反向转换必须显式强制并承担截断风险；而 byte、short、char 参与运算会先变成 int。五类运算符中，&&、|| 的短路效果和 >>、>>> 的补位差异最容易写错，扩展赋值运算符则自带一次隐式强转。下一章将用这些积木搭出程序的流程控制，让代码能根据条件走不同的分支。
