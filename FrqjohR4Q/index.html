王树森深度强化学习笔记10：高估问题、目标网络、DDQN（Overestimate、Target Network、Double DQN）

Posted on 2024-01-17，5 min read

一、自举问题（Bootstrapping）

在强化学习中，Bootstrapping（自举）的意思是用一种估算去更新同类的估算。

首先来看 TD target：\(y_t = r_t + \gamma \cdot \max_a Q(s_{t+1}, a; w)\)。它由当前观测到的奖励 \(r_t\) 和 DQN 对下一时刻状态与动作的预测值两部分组成。

然后我们用随机梯度下降（SGD）来更新 DQN 的参数 w。这里的 SGD 用到了 \(y_t\)，而 \(y_t\) 又部分基于 DQN 在 t+1 时刻的估计。因此，用 TD 算法更新 DQN 就是 bootstrapping 的一个例子。

二、高估问题（Problem of Overestimation）

首先，我们要知道：TD算法可能会导致高估真实的动作价值。造成高估的主要原因有两个：

① 原因一：计算 TD target 时使用了最大化（The Maximization）

也就是说，TD target 中的 max_a Q(s_{t+1}, a; w) 会在所有动作的估计价值里取最大值，而这一步“取最大值”正是高估的来源。

证明如下：

首先，我们获得一些真实的观测数据 \(x_1, x_2, \dots, x_n\)，再给它们加上均值为 0 的随机噪声 \(Q_1, Q_2, \dots, Q_n\)。由于噪声的均值为 0，所以对 Q 求期望等于对 x 求期望；但 Q 的最大值的期望会大于等于 x 的最大值，Q 的最小值的期望则会小于等于 x 的最小值，即 \(\mathbb{E}[\max_a Q] \ge \max_a \mathbb{E}[Q]\)，\(\mathbb{E}[\min_a Q] \le \min_a \mathbb{E}[Q]\)。

回到 DQN 的高估问题：假设真实动作价值为 \(x(a_1), \dots, x(a_n)\)，DQN 给出的估计为 \(Q(s, a_1; w), \dots, Q(s, a_n; w)\)，并假设估计是无偏的（即噪声均值为 0）。那么取最大值的 \(q = \max_a Q(s, a; w)\) 就会产生上述高估问题，如下图所示：

下图用一个具体例子说明这一点：真实价值不变，只给每个动作的估计加上均值为 0 的噪声，取最大值的结果就明显偏高。

由上文可知，\(q\) 高估了真实的 \(x(a)\)。假设 \(q_{t+1}\) 是对 \(t+1\) 时刻真实动作价值的估计，那么它同样偏高；而 TD target 由当前观测到的奖励 \(r_t\) 与这一偏高的 \(q_{t+1}\) 组成，所以 \(y_t\) 也会偏高。TD 算法要让 \(Q(s_t, a_t; w)\) 逼近 TD target，于是 \(Q(s_t, a_t; w)\) 也跟着高估真实的动作价值。

② 原因二：自举产生的高估问题（Bootstrapping）

如果已经产生了高估，再通过 Bootstrapping 更新，高估就会不断被放大。

这里讨论为什么Bootstrapping会导致高估：

TD target 的公式中包含最大化运算，而我们又用 TD target 去更新 \(Q(s_t, a_t; w)\)。假设 DQN 的动作价值已经偏高，那么 \(Q(s_t, a_t; w)\) 本身就是高估的量；最大化又会在这些偏高的估计中再取最大，使 \(q_{t+1}\) 更大，再用偏高的 \(q_{t+1}\) 更新 \(Q(s_t, a_t; w)\)，等于把高估重新送回 DQN 的参数里。因此，高估会一轮比一轮严重。

把两个原因串起来看：最大化先制造高估，自举再把高估不断放大，形成正反馈。总结如下图。

高估本身未必是问题：采用最大化时，我们参考的是动作价值之间的相对大小而不是绝对值，因此均匀的高估并不影响最终选出的动作。真正有害的是非均匀的高估，它会让部分动作被系统性地高估。

缓解高估问题主要有两种方法：

① 使用目标网络（Target Network）

② 使用双 DQN（Double DQN）

三、目标网络（Target Network）

与 DQN 相比，目标网络（Target Network）是一个独立的网络。它与 DQN 有着相同的神经网络结构，但使用另一套参数，记作 w−。

我们用 Q(s, a; w) 控制 Agent 并与环境交互，收集经验，即 transition (s_t, a_t, r_t, s_{t+1})。

用目标网络 Q(s, a; w−) 来计算 TD target。

原来用 DQN 自身计算 y_t 并更新参数，会产生自举；现在改用目标网络计算 y_t，从而缓解高估问题。

注意：计算 TD target 用的是目标网络，参数为 w−；随机梯度下降（SGD）只用来更新 DQN 的参数 w。

2）Target Network

目标网络把「选动作」和「算目标」都交给 \(Q(s, a; w^-)\)：先用它选出最大化动作，再用同一个网络计算 TD target。它缓解了自举带来的偏差，但两步都基于同一个网络，因此高估并没有被完全消除。

3）DDQN

DDQN 把这两步分给两个网络：用 DQN \(Q(s, a; w)\) 选动作，用目标网络 \(Q(s, a; w^-)\) 算目标，避免让同一个网络既当选手又当裁判。

DDQN 的第一步（求最大化动作）沿用传统 DQN，用 \(Q(s, a; w)\) 选出最优动作 \(a^*\)；第二步计算 TD target 时改用目标网络 \(Q(s, a; w^-)\)，由此很容易得到如下不等式：
