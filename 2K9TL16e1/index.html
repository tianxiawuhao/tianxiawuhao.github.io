docker安装elasticsearch

Posted on 2022-01-16，1 min read

本文记录在 Docker 中安装 Elasticsearch 2.4.4，并用 head 插件查看集群状态的完整过程。

注意：2.4.4 是 2016 年的版本，只适合学习验证。新版本（7.x/8.x）的插件安装命令已改为 elasticsearch-plugin，head 这类站点插件也不再被支持，官方推荐用 Kibana 或独立部署的 head 服务。

一、搜索并拉取镜像

docker search elasticsearch

选择一个版本，拉取镜像

docker pull elasticsearch:2.4.4

查看镜像

docker images

二、启动容器

通过镜像启动一个容器，把 9200（HTTP 服务）和 9300（节点间通信）端口映射到本机，并用 ES_JAVA_OPTS 限制堆内存。

docker run -d -p 9200:9200 -p 9300:9300 -e ES_JAVA_OPTS="-Xms512m -Xmx512m" --name elasticsearch elasticsearch:2.4.4

查看已启动容器

docker ps

三、验证安装

访问以下地址验证是否安装成功：

http://localhost:9200/

四、安装 head 插件

安装插件前先进入容器，容器名就是启动时指定的 elasticsearch：

docker exec -it elasticsearch /bin/bash

进入容器的 bin 目录查看内容，再执行安装插件命令：

cd bin
ls

plugin install mobz/elasticsearch-head
# 1.x 版本的命令为：plugin -install mobz/elasticsearch-head

访问：

http://localhost:9200/_plugin/head/

插件安装成功
