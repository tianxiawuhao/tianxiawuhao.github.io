安装jdk17

1 打开虚拟机

创建jdk的目录

mkdir /home/jdk17

2 下载jdk17并将其放到我们所建立的目录中

wget https://download.oracle.com/java/17/latest/jdk-17_linux-x64_bin.tar.gz -P /home/jdk17/

3 解压文件

tar xf /home/jdk17/jdk-17_linux-x64_bin.tar.gz -C /home/jdk17/

4 查看安装的jdk具体的版本是什么

ls /home/jdk17/

5 修改环境变量

vim /etc/profile

注意：JAVA_HOME 的路径要指向刚才解压出的 jdk 文件夹

#jdk17
export JAVA_HOME=/home/jdk17/jdk-17.0.10
export CLASSPATH=.:$JAVA_HOME/lib/tools.jar:$JAVA_HOME/lib/dt.jar
export PATH=$JAVA_HOME/bin:$PATH

刷新环境变量

source /etc/profile

6 测试是否安装成功

java -version

安装maven

1 创建 maven 目录

mkdir /home/maven

2 下载 maven 安装包并放入该目录

wget https://mirrors.tuna.tsinghua.edu.cn/apache/maven/maven-3/3.8.8/binaries/apache-maven-3.8.8-bin.tar.gz -P /home/maven/

或者去官网下载

Maven – Download Apache Maven

3 解压文件

tar xf /home/maven/apache-maven-3.8.8-bin.tar.gz -C /home/maven/

4 查看解压出的 maven 目录内容

cd /home/maven/
ls

5 修改环境变量

vim /etc/profile

注意：MAVEN_HOME 的路径要指向刚才解压出的 maven 文件夹

#maven 
export MAVEN_HOME=/home/maven/apache-maven-3.8.8
export PATH=$MAVEN_HOME/bin:$PATH

刷新环境变量

source /etc/profile

6 测试是否安装成功

mvn -version

安装jenkins

1 查询镜像

docker search jenkins

2 下载镜像

docker pull jenkins/jenkins

3 编写docker-compose.yml

version: '3'
services:
  jenkins:
    user: root
    restart: always
    image: jenkins/jenkins
    container_name: jenkins
    ports:
      - 8080:8080
      - 50000:50000
    volumes:
      - /home/jenkins/jenkins_home/:/var/jenkins_home/
      - /var/run/docker.sock:/var/run/docker.sock
      - /usr/bin/docker:/usr/bin/docker
      - /home/jdk17/jdk-17.0.10:/home/jdk17/jdk-17.0.10
      - /home/maven/apache-maven-3.8.8:/home/maven/apache-maven-3.8.8
      - /root/.ssh:/root/.ssh

如果不想用 docker-compose，也可以用下面这条等价的 docker run 命令启动容器：

docker run -di -p 8080:8080 -p 50000:50000 --name jenkins --restart=always -v /home/jenkins/jenkins_home/:/var/jenkins_home/ -v /var/run/docker.sock:/var/run/docker.sock -v /usr/bin/docker:/usr/bin/docker -v /home/jdk17/jdk-17.0.10:/home/jdk17/jdk-17.0.10 -v /home/maven/apache-maven-3.8.8:/home/maven/apache-maven-3.8.8 -v /root/.ssh:/root/.ssh jenkins/jenkins

4 设置权限

chown -R 1000:1000 /home/jenkins/jenkins_home
chown -R 1000:1000 /home/maven

默认情况下，docker 命令会使用 Unix socket 与 Docker 引擎通讯。而只有 root 用户和 docker 组的用户才可以访问 Docker 引擎的 Unix socket。出于安全考虑，一般 Linux 系统上不会直接使用 root 用户。即我们当前的用户不是root用户。

解决办法：把我们当前的用户添加到docker组中就可以了。

# 将当前用户加入 docker 组（$USER 会自动展开为当前用户名）
sudo gpasswd -a $USER docker
# 重新加载 docker 组，使当前会话立即生效
newgrp docker

5 启动容器前配置国内更新源（可选）

Jenkins需要下载大量内容，但是由于默认下载地址下载速度较慢，如有需要可以设置下载地址为国内镜像站

cd /home/jenkins/jenkins_home/
cat hudson.model.UpdateCenter.xml

修改数据卷中的hudson.model.UpdateCenter.xml文件

# 修改数据卷中的hudson.model.UpdateCenter.xml文件
<?xml version='1.1' encoding='UTF-8'?>
<sites>
  <site>
    <id>default</id>
    <url>https://updates.jenkins.io/update-center.json</url>
  </site>
</sites>
# 将下载地址替换为http://mirror.esuni.jp/jenkins/updates/update-center.json
<?xml version='1.1' encoding='UTF-8'?>
<sites>
  <site>
    <id>default</id>
    <url>http://mirror.esuni.jp/jenkins/updates/update-center.json</url>
  </site>
</sites>
# 清华大学的插件源也可以https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json

6 启动容器

#在docker-compose.yml所在目录启动
docker-compose up -d jenkins

7 访问 Jenkins

1、启动之后使用http://ip:端口访问jenkins。

复制管理员密码

初始管理员密码存放在容器的 $JENKINS_HOME/secrets/initialAdminPassword 中。本文用 docker-compose 部署，JENKINS_HOME 即 /var/jenkins_home，对应宿主机路径如下：

cat /home/jenkins/jenkins_home/secrets/initialAdminPassword
# 输出即初始管理员密码

部署

1 创建项目

2 用户密码类型

  • 1创建凭证
  • 选择"Username with password"，输入Gitlab的用户名和密码，点击"确定"。

3 配置源码管理，从 GitLab 拉取代码

4 编译打包

# 构建 -> 添加构建步骤 -> Execute Shell
echo "开始编译和打包"
mvn clean install -DskipTests
VERSION=`date +%Y%m%d%H%M`
echo $VERSION
echo "=============== 登录Harbor  ==============="
cd dt-os-plat/
docker login -u 11111 -p 11111 https://registry2-qingdao.cosmoplat.com
echo "=============== 打包Docker镜像 ： " registry2-qingdao.cosmoplat.com/62_d3os/dt-co-simulation:$VERSION "==============="
docker build -t registry2-qingdao.cosmoplat.com/62_d3os/dt-co-simulation:$VERSION .
echo "=============== 推送到镜像仓库  ==============="
docker push registry2-qingdao.cosmoplat.com/62_d3os/dt-co-simulation:$VERSION
echo "=============== 登出  ==============="
docker logout
echo "编译和打包结束"

提示：docker login 的用户名密码建议改用 Jenkins 凭据（Credentials）在构建中引用，不要明文写进构建脚本。
