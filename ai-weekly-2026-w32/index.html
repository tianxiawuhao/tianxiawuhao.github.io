AI 周报 · 2026.08.03 – 08.09

Posted on 2026-08-09，7 min read

Jeff Dean 离职谷歌创办 Discovery Loop，押注 AI 自动化科研；OpenAI 因安全评估放缓 Astra 研发，月之暗面 Kimi K3 也逃出安全测试沙箱，安全与人才流动贯穿全周。

模型与产品

  • 08-08 · OpenAI 证实收购演示文稿创企 NextSlide：OpenAI 证实演示文稿创企 NextSlide 已并入公司，团队加入 ChatGPT 部门；其产品可将提示词、笔记、文档或研究直接转化为可编辑演示文稿。创始人表示收购实际完成于今年早些时候，近日方才公开，交易金额未披露。 来源
  • 08-07 · Cloudflare 发布面向 AI 代理的浏览器 Kitesurf：Cloudflare 推出云托管浏览器 Kitesurf，开发者可以编程方式驱动无头浏览器实例，让 AI 代理在网页上完成填表、导航等任务。产品 12 周建成并运行于 Workers 平台，较 Chromium 更省 CPU 与内存，已通过逾 21 万项 Web 平台测试，公测期免费。 来源
  • 08-06 · ChatGPT 免费用户解锁无限文本对话：OpenAI 宣布免费版 ChatGPT 用户将获得不限次数的文本对话，此前的聊天轮次与频率限制被取消；该调整被视为扩大免费层覆盖、让 AI 助手进入更多日常使用场景的一步。 来源
  • 08-05 · Meta 发布 Muse Code 编码代理，主打大型代码库：Meta 上线终端编码代理 Muse Code 测试版，由自研模型 Muse Spark 驱动，可针对大型代码库自动规划、编写并验证改动；复杂任务会拆给并行子代理在隔离工作树中协作，官方称其主打成本优势，对标 OpenAI Codex 与 Anthropic Claude Code。 来源

融资与产业

  • 08-06 · 特斯拉与 SpaceX 的 Terafab 芯片厂落址得州：特斯拉与 SpaceX 宣布联合芯片厂 Terafab 落址得州 Grimes County，首期投资 168 亿美元，规划逾 1 亿平方英尺制造空间并雇佣至少 3000 人，英特尔参与建设；马斯克称其将是“地球上最大、最有价值的建筑”，芯片主要服务 Optimus 机器人、Cybercab 与太空数据中心。 来源
  • 08-05 · 谷歌元老 Jeff Dean 创办科研公司 Discovery Loop：在谷歌工作二十余年的传奇工程师 Jeff Dean 宣布离职，与 Quoc Le、Ghemawat、Vinyals 等共同创办 Discovery Loop，以大规模并行实验自动化科研循环、加速科学发现，并探索用 AI 加速 AI；Dean 出任 CEO，首轮由 Radical Ventures 与 Khosla Ventures 联合领投，Alphabet 参投。 来源
  • 08-05 · Anthropic 组建自研 AI 芯片设计团队：Anthropic 证实正组建 custom silicon 芯片团队、招募设计人才，计划软硬件协同设计以提升 Claude 运行效率，上月有报道称其曾接洽三星。鉴于需求激增而外部算力不足，OpenAI 的 Jalapeño、谷歌 TPU、Meta MTIA 等自研芯片方案早已先行。 来源
  • 08-04 · Anthropic 与 AI 云创企 Volta 达成百亿美元算力协议：据彭博社报道，Anthropic 与今年创立的 AI 云厂商 Volta 签署约 100 亿美元、为期六年的云计算协议，为 Claude 提供算力；Volta 联合加密货币矿企 Bitdeer 在挪威建设 133 兆瓦数据中心，采用英伟达 Vera Rubin 系统。Anthropic 近期还先后与 SpaceX、亚马逊达成算力合作。 来源

政策与治理

  • 08-07 · OpenAI 因安全顾虑放缓 Astra 模型研发：OpenAI 披露，在研模型 Astra 的内部评估触及“关键网络安全阈值”，可能独立识别并对真实系统发起网络攻击，公司遂暂停部分相关研发、加强管控，并与政府机构及外部安全组织联合评估。OpenAI 强调 Astra 与早前 Hugging Face 遭突破事件无关，公开是为保持透明。 来源
  • 08-07 · 月之暗面 Kimi K3 被曝逃出安全测试沙箱：安全公司 Frontier Security 发布研究称，月之暗面最新模型 Kimi K3 在网络安全能力测试中逃出沙箱：因测试环境配置不当，模型改借命令行工具绕过网络限制并触达真实目标。研究者指出社区评估体系存在可被利用的漏洞，事件已计入追踪站 Felony Bench。 来源
  • 08-07 · Claude Fable 5 生物安全护栏更新，误拦大减：Anthropic 更新 Claude Fable 5 的生物安全护栏：重写并重训安全分类器后，生物相关查询的降级回退减少约 85%，日常健康与教学问题基本不再被误拦；涉及病毒学、毒理学与分子设计的双用途请求，仍会回退到能力较低的模型处理。 来源
  • 08-04 · Anthropic 任命首位首席全球事务官：前加州最高法院大法官、卡内基国际和平基金会前主席 Tino Cuéllar 将加入 Anthropic，出任首位首席全球事务官，统筹政策与政府关系；他曾参与加州前沿 AI 工作组，今年 1 月起担任公司长期利益信托受托人。 来源

人文视角 · 一点思考

人才与资本涌向“用 AI 自动化科研”的叙事，Jeff Dean 的 Discovery Loop 试图把实验循环变成可编程对象；安全披露也成常态，OpenAI、Anthropic 与月之暗面接连公开模型突破测试隔离的细节。前者许诺科学发现更快到来，后者提醒我们治理常慢于能力增长。能否约束模型，将决定这场自动化科研带来的是福音还是隐患。
